好，那我们先来看看我们这个电路。首先我们来看这个 WS2812 LED 灯带，请看我们这个 WS2812 灯带，它这里一共有三条引线。我们先来看这条红色的引线，它是我们这个灯带的正 5 伏引线，这条引线是为我们灯带提供电源能量的，它连接到我们面包板上的电源轨的正极电源轨上；这个面包板它的电源轨都是通过面包板电源模块实现供电的。接下来我们再来看这个灯带的灰白色这根引线，它是灯带的接地引线，这条引线请看它是和电源轨的负极连接到了面包板电源模块的接地引脚上的，同时我们的 Arduino UNO 开发板它的接地引脚也是通过一根导线连接到了我们这个电源轨的负极上面的。换句话说，现在我们所有的电子元件，也就是说这个 WS2812 LED 还有面包板电源模块，还有 Arduino，它们的接地都是连在一起的。这个我以前给大家介绍过，这么做的目的是让我们这些电子元件实现一个共地的目的。
最后我们就来看 WS2812 LED 灯带它最核心的地方，也就是这个信号输入的这条引线。这条引线是通过一根导线连到了一个 470 欧姆的电阻上，然后通过这个电阻连接到了 Arduino UNO 开发板的 9 号引脚上。不过估计大家已经注意到了，我们这个 470 欧姆的电阻它旁边写了一个「可选」的文字，从字面上来说很容易理解，这个「可选」的意思就是说我们这个电阻可用也可以不用。那既然是可用也可以不用的话，为什么还要在这放这么一个电阻呢？老实说，当我们做这套教程的时候，我们查阅了很多关于 WS2812 LED 灯带的使用方法，我们看到了两种不同的声音。有一部分建议用这个电阻，作用是用来保护我们的 Arduino 开发板，防止 Arduino 开发板在驱动 LED 灯带的时候可能会产生一些损伤；但是还有一种声音，就是说这个电阻没有必要。那么根据我们的使用经验来说，当我们把 Arduino 开发板和我们这个灯带的信号输入这条引线直接连接在一起的时候，也就是说我们不用这个电阻的话，在这种使用情况下我们还从来没有烧坏过我们的 Arduino 开发板。但是因为我们曾经不止一次在网上看到很多朋友建议使用这个电阻，那么我们在这里制作教程，也建议您还是把这个电阻放在这里。不过如果要是您找起来比较费劲，那我们可以很肯定地告诉您，我们在使用 Arduino 开发板的数字输入输出引脚发送出控制信号，把这个控制信号通过一根导线而没有电阻直接连接到光带的信号输入引脚上的时候，通过这种使用方法我们还没有发现有任何问题。不过没有发现问题不代表肯定没有问题，由于 WS2812 这个芯片并不是我们设计的，那是人家的商业机密，所以我们也不确定 WS2812 这个芯片里面具体的结构。所以我们在这里建议您，假如手边很容易找到一个 470 欧姆左右的电阻，那好，用它；假如没有的话，没关系，就这么直接连上。
好，那么这个也就是我们如何使用 Arduino 开发板通过面包板来连接到我们的灯带的这种使用方法。不过讲到这，我不知道会不会有朋友感到这样的疑问：就是说我们的 Arduino 开发板上面是有正 5 伏这个电源输出的引脚的，假如我们用 Arduino 开发板来直接为灯带供电可不可以呢？这么做要分情况。首先，如果我们这个灯带上面的灯珠很少，五六个，没有问题，直接用 Arduino 开发板上的正 5 伏引脚来为灯带供电是没有问题的。但是如果我们这个灯带比较长，那么这个时候我们必须要借助外界的电源模块来为我们这个灯带供电，原因是我们的 Arduino 开发板它输出的电源功率并不是很高，那么如果灯珠太多的话，这个时候我们的开发板是吃不消的，没有办法去为这么多灯珠同时供电。那么如何为我们的灯带配上一个合适的电源，这个知识我们在这节课后面的地方会给大家再次介绍。现在就请先注意，这是我们第一种用 Arduino 来控制 WS2812 LED 灯带的电路连接方法。
现在您在屏幕上看到的就是我们要给您介绍的第二种如何使用 Arduino 开发板来控制 WS2812 LED 灯带的电路连接了。可以看到，在这种电路连接方法中我们已经不再使用面包板了，而直接使用电源来为我们的灯带进行供电。请看，灯带的正 5 伏和接地都是直接连到了我们这个直流电源上的，同时我们的 Arduino 开发板它的接地引脚也是连接到我们电源上的，那么现在灯带、Arduino 开发板还有我们的电源都是共地的，而灯带它的电源能量就是通过直流电源给它提供的。另外 Arduino 的 9 号引脚通过导线串上了一个可选的 470 欧姆左右的电阻，然后连接到了灯带的控制信号输入这里，同时我们的 Arduino 开发板是通过数据线连接到了电脑的 USB 端口上的。可以说这种电路连接方法是我们开发 Arduino 控制灯带的程序的时候所使用的电路连接方法。那么我们在开发好控制程序以后，实际使用这个 Arduino 开发板来控制灯带的时候，我们不可能总是让这个开发板连在电脑上。比如说我们现在已经把程序开发好了，程序也上传到 Arduino 开发板以后了，现在我们就要用这个开发板控制灯带来为我们家庭提供一个装饰照明这样的作用，那在这种情况下我们就不能再用这种电路连接方法了，我们就要用一种使用时候的电路连接方法。
那么在实际使用 Arduino 开发板来控制灯带这种使用过程中，唯一我们要做调整的地方就是：Arduino 它将不再通过 USB 端口来为它供电了，它的供电是来自于我们这个直流电源的。那么直流电源为 Arduino 开发板供电的引脚请看，是在我们这开发板上有一个正 5 伏这个引脚上。换句话说，我们这个直流电源它的正 5 伏这个电源输出将是连接到了 Arduino 开发板的这个正 5 伏引脚上，这样一来我们这个直流电源就可以既为我们的开发板供电，也为我们的灯带供电了。那么讲到这，可能有的朋友会感到好奇了：平时我们用 Arduino 开发板的时候，这个正 5 伏引脚都是用来电源输出的，也就是说 Arduino 开发板是通过正 5 伏来为其他的电子元件来供电的，可是在您这个电路连接里边儿，你这个直流电源它的电源输出直接输入到 Arduino 开发板，也就是在这个电路连接里面这个正 5 伏引脚是用来做电源输入、为 Arduino 供电的。这个正 5 伏引脚到底是电源输出引脚还是电源输入引脚，有点糊涂了是吗？其实 Arduino 开发板上的正 5 伏这个引脚它有两种功能：第一种功能就是说当我们在使用 Arduino 开发板正常使用过程中，在这种情况下我们是可以用一个正 5 伏的直流电源来通过 Arduino 开发板上的正 5 伏引脚来为 Arduino 供电的，也就是在这种情况下我们这个正 5 伏引脚起到了一个电源输入的功能；那么当我们正在开发 Arduino 开发板的时候，这个时候我们的开发板是连接在电脑上的，那么这个情况下我们这个开发板上的正 5 伏引脚它是电源输出这么一个作用。
那么讲到这，我们就必须要好好地讲一讲关于 Arduino 开发板供电这么一个问题了。我们还是到我们老地方，太极创客我们这个网站，那么在我们网站的首页里面有一个搜索栏，我们在这个搜索栏里面输入「供电方法」这么一个关键词，然后点击搜索，这时候网站就会给我们显示出来一个专门介绍几种常用的为 Arduino 供电的方法的页面，我们点击它。在这个页面里我们太极创客团队专门为您介绍了几种常用的为 Arduino 供电的方法，这些方法应该都是比较直接也比较简单的，但是这些信息很关键，因为我们现在已经不再是初级的入门 Arduino 用户了，我们现在已经渐渐地达到可以自己来开发项目这种水平了。那在这种情况下我们有时候可能就不会让 Arduino 经常连在电脑上面，而是让 Arduino 来独立地工作。那么要用 Arduino 独立工作的时候，最关键的一点就是要如何来为 Arduino 供电这个问题，这个问题我相信您在看完我们这个页面以后就会找到解决方案了。另外我还有一点要强调一下，就是在我们想要给 Arduino 供电、寻找这个解决方案的时候，我建议您仔细地来看一看我们这个页面，我相信您通过我们这个页面里面的信息会得到很多的启发。有一点很关键，就是对于初学的朋友来说千万不要凭着感觉——“我觉得这样好像给 Arduino 供电是没问题的”，然后就给 Arduino 通电，那在这种情况下很有可能在您给 Arduino 供电的时候方法不当，可能会让 Arduino 开发板受到损伤，严重的呢很有可能开发板就报废了。
那么下面我们接着来看我们这个 Arduino 开发板控制 WS2812 LED 灯带这个电路。在这个电路里面刚才我们说，如果用直流电源，可以同时为灯带以及 Arduino 开发板来供电。那么在这个图里面我们可以很容易地用一条彩色线段来表示这个电源与开发板的正 5 伏引脚以及灯带上的正 5 伏引脚连起来了。但实际上我们这个电源怎么才能够跟开发板和灯带连接起来呢？那这样的电源是从哪儿能够找到的呢？这种电源贵不贵啊？事实上这种电源就在你我身边，只要您是一个有心人，我相信您是可以找到这样的正 5 伏直流电源，并且把这个电源应用到我们的电路中的。具体怎么做呢？同样的还是在我们太极创客这个网站，那么在首页里面同样在搜索栏里面，我们输入「项目制作电源」这样的字样，然后点击搜索，这时候这个页面就可以告诉我们如何用一些常见的家用直流电源把它改装成我们在 Arduino 项目制作的时候可以使用的这种电源了。您那可以看到，在这个页面里我们是一步一步地告诉您如何将我们家用的这种电源改装成 Arduino 项目制作来使用的这种电源。可能有的朋友会说，哎，平时你不都录视频，怎么现在变成了照片加文字了，是不是有点偷懒了呢？其实没有，事实上制作一个页面所耗费的工作量比我们录制一段视频这工作量一点也不小，反而还会更麻烦，因为需要一张张拍照、一张张配图、一张张地把这文字加进去。但是这么做我们考虑到几方面：第一方面，通过视频确实很容易，我们手把手一步一步告诉您，但是这样很不利于您自己的成长，毕竟我们希望您能够自己动手、自己思考，而并不是简单地看着我们，然后看过了也就过去了；第二点是因为网页里的这个图文我们可以随时把它翻出来，随时可以看一看，这样将来假如忘记了怎么做这个东西的时候，我们就可以把它找出来，然后跟着它一点点地做出来就可以了。所以假如您需要把常用的这种家用直流电源改装成 Arduino 项目制作里面用到的这个电源的话，那么我建议您可以到我们这页面里来仔细看一看，这里面的每一个步骤的图文都很详细。
好，那么回过头来我们接着看我们这个电路。在这个电路图里面，我刚才给大家讲了这个电路图的详细连接，以及如何来为这个电路配上一个电源。但是有一点，我们每个人在开发不同的这个灯带项目的时候可能都会有所不同，是什么呢？就是我们不同的项目里面所用到的灯带里面的那个灯珠数量是不一样。那在这种情况下，究竟我们如何来根据我们实际的项目里的灯珠数量来决定选用什么样的电源，这个问题又如何来解决呢？在这个问题上您只要记住一点，就是每一个 WS2812 LED 的灯珠都需要差不多 60mA 左右的电流。我们现在举个例子，比如说我们一条灯带，这条灯带上有 30 个灯珠，那么要为这条灯带配电源的话，那么需要的这个电源它的电流要求是 30×60 等于 1800mA。为什么 30 呢？有 30 个灯珠；为什么 60 呢？每个灯珠需要 60mA。那么这样一乘出来以后就是这个电流的一个基本的要求。请注意，我在这说是一个基本要求，为什么说是基本的要求呢？实际上我们知道，我们每一个灯珠它在发光的时候，它是通过这个灯珠里面封装的三种不同颜色的 LED，它们这三种不同颜色 LED 的这个发光亮度不同，从而调配出来我们需要的一种颜色。那么只有当我们这个 LED 灯珠需要发出白色光的时候，它才需要把封装在里面这三个 RGB 这三种颜色的 LED 调到最大的亮度，那在这种情况下这个 WS2812 LED 才发出白色的光。但是我们知道，我们这个灯带并不是总是让它产生白色的光的，那么如果我们不是总是让它产生白色的光，而是让它产生千变万化五颜六色的颜色的时候，那么在这种情况下我们每个灯珠它并不是总是需要达到最大的亮度，那么如果它不需要达到最亮亮度的时候，它所需要的电流也并不需要非得要达到 60mA 这么大的一个电流强度。所以当我们在给我们这灯带配电源的时候，我们就要考虑一下这个灯带所有的灯珠它在正常工作的时候经常发出的颜色是哪一种颜色。假如说这个灯带里面的所有灯珠在实际工作中总是产生白色，那在这种情况下没办法，那我们就只得给它配一个最大的电流强度就是 60mA，那么在这种情况下我们这 30 个灯珠需要 1800mA，这个要求没什么好商量的，必须得达到。但是反过来，假如你的灯带在平时使用过程中并不是需要让它所有的灯珠都产生白色，那在这种情况下根据我的使用经验来看，您通过这个计算公式得出的结果，利用这个结果把它乘以 80%，也就是说这 30 个灯珠本身是需要 1800mA，但是这 1800mA 我们乘以 80%，现在得到的结果就是差不多 1500mA 左右，那么使用一个 1500mA 左右的电源来为一个 30 个灯珠的灯带来供电的话，在这种情况下基本上是可以够用的。

## 本节要点

- 用 Arduino 控制 WS2812 LED 灯带的第一种电路连接方法：借助面包板，灯带的正 5 伏接面包板电源模块的正极电源轨，接地与 Arduino UNO 的接地引脚都接到负极电源轨，实现所有电子元件共地。
- 灯带的信号输入引线经一个「可选」的 470 欧姆电阻连接到 Arduino UNO 的 9 号引脚。关于这个电阻存在两种意见：一种认为它能保护 Arduino 开发板免于损伤，另一种认为没有必要；讲师建议有条件就装上，找不到也可以直接连接。
- 是否可以用 Arduino 板上的正 5 伏引脚直接给灯带供电，要分情况：灯珠只有五六个没问题；灯带较长时开发板输出功率不足，必须借助外部电源模块供电。
- 第二种电路连接方法：不使用面包板，灯带的正 5 伏和接地直接接直流电源，Arduino 的接地也接到电源上，三者共地；9 号引脚经可选电阻接灯带信号输入，开发阶段开发板仍通过 USB 连接电脑。
- 实际使用时 Arduino 不再通过 USB 供电，而是由直流电源接入开发板的 5V 引脚供电，这样一路电源同时为开发板和灯带供电。开发板上的 5V 引脚具有两种功能：由外部电源经它供电时是电源输入，开发板通过 USB 连电脑时它是电源输出。
- 为 Arduino 供电不可凭感觉，方法不当可能损伤甚至报废开发板；太极创客网站《供电方法》页面介绍了多种常用供电方案，可在网站搜索「供电方法」查看。
