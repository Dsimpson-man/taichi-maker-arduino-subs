首先，我请您回忆一下，我们在整个零基础入门学用 Arduino 教程的刚开始第一部分，我们曾经教给大家如何使用一个按键开关来控制一个 LED 的亮和灭。接下来，我们在整个零基础入门学用 Arduino 教程的第二大部分机械臂篇里面，我曾经教给大家如何使用 Arduino 的串口监视器，通过向 Arduino 发送串行指令来控制一个机械臂。通过刚才我给您举的这两个例子，我不知道你有没有体会到，目前我们学习的内容都是我们人给 Arduino 发送指令：无论是通过按键开关给 Arduino 发送一个指令，还是通过串口监视器给 Arduino 发送指令，都是我们人在给 Arduino 发送一个指令，然后 Arduino 会根据我们人类给它的这个指令再进行相应的动作，无论是控制一个机械臂也好，还是只是简单地点亮一个 LED。换句话说，在整个过程中都是我们在给 Arduino 做出一些指挥，而 Arduino 是在接收到我们人给它指令以后再做出相应的动作。

那 Arduino 能不能脱离开我们人类，而独立自主地来进行工作呢？答案当然是肯定的了。接下来请您看下面这几个例子。比如说我们现在要做一个小项目，在这个小项目里面，我们用 Arduino 控制器可以感受到外面的光亮程度，也就是说白天和夜晚的亮度，根据这个亮度不同来点亮或者是熄灭一盏灯。或者我们可以让 Arduino 的控制器可以感知到是不是有人来到它的身边了，那么一旦有人来到它身边，它就点亮一盏灯，那人走以后它就自动地把这盏灯熄灭了。或者我们可以让 Arduino 感知到它所处的环境的温度情况，然后把这个温度情况通过一个屏幕显示出来，让我们知道当前的温度是多少。

那么刚才给大家举的这些例子都非常简单，Arduino 能做的事情远远不止这些。不过这几个例子都具有一个典型性。为什么有典型性呢？也就是说，Arduino 是可以感应到我们外界的状态的：无论温度状态，还是有没有人来，还是这个亮度，它都能感应到。它是怎么感应到的呢？单凭 Arduino 控制器本身是不够的，那么还差什么呢？还差一个非常关键的元件，它叫做传感器。

估计您在听到"传感器"这个名词的时候，应该不会感到陌生，因为我们生活里面到处都充满了传感器的影子。那么到底传感器究竟是什么呢？我们来看一看传感器的基本概念。传感器是一种物理装置或者是生物器官，传感器能够探测、感受外界的信号、物理条件，比如说光、热、湿度，或者是化学组成，比如说烟雾，并且将探知的信息传递给其他装置或器官。在我们这里，我们这个传感器是能够把外界的光亮情况、温度情况感知出来，并且将这些信息传递给我们的 Arduino。

我们再看，传感器对 Arduino 来说，就相当于给 Arduino 配上了眼睛、配上了耳朵，让它能够感知外界的状况，而不是只是单纯地让我们人类给它发送指令，而是 Arduino 自主地可以感受到外界的情况，然后再根据外界的情况做出相应的动作。那么在接下来的几节课里面，我将给大家讲解几种常见的传感器在 Arduino 上的应用。

那么传感器本身是非常庞大的一个家族，而且它的分类也非常繁多。我们这个教程不可能把所有的传感器都讲给大家，所以我们想要做的是让大家对传感器有一个初步的认识。同时，随着我们教程的学习，我们未来也会给大家讲述更多的不同类型的传感器，而且我相信大家在未来的学习、未来的工作中，也会接触到很多很多不同类型的传感器。那么当我们在接触到新的传感器的时候，我们其实是在不断学习的过程。好，这节课的内容先告一个段落，从下一节开始，我们将一起来学习、接触我们的第一个传感器。这节课内容到这里就结束了，感谢您，我们下节课再见。

## 本节要点

- 回顾前面所学：按键开关控制 LED、用串口监视器发送串行指令控制机械臂，本质上都是"人给 Arduino 发指令，Arduino 再执行动作"。
- Arduino 可以脱离人的指挥独立工作，例如根据亮度点亮或熄灭灯、感知有人靠近时点灯、人走自动灭灯、把环境温度显示在屏幕上。
- 这些例子的共性在于：Arduino 能够感应外界状态（温度、人体、亮度等），而单靠 Arduino 控制器本身是不够的。
- 传感器的基本概念：一种物理装置或生物器官，能探测、感受外界信号与物理条件（光、热、湿度等），或化学组成（如烟雾），并将信息传递给其他装置或器官。
- 传感器对 Arduino 的意义，相当于给它配上眼睛和耳朵，让它从"被动接受指令"变成"主动感知外界并做出动作"。
