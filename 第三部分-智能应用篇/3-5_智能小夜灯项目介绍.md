# 3-5 智能小夜灯项目介绍

## 正文

从这节课开始，我们将应用之前几节课所学到的知识一起来制作一款环保智能小夜灯。这个环保智能小夜灯可以看作是我们目前所学习知识的一个总结，也可以把它看作是一个热身。是什么热身呢？是为了迎接我们下一个制作的热身，我们下一个制作将会一起来使用可编程控制 LED 光带制作一款可以用红外遥控的智能家居照明灯。那么下一个制作要相对复杂一些，所以我们先练练手，先做一个环保智能小夜灯。不过请您也不要小瞧这款小夜灯，因为它将是我们第一次使用身边的材料来制作的、可以给我们在生活中提供帮助的一个物品。另外我们太极创客这个团队也对它付出了不少的精力，让它具有节能、环保还有易用这么几个特点。那么具体这几个特点是怎么实现的呢？下面我给大家讲一讲。

首先我们看节能这个特点。我们让这款夜灯只有在需要照明的时候才能够点亮，换句话说，它是可以感应外界的亮度的。我们是通过使用光敏电阻让它感知环境亮度，并且通过所感知到的环境亮度来控制照明。另外我们要让这款夜灯只有在感应到人的时候才会自动地点亮，没有人的时候它会保持熄灭，那么我们是通过使用红外模块来让它感应到有没有人，从而控制照明。

接下来我们来看看这款夜灯的环保特点。不过在讲述它的环保特性之前，我想先问你一个问题：您知不知道全世界范围内每一分钟有多少个塑料瓶被用掉？这个问题的答案是 100 万个。那你又知不知道这些被用掉的塑料瓶它的回收利用率有多少呢？答案只有 9%。换句话说，在全世界范围内每分钟就会有 91 万个塑料瓶被白白地浪费掉了。接下来我想让您再思考一个问题，在 2016 年全世界范围内纸箱等生产量是多少您知道吗？这个生产量是用一个以平方米为单位的数字来作为答案的，这个答案代表的就是制作这些纸箱所需要的纸板它的面积是多大，是这么长长的一串数字。这数字有多大呢？这是 2400 亿平方米。这么庞大的数字我们可能很难去体会它的实际意义，那好，我给您做了一下换算，这 2400 亿平方米是足足可以覆盖住 330 万个足球场的。

听过这些庞大的数字以后，可能有的朋友有点糊涂了：我们这个教程是在讲 Arduino 还是在讲环保呢？其实这两者并不矛盾，因为有了 Arduino 控制器，我们这个小夜灯将使用 Arduino 控制器把我们身边的这些废物让它们重获新生。在我们制作这款智能小夜灯的过程中，我们将使用用过的饮料瓶还有用过的包装纸箱把它们作为制作材料，让这些所谓的废物再次为我们的生活发光发热。无论您是在制作这款小夜灯的过程中也好，或者是把它制作好以后放在家里面、有朋友到家里来看到它也好，我想通过这款小夜灯我们想表达的概念很清晰，那就是保护我们的地球家园不能只停留在嘴上，而是可以付出实际的行动的。不好意思，可能有点太激动了，所以讲的关于环保的内容就有点多了。

我们还回过头来看一看我们的这款小夜灯。我们刚才说到它的第三个特点是易用，这个特点就没什么好多说的了，易用顾名思义就是容易使用，任何人拿过来把它插上电源，就可以让它开始为我们工作，让它为我们照明了。

下面我就给大家介绍一下制作这款环保智能小夜灯都需要哪些材料还有工具，您可以跟着我的讲解把这些材料和工具先准备好，然后您就可以跟着我们的视频演示一起来制作这款环保智能小夜灯了。首先我们需要一块 Arduino UNO R3 开发板，一个红外人体感应模块，一个光敏电阻。我们这个教程里面用的这个光敏电阻是 5528 的型号的，你也可以用别的型号的光敏电阻，但如果你用别的型号的光敏电阻的话，后面我们在使用这个分压电阻还有后面写程序的时候所使用的一些程序内容就要进行相应调整了，我们这边建议您使用 5528 这个型号的光敏电阻。

接下来还需要一个分压电阻。如果您和我们一样选用的是 5528 这种型号的光敏电阻的话，那么我们推荐您使用的是 10k 这么一个分压电阻；如果你选择别的型号的光敏电阻的话，那么这个分压电阻阻值就要进行相应的调整了。接下来我们还需要一个 RGB LED，RGB LED 我们选用的是一个共阴极的 RGB LED。可不可以选用其他型号的 LED 呢？可以，不过同样的，如果你用别的类型的 RGB LED 的话，那么后边我们在写程序的时候您就需要进行相应的修改了。同时为了配合我们这个 RGB LED，我们还需要三个限流电阻。为什么三个限流电阻呢？我们之前课程里给大家讲过，RGB LED 它是把三个颜色的 LED 封装在一个里面了，那么这个时候我们需要三个限流电阻来配合这个 RGB LED。我们选用的这个 RGB LED 的限流电阻阻值可以在 100 欧姆到 300 欧姆之间，具体数值你可以自己来定。

另外我们还需要一个面包板，以及十个公对公的杜邦线和十个公对母的杜邦线，注意是两种杜邦线，大概都是十根左右。接下来的内容你就可以自由发挥了。首先我们需要一个旧纸盒，这个旧纸盒可以是一个旧的快递纸盒，也可以是其他的包装纸盒，原则上就是希望它尽量地不要脏，要干净一点，毕竟它将来会摆在我们的桌子上面，所以呢不让它是一个脏的旧纸盒。还有我们需要一个旧瓶子，这个旧瓶子同样的，主要是一个脏的旧瓶子不行，毕竟我们将来可能会经常看到它，脏瓶子会很别扭的。还有就是我们希望尽量您选择的是磨砂材质的这种旧的塑料瓶子，它会比较有利于我们这个 LED 照明。

另外我建议您准备一根 USB 延长线，它的作用是来延长 Arduino 开发板的数据线的。通常我们的 Arduino 开发板的数据线都不是很长，那么当我们做好这个智能环保小夜灯以后，我们需要通过这个数据线给这个小夜灯来供电使用，所以这根线如果太短的话可能就不是很方便，所以我建议您也准备一根 USB 延长线。在我们这个小夜灯制作过程中将会有一些粘合粘贴的操作，我们是使用双面胶作为这个教程来粘合粘贴操作的工具，不过您也可以根据个人习惯选择其他的工具，比如说像热熔胶或者其他的工具都可以。

另外我们还需要一些绝缘胶带，请您注意，绝缘胶带并不是普通的胶带在外面起到绝缘作用的，它是绝缘胶带。还有我们需要一个小的尖嘴钳子，如果您没有尖嘴钳子的话，用别的钳子也能凑合替代，最好是准备一个尖嘴钳子会比较好操作。以及需要螺丝刀，这个螺丝刀将来是用来给我们这个盒子和瓶子开孔用的，所以首先我希望您能多准备粗粗细细的不同的几把；其次，如果您开孔有电钻一类的工具的话那更好了，不过考虑到我们这教程面向对象主要是初学者，我们的手里面可能没有那么多的工具来让我们使用，那在这种情况下我建议您可以使用螺丝刀来给盒子以及瓶子进行开孔，不过在操作的时候一定要小心，不要伤到手。最后我们还需要一把剪刀，这个相信我们家里面的人人都会有的，比较容易找到。

好，以上就是我们需要制作环保智能小夜灯所需要的所有的材料和工具了。那么这节课的内容到这里就结束了，下节课我们将以视频演示的形式给大家讲解如何来制作和组装这款环保智能小夜灯。好，这节课内容到这里就结束了，感谢您，我们下节课再见。

## 本节要点

- 环保智能小夜灯是对前面所学知识的总结，也是为下一个更复杂的制作（可编程控制 LED 光带 + 红外遥控智能家居照明灯）做热身。
- 三个特点：节能、环保、易用。节能体现在用光敏电阻感知环境亮度、用红外人体感应模块感知有没有人，只有「需要照明且有人」时才点亮。
- 环保体现在使用废弃材料制作，用过的饮料瓶和包装纸箱都可以作为制作材料。
- 材料清单：Arduino UNO R3 开发板、红外人体感应模块、5528 光敏电阻、10k 分压电阻、共阴极 RGB LED、三个 100～300 欧姆限流电阻、面包板。
- 连接材料：十个公对公杜邦线 + 十个公对母杜邦线（两种各十根左右）。
- 自由发挥的材料：一个干净的旧纸盒、一个磨砂材质的旧塑料瓶（如酸奶瓶）。
- 光敏电阻换型号时，分压电阻阻值和程序都要相应调整；RGB LED 换成别的类型，程序也要相应修改。
- 工具：USB 延长线、双面胶（或热熔胶等）、绝缘胶带、小尖嘴钳、粗细不同的螺丝刀（有电钻更好）、剪刀。
- 用螺丝刀开孔时一定要小心，不要伤到手。
