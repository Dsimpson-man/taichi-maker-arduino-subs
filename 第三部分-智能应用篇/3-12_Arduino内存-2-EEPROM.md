在上节课里，我给大家讲到 Arduino UNO 开发板，它的核心元件 ATmega328 微控制器里面的存储单元一共有三种存储介质。这三种存储介质由于各自的特点不同，所以它们发挥的功能也不一样。对于 Flash 闪存来说，因为它制作成本比较低，同时它的读写速度比较慢，所以我们用它来存储数量比较大的静态信息，比如像 Arduino 程序。那么与 Flash 相对应的 SRAM 静态随机存储器，由于它的制作成本要相对高得多，同时它的读写速度也要快得多，所以它经常被用来服务于数量比较小的动态信息，比如像是我们的程序变量。讲到这儿我要请您留意一点，Flash 闪存以及 SRAM 这两者，它们在 Arduino 的运行过程中所发挥的功能远远不止我所说的这些，如果真的要展开，把它们的全部功能给大家讲清楚的话，那这里面所涉及的软件还有硬件的基础知识就比较复杂了，同时也偏离了我们这套教程的主题，所以到这儿我就给大家点到为止。如果感兴趣的话，我建议您可以找一些其他的资料来了解一下。也就是说，在这儿我们只需要建立一个基本的印象：Flash 便宜、容量大、速度慢，适合存放不变的东西；SRAM 昂贵、容量小、速度快，适合存放会变化的东西。我们现在还是回到我们这套教程来，因为我们这节课主要讲解的内容就是 EEPROM 电可擦除可编程只读存储器，我们要一起来学习如何用 Arduino 向 EEPROM 写数据，以及如何从 EEPROM 里面读取数据。

## 本节要点

- Arduino UNO 的 ATmega328 微控制器有三种存储介质：Flash（32KB，存静态信息如程序代码）、SRAM（2KB，存动态信息如程序变量）、EEPROM（1KB，掉电不丢失）。
- EEPROM 的结构像信报箱，被分成 1024 个大小相同的小格子，每个格子有一个独立地址，每个地址可以存储一个字节；首地址是 0，末地址是 1023，而不是 1 和 1024。
- 一个字节是 8 位，可存放 0 到 255 之间的十进制数字，所以 EEPROM 一共可以存 1024 个 0 到 255 之间的整数；超过这个范围的数值（如 9999 或小数）需要借助 `EEPROM.put()` 和 `EEPROM.get()`。
- 使用 EEPROM 库需要在程序开头写 `#include <EEPROM.h>`，也可以通过「项目 → 加载库」让 IDE 自动添加。
- `EEPROM.write()` 用于写入：示例程序用 `addr` 变量记录地址编号，每写入一次就自加一，当 `addr` 等于 `EEPROM.length()` 时归零；`EEPROM.length()` 返回本开发板 EEPROM 的存储空间大小（UNO 返回 1024），使程序可以通用到不同开发板。
- 每次写完 EEPROM 要 `delay()` 等待几十毫秒，让 Arduino 有充足时间完成写入，否则程序运行会不稳定；官方示例用 100ms，讲者认为 10ms 已足够。
- `EEPROM.read()` 用于读取，其参数指明要读取的地址，读出的数值赋给 `value` 变量，再通过串口监视器显示地址和数值，从而验证写入是否正确。
- 实验演示：把 `value` 写成 123 再写入 EEPROM，读回时全为 123；改成 456 后读回变成 200，因为 456 超出 0 到 255，Arduino 用 456 减 256 得到 200。
- 编译简报中的两个数字 32256 和 2048 的来源：Flash 为 32KB，其中 0.5KB 用于系统引导，剩 31.5KB 即 32256 字节；SRAM 为 2KB 即 2048 字节。
- 标准库是预装在 Arduino IDE 中、无需单独安装即可使用的库（如 EEPROM、Servo），第三方库则需要额外安装；存储其他类型数据可参考网站上 `EEPROM.put()` 与 `EEPROM.get()` 的页面资料。
