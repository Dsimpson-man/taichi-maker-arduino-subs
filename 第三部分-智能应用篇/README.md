## 关于本字幕集

这是太极创客 Arduino 教程**第三部分**的完整字幕文稿，主线是**从"会编程"走向"做作品"**。

原视频共 **27 个分P，已全部整理交付**，总时长约 **8 小时 27 分钟**。

前两部分解决了"怎么写程序"和"怎么装机械臂"，这一部分开始讲**传感器怎么读、执行器怎么驱动、项目怎么从零搭起来**。教程用了整整一条主线——**智能小夜灯**——把传感器、电路连接、程序调试串成一个完整项目；后半段则深入 Arduino 的内存管理与红外遥控、WS2812 智能 LED、FastLED 库等实用主题。

**整理标准：**

- ✅ 去除口语语气词（"呢/啊/呃/那么"等）与口误重复
- ✅ 补充标点、按知识点与操作步骤分段
- ✅ 校正 Arduino 领域技术术语（`analogWrite()`、`EEPROM`、`IRremote`、`WS2812`、`FastLED` 等）
- ✅ 保留讲解者的教学语气与全部实质内容（正文信息保留率 ≥ 80%，本册实测 86%–97%）
- ✅ 每集附「本节要点」便于复习
