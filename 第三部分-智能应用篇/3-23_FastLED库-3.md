- 此前对颜色的使用一直局限于 `FastLED` 库预先设定好的一系列颜色名称，用它们来控制灯带产生心中想要的颜色不够用，让灯带做颜色变化也受到很大限制；本节课学习如何用 `FastLED` 库允许的方法自定义颜色。
- WS2812 灯珠归根到底是一系列 RGB 灯珠的封装，因此第一种自定义颜色的方法就是改变 RGB 的数值。
- 用 `CRGB` 建立自定义颜色，写法与建立 `leds` 灯带对象的方法类似，只是把后续字符串换成自定义颜色的名称，小括号中三个数字分别是红、绿、蓝的数值，并为便于使用给颜色命名（如 `myRGBColor`）。
- 示例中 `myRGBColor` 的 R 为 50、G 为 0、B 为 50，通过 `fill_solid` 把灯珠全部点亮为这个颜色，再调用 `FastLED.show()`，灯带呈现紫红色；`FastLED.show()` 非常关键，没有它灯带不会产生想要的色彩。
- 用点号可以直接访问和修改自定义颜色的分量，如让 `myRGBColor.r = 0`，颜色由 50、0、50 变为 0、0、50，再把 `.b` 也设为 0，颜色变为 0、0、0。
- RGB 三个数值全部为 0 时灯带上所有灯珠处于熄灭状态；配合把分量恢复为 50 并延时 500ms，就能实现自定义紫色「熄灭、闪烁」交替的效果。
- RGB 表达方法直观，可以直接修改红绿蓝各自的数值，但存在缺陷：要让灯珠产生颜色渐变效果时会很拘束，因此引入新的颜色表达方法 HSV。
- 用 `CHSV` 建立自定义颜色（如 `myHSVColor`），小括号中三个数值依次代表色调、饱和度、明亮度，与 RGB 三个数值的含义不同。
- 色调 H：可设想为一个彩色圆盘，颜色以渐变形式从红到黄到绿再回到红。`FastLED` 把 360 度等分成 256 份，原点 0 度对应数值 0，转满一周达到最大值 255 后回到 0。例如 H 为 42 大约是黄色，H 为 127 大约是蓝绿色。色调表达能产生非常光滑的渐变，这就是 HSV 相对 RGB 的优越性。
- 用 H 进行自加（每次 `loop` 加一）并把延时由 500ms 改为 50ms，可以让 `myHSVColor` 的色调从 0 一直增加到 255 再回到 0，从而让灯带颜色产生光滑的渐变效果。
- 饱和度 S：同一色调下颜色由饱和度为 0 时的白颜色逐渐过渡到饱和度为 255 时的本来颜色（本色）；让 S 自加即得到由白到本色的渐变效果。
- 明亮度 V：V 为 0 时整条光带处于熄灭状态，V 越大亮度越高，颜色色调保持不变；让 V 自加即可得到由暗到明、周而复始的变化。
- HSV 背后的理论较深，本课只做直观讲解，但这些内容用于控制灯带已经足够，感兴趣的学员可以通过其他渠道加深理解。
