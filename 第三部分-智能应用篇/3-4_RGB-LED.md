## 正文

LED 在我们身边会有很多种形式出现。比如这种一个一个独立出现的 LED 叫做 LED 灯珠；当我们把它们连在一起，就形成了 LED 灯带；这种把 LED 组合形成矩阵的电子元件叫做 LED 矩阵，很多 LED 屏幕都采用类似这种形式；LED 还会被固定在硬质板材上，那这种电子元件叫做灯板。我们家里边很多照明元件都是采用这种 LED 的形式。我们这系列教程的主要介绍对象是 LED 灯珠和 LED 灯带，原因是你可以把灯珠试想成我们画画时候的一个一个的点，那么灯带你可以把它设想成一条又一条的线段，那么有了点、有了线以后，我们就可以用 LED 勾画出丰富多彩的画面了。那么在这节课里面，我首先给大家主要介绍一下 LED 灯珠，具体来说就是 RGB LED。

为什么我们这节课要先讲 RGB LED 呢？因为我们在后面制作智能小夜灯、制作 LED 光带照明灯的时候，都要用到这颗灯珠，它可以说是我们后面所有制作的一个基础。所以这节课我会先把它的内部结构、引脚分布还有它的控制方法给大家讲清楚，等我们在后面做制作的时候，您再回过头来看就知道这节课的内容有多重要了。

请您看画面里这个 LED，估计您看它以后有一种似曾相识的感觉。以前我们给大家讲过 LED，它的学名叫做发光二极管，那么发光二极管它有两个极，一个正极一个负极。那么这个二极管好像有 1、2、3、4 四个引脚，那怎么这么多个引脚呢？答案其实就在 RGB LED 的名称里面。RGB 它是 red、green、blue 这三个单词的缩写，换句话说我们也可以管 LED 叫做红绿蓝 LED。叫它红绿蓝 LED 是因为它能够发出红色、绿色还有蓝色的光吗？这么说也对也不对。说得对是因为 RGB LED 确实能发出红色、绿色和蓝色的光；说的不对是因为 RGB LED 所发出光芒的颜色远远超过这三种颜色。他是怎么做到的呢？那么请您继续听我讲，相信您就能找到答案了。

首先我们来看看 RGB LED 它是如何构成的。在屏幕上现在您看到的画面可以当做 RGB LED 的一个进化过程。首先我们看左边这里，我们有三个 LED，分别是红的 R、绿的 G、蓝的 B，RGB 三个 LED。为了让这个电路更加简化一些，也为了让我们更容易控制 RGB LED，我们把这三个 LED 它们的负极把它们连在一起，形成一个公共的负极；同时我们再把这三个 LED、这三个灯珠放到同一个灯珠里面去，于是我们就形成了 RGB 这么一个 LED。这个就是为什么我们的 RGB LED 还有四个引脚，因为这四个引脚里面其中有一个是它们的公共负极，那么另外的三个是 RGB 三个 LED 它们各自的正极。而这个引脚代表的是红色的 LED 的正极，相应的 G、B 代表它们相应颜色的 LED 各自的正极。这一点我们从 RGB LED 的电路符号上面也能看出来，请看右下角这个电路符号就是 RGB LED 的电路符号了。那么我们可以看到这三个发光二极管它们的正极是独立的，但是它们的负极被连在一起了。

请注意，这种类型的 RGB LED 叫做共阴极 RGB LED，原因是这三个发光二极管它们的阴极都被连接在一起，它们有一个公共的阴极。那么同样的是不是有共阳极 RGB LED 呢？有的，不过我们这节课主要讲解的是共阴极 RGB LED。那么共阳极 RGB LED 同样的，只要把三个发光二极管它们的阳极有一个公共的连接在一起，那么它们阴极是独立的。另外我在刚才的描述中，我说发光二极管一会儿说是正极负极，一会儿说是阳极和阴极。那么请注意，正极就是阳极，负极就是阴极。换句话说，共阴极 RGB LED 也就是共负极的 RGB LED。好了，到这里关于 RGB LED 的基本结构我就给大家讲述结束了。

下面我给大家讲一讲如何用 Arduino 控制器来控制 RGB LED，而 RGB LED 它又为什么能够发出丰富多彩的颜色。接下来我还是用实验演示的形式给大家展示我们是如何用 Arduino 控制器来控制 RGB LED 的。首先我们先看看这个实验中的电路连接是怎么样的。首先请您看这里，这里就是我们这个电路的主角了，它就是 RGB LED，它一共有 1、2、3、4 四个引脚，其中最长的这个引脚就是它的共阴极了，那么这个共阴极我们是连接在了 Arduino 的接地这个引脚上。那么其他的这三个 RGB 这三个正极，我们是通过三个限流电阻连到了哪里呢？连到了 Arduino 控制器上的 6 号引脚、5 号引脚和 3 号引脚上。6 号控制的是红色，5 号引脚控制的是绿色，3 号引脚控制的是蓝色。我们还用了三个不同颜色的导线来向你展示，也就是说我们的 Arduino 控制器可以通过 6 号、5 号和 3 号引脚来控制我们的 RGB LED 它的颜色。

下面我给你介绍一下用 Arduino 控制器来控制 RGB LED 的示例程序。由于我们这一期智能应用篇的教程主要针对的对象是如何使用 Arduino 控制器来进行实际的制作和操作，那么编程已经不再是我们这期教程的重点了，所以我在讲解这个程序的时候不会像以前似的那么一点一点地掰开了揉碎了给您讲解，否则我们这课程的内容就太重、太繁琐了。同时那些已经掌握了 Arduino 编程的朋友可能会发现我的讲解会变得太絮叨、节奏太慢了。所以我从现在开始加快我们的程序讲解，我将只是主要介绍一下程序的主旨。如果您感觉听我这个讲解觉得有点吃力，那么可能您对 Arduino 编程的一些基础知识有一些欠缺，那么我建议您跟着我们零基础入门学用 Arduino 教程的第一部分基础知识篇，还有第二部分 Micro:bit 机械臂篇，跟着这两部分再仔细重温一下，然后再来跟着我们学习这部分的知识。关于我刚才提到这两部分教程的内容，您可以到我们太极创客的网站上面免费地获取到教程的视频以及相关的资料。

好了，我废话少说，让我们开始吧。首先我给大家介绍一下这个程序上传到 Arduino 以后，Arduino 将是如何来处理它的。我们可以通过 Arduino IDE 的串口监视器向 Arduino 控制器发送一条指令，那么这条指令的作用就可以把连接在 Arduino 上面的这个 RGB LED 它三个红色、绿色还有蓝色这三个 LED 的亮度调节到相应的数值上。那么具体是怎么实现的呢？请看好，我们这里有一个指令的示例，这个指令假设我们在 Arduino 控制器运行过程中，通过 Arduino IDE 输入 `r128 g100 b20` 这样一条指令，那么这个指令就会把连接到 Arduino 控制器上的这个 RGB LED 它三个 LED，也就是红色、绿色、蓝色这三个 LED 的亮度分别调节到：红色 LED 的亮度调节到 128，绿色调节到 100，蓝色调节到 20 这样的一个亮度状态。

下面我们就来看看我们是如何来实现这个功能的。请看，在程序的刚一开始我们建立了三个整数型常量，它们的存储内容就是 RGB LED 三个正极与 Arduino 控制器的引脚号码：红色 LED 引脚连接 Arduino 控制器的 6 号引脚，绿色 LED 的正极引脚连接 5 号引脚，蓝色 LED 的正极连接控制器上的 3 号引脚，这些和刚才您看到这个电路连接的介绍是相一致的。紧接着往下看，下面我们又建立了三个整数型变量，它们的作用是用来控制 RGB LED 这三个 LED 的亮度数值。请看 `ledR` 就是红色 LED 这个亮度数值，相应的 `ledG`、`ledB` 是控制绿色和蓝色的这两个 LED 的亮度数值。再往下面我们来看看这个程序的 `setup()` 函数，其实内容也非常简单，`setup()` 函数里面一共有六条语句，前三条语句的作用是用来设置这三个引脚为输出模式，然后启动串口通讯，接下来通过串口监视器输出一段欢迎性的文字，让我们知道我们这个程序已经启动成功了。

下面我们就进入到我们整个程序的 `loop()` 函数了。在 `loop()` 函数里面的 Arduino 控制器将不断地监测 Arduino IDE 里面有没有我们输入的指令，一旦发现我们通过串口监视器输入指令了，那么它将通过 `serialCommand` 这个函数来执行我们所输入的指令。同时我们让 Arduino 控制器在每运行完一次 `loop()` 函数以后都稍微地等一等，让这个程序的运行能够更加流畅稳定一些。接下来我们来看看 `serialCommand` 这个函数是如何来执行我们输给它的这个指令的。请看好，这里是 `serialCommand` 这个函数的开始，在这个函数里 Arduino 是通过 `switch` 这么一条语句来分析 RGB LED 控制指令，那么分析完这个指令以后，它将执行相应的操作。

那具体是如何操作的呢？我来给大家简单介绍一下。请大家回忆一下，在我们整个程序的一开始，我们有一个指令的示例，这个指令的内容是 `r128 g100 b20`，那么 Arduino 在接收到这个指令以后，它会把 R 这个字符后面的 128 这个数字通过这条指令赋值给 `ledR` 这个变量；相应地，G 这个字符后面的 100 这个数字也会通过这条指令赋值给 `ledG` 这个变量；那么同样的，B 这个字符后面的 20 也就赋值给 `ledB` 这个变量了。我也刚刚给大家介绍过，`ledR`、`ledG`、`ledB` 这三个变量的作用是用来控制连接在 Arduino 控制器上的这个 RGB LED 它所包含的这三个 LED 的亮度，`ledR` 控制红色的亮度，`ledG` 控制绿色的亮度，`ledB` 也就控制蓝色的亮度。

获取到这三个变量的数值以后，Arduino 将通过三条 `analogWrite()` 模拟输出语句，把 `ledR`、`ledG` 和 `ledB` 所存储的相应的亮度数值设置到相应的 LED 连接的引脚上，于是我们这个 RGB LED 也就会根据我们的要求进行相应的颜色的调节了。这里要注意的是，`analogWrite()` 输出的数值范围是 0 到 255，0 表示这个颜色完全关闭，255 表示这个颜色达到最大亮度，中间的值就对应中间级别的亮度，所以我们在串口监视器里面输入的数值不能超过 255，也不能是负数。另外还要给您提一下，就是在我们这个 `switch` 语句里面，我们还可以通过 C 这个字符将 RGB LED 里面的三个 LED，也就是红色、绿色、蓝色这三个 LED 全部都关闭。最后还有一点很关键，就是 Arduino 在每次执行完指令以后，都会把当前的 RGB LED 的三个 LED 亮度数值通过串口监视器输出出来，让我们能够更好地观察到当前的这三个 LED 它们各自的亮度以及它们这个亮度所呈现给我们的状态。

好了，关于这个程序的内容我要给大家讲解的就是这些了。接下来就请您看我们的实验演示，请您仔细观察，看看我们这个 RGB LED 是怎么被我们通过指令玩弄于股掌之中的。现在大家在屏幕上看到这个 Arduino 控制器，我们已经按照刚才我给大家讲述的这个电路连接的方式，把它和我们这个 RGB LED 通过三个限流电阻连接成功了。接下来我已经把刚刚给大家讲解的这段示例程序上传到 Arduino 里面了，那么接下来我就通过点击串口监视器这个按钮打开 Arduino IDE 的这个串口监视器。打开以后我们会看到在串口监视器里面显示了一段欢迎文字，这段欢迎文字告诉我们程序已经运行启动成功了。

我现在可以在串口监视器里面输入 RGB。首先我先试着单独地打开红色、绿色还有蓝色这个 LED。我先打开红色这个 LED，让这个 RGB LED 显示红色，我将输入什么指令呢？请看我首先输的指令是 `r255 g0 b0`。好，刚才给大家讲过，这条指令的绿色 G 是不打开，零；蓝色同样的也是零。好，接下来请看我回车，我们来注意观察一下屏幕里这个 LED 它的颜色。回车，很自然，这 LED 被我打开调成红颜色的了。那我现在再试试看能不能把它变成绿色的。我接下来再输入一个新的指令 `r0 g255 b0`。好，现在请看我这个红色的亮度是零，绿色我把它调到最大，蓝色同样的还是零。我回车，请看它是不是变绿了？果然是绿色的了。我估计你也猜到，接下来我要调成蓝色的话也非常简单，`r0 g0 b255`，回车，自然吧，这个 LED 现在变成蓝色的了。

实验做到这里，我不知道您会不会感到好奇，假如我们把两种颜色的 LED 同时打开会得到什么效果呢？比如说我们现在同时打开红色还有蓝色两种颜色的 LED，会使得到什么样的结果呢？我估计那些喜欢画画的朋友们可能已经猜到了，如果我们在画画的时候把两种不同的颜料，红色还有蓝色两种颜色的颜料把它混在一起，我们会得到什么样的颜色呢？是会得到紫色的颜色。那么对于 LED 是不是也这样的结果呢？我们试试看。现在呢我是在串口监视器里面输入新的指令，同时打开红色还有蓝色这两个 LED。我输入，首先输入的指令是 `r100`，红色调到 100 这么一个亮度；`g0`，绿色的 LED 保持关闭；`b100`。好，红色和蓝色都是调到 100 这么一个亮度。我注意 LED 的颜色变化，我将输入回车，你看现在这个 LED 它这个颜色就有点发紫的那个颜色了。我们其实是可以把这个 RGB LED 设想成一个调色盘，那么 RGB 分别对应的三个 LED，我们可以把它想成三种不同颜色的颜料，那当我们想要调出我们想要的光亮的色彩的时候，我们就可以通过调节 RGB 这三个 LED 各自的亮度，最终调和出我们想要的颜色。这就像我们在画画的时候，手里只有三种颜料，但是通过不同比例的调配，就能得到无穷多的色彩一样。是不是这样的？我们再做一个实验。下面我们同时打开红色还有绿色这两个 LED，保持蓝色这个 LED 把它关闭，红色绿色同时打开，你知道什么颜色吗？是黄色的。我们看是不是这样的。

好，首先我说 `r100` 把红色打开，G 我输入一个 10，不用太亮，B 我输一个零。好，这时候我们回车，请看现在您在屏幕上看到 LED 的颜色就是发黄色的这么一个颜色了。在刚才实验里我们看到，通过调和红色、绿色还有蓝色这三个 LED 的亮度，我们可以得到其他的颜色。比如红色、蓝色一起点亮我们得到紫色，红色、绿色 LED 一起点亮我们得到的是黄色。当我把蓝色和绿色这两个 LED 同时点亮的时候，我们得到这个颜色叫做蓝绿色，这个名字还挺好猜的，蓝绿色，一个是蓝色和绿色同时点亮的，有人管它叫青色。另外当我把红色、绿色还有蓝色这三种颜色的 LED 都点亮到最大亮度的时候，我们得到什么颜色呢？正是中间这个颜色——白色的。因此通过改变 RGB 的数值，我们可以组合出很丰富的颜色。请看屏幕上这个彩虹色，就是通过改变相应的数值所得到的。

我们在实验里还可以看到更多混合出来的颜色。比如说，除了红色和蓝色混合得到紫色、红色和绿色混合得到黄色以外，我们还可以把三种颜色的亮度做出各种不同的组合，比如让红色亮一点、蓝色暗一点，或者让绿色和蓝色都保持在一个中间值，这样就能得到浅紫、粉红、天蓝这一类过渡的颜色。另外我们还可以把三个 LED 都调到比较小的数值上，让这个 RGB LED 发出一种暗暗的、偏向白色的光，这就是中间那个颜色——白色；如果我们把三个数值从小到大均匀地变化，还可以看到这个 LED 缓慢地由暗变亮、再由亮变暗，这就是我们后面做智能小夜灯要用的一个效果。

另外，不知道您有没有想过这么一个问题，我们的 RGB LED 到底能显示出多少种颜色呢？我们知道通过 Arduino 控制器，我们可以把红色、绿色还有蓝色这三个 LED 分别做出 256 个级别的亮度调整，通过简单计算我们可以得到是 1677 万 7216 种不同的颜色，呵呵，还真不少。不过很遗憾地告诉您，这个只是一个理论数值，实际上我们的 Arduino 控制器还有我们的 RGB LED 是肯定做不到这么多种颜色的。不过也没有关系，因为我们人的眼睛能够识别出的颜色的种类也就 1000 万种颜色左右吧，而且我们不同的人识别颜色的能力也不一样。不过有一点是肯定的，就是 Arduino 控制器还有 RGB LED 肯定能够显示出足够丰富多彩的颜色，让我们能感受到它们的魅力。

还有就是有的朋友听说过真彩这个概念，比如说我们要买一个 LED 灯珠或者灯带，这时候商家会告诉我们，我们这个是真彩 LED，那么这个真彩的概念指的就是这个 1677 万 7216 这么一个概念。最后还有一点概念要跟您再强调一下，并不是那些能够发出绚丽多彩颜色的 LED 都是 RGB LED。比如您现在屏幕上看到的这些 LED，它们能发出的颜色很丰富多彩，但是让我们在看它的引脚的时候，我们看到它们都只有两个引脚，这些肯定不是 RGB LED。还有就是，并不是所有能够改变颜色的 LED 都是 RGB LED，我再说一遍，比如说我们在街上看到的那些丰富多彩的、能够改变颜色的那些 LED 光带也好，或者是屏幕上面的 LED，它们并不都是 RGB LED，而它们到底是什么类型的 LED，这部分内容我们在以后的课程会给大家介绍。那么这节课内容到这里就结束了，感谢您，我们下一节课再见。

## 本节要点

- LED 常见形式有 LED 灯珠、LED 灯带、LED 矩阵和灯板；本系列教程主要介绍灯珠和灯带，可把它们分别理解为画画时的「点」和「线段」。
- RGB LED 是把红、绿、蓝三个 LED 封装在同一个灯珠里，并把它们的负极连在一起形成公共负极，因此它有四个引脚（一个公共极 + 三个颜色正极）。
- 公共极为负极的叫做共阴极 RGB LED，公共极为正极的叫做共阳极 RGB LED；正极即阳极，负极即阴极。
- RGB LED 靠三个颜色 LED 的亮度比例混合出各种颜色，可以把它设想成一个调色盘：红+蓝得紫，红+绿得黄，蓝+绿得青，三色全亮得白。
- 控制引脚用 6 号、5 号、3 号，分别对应红、绿、蓝；不用 4 号引脚是因为它不是 PWM 引脚，而调光必须使用 PWM 引脚。
- 每个颜色引脚都要串接一个限流电阻，三个颜色各一个。
- 示例程序在串口监视器中输入形如 `r128 g100 b20` 的指令，由 `serialCommand` 函数用 `switch` 语句解析，再把数值赋给 `ledR`、`ledG`、`ledB` 三个变量。
- 程序用三条 `analogWrite()` 语句把三个亮度值输出到对应引脚；输入 `c` 可以把三个 LED 全部关闭；每次执行完指令都会把当前三个亮度值通过串口打印出来。
- 三个通道各 256 级亮度，理论上可组合出 1677 万 7216 种颜色，这就是「真彩」概念；理论值并不等于实际可显示值。
- 并非所有彩色 LED 都是 RGB LED——只有两个引脚的彩色 LED 就不是。
