为了方便大家理解，我们不妨把这段程序的核心代码写出来看一下：

```cpp
#include <ArduinoJson.h>

void setup() {
  Serial.begin(9600);

  const size_t capacity = JSON_OBJECT_SIZE(2) + 30;
  DynamicJsonDocument doc(capacity);

  String json = "{\"name\":\"taichi-maker\",\"number\":1}";
  deserializeJson(doc, json);

  String nameStr = doc["name"].as<String>();
  int numberInt = doc["number"].as<int>();

  Serial.println(nameStr);
  Serial.println(numberInt);
}

void loop() {}
```

## 本节要点

- JSON 的解析工作比较复杂，本课借助第三方库 `ArduinoJson` 来完成，该库虽是面向 Arduino 平台开发，但同样适用于 ESP8266。
- 使用该库前必须在程序开头写 `#include <ArduinoJson.h>`，并需要先在 IDE 中安装好这个第三方库。
- 解析前要建立一个解析对象（如 `doc`），建立时需提供 `capacity` 参数来指定所需的内存空间。
- `capacity` 的类型是 `size_t`，在 Arduino 与 ESP8266 平台上它相当于无符号长整型 `unsigned long`；这只是为了便于代码跨平台移植。
- `capacity` 的值由 ArduinoJson 官网的在线工具自动算出，规则是把 JSON 结构所需的内存大小再加上 30 的余量。
- `deserializeJson()` 负责把 JSON 字符串解析成对象结构，`serializeJson()` 则用于把对象结构序列化成 JSON 字符串。
- 通过 `doc["名称"]` 或 `doc[序号]["名称"]` 可以取出对应的值，再用 `as<String>()`、`as<int>()` 等函数转换成目标类型。
- 数组中元素靠序号访问，序号从 0 开始；对象中的名值对靠名称访问，没有序号。
- ArduinoJson 官网提供了一个在线工具（Assistant），粘贴 JSON 文本后即可自动生成 capacity 计算、解析和数据提取的完整代码。
- 自动生成的代码中，那些未被使用的常量指针可以删除，以便精简程序，但建立 `doc` 对象与解析的语句必须保留。
