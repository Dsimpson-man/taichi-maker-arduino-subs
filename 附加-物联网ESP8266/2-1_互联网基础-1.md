## 正文

大家好。从这节课开始，我们进入互联网基础知识的学习。在之前的课程中我给大家讲过，我们的物联网是在互联网的基础之上增加了更多可以联网的设备类型，因此学好互联网的基础知识是非常非常关键的。但因为我们这个教程是物联网教程，所以在这里我不可能把所有的互联网知识都讲得一清二楚，我们将比较有针对性地挑出相关内容来做讲解。

我们要学的第一个概念是互联网协议。互联网协议这个概念听起来挺抽象，互联网我们天天都在用，那这个协议长什么样子、写在哪儿了？好像没有见过。其实互联网协议这个概念非常简单，它就在你我的身边。

互联网协议是什么呢？我们知道，当我们在交流的时候，是用语言来进行沟通的。但是在互联网中的这些网络设备，它们之间互相交流的时候就不能用我们人类的语言了。那么为了让这些网络设备之间能够正确地进行通讯，它们就必须使用一种彼此都能够理解的「语言」。这种网络设备之间彼此能理解的通讯语言，我们称之为协议。那么自然而然，在互联网上所使用的这种通讯协议就是互联网协议了。

更确切地说，这个互联网协议的名称叫做 TCP/IP 协议。提起 TCP/IP 协议很多朋友都听说过，因为我们经常用互联网，这两个字也经常见到。到这里我想考一考您：您知道这个 TCP/IP 协议是由什么组成的吗？可能有朋友会说，我至少知道 TCP 协议是由 TCP 协议和 IP 协议共同组成的，这就叫 TCP/IP 协议了。如果您给我这样的答案，我只能说您答对了一部分，但是它远远不止这两种协议。

您现在在屏幕上看到的这个表格就是 TCP/IP 协议。其中请看，这里是 IP 协议，这里是 TCP 协议，没有问题。除了这两个以外还有很多其他的，有的我们见过，比如 HTTP，这个看起来眼熟；比如 Wi-Fi，这个太常见了；还有一些我们看起来有点陌生，比如 mDNS，这些都是什么东西呢？这些协议无论您看着眼熟还是比较陌生，它们都是 TCP/IP 协议中的一部分。换句话说，这个 TCP/IP 协议是由很多很多种不同的协议所组成的。

严格意义上来说，TCP/IP 协议不应该称作「一种协议」，而应该叫做「一个协议组」。不过尽管 TCP/IP 协议是一组协议的统称，我们很少会把这个「组」字带出来，通常就叫做 TCP/IP 协议。

我们接着看。为了进一步将这些协议加以区分，我们将这个 TCP/IP 协议分成了四层，不同的协议各具自己的功能和特点，它们分别属于各自的协议层中。比如说请看，这个 HTTP 协议，它是用来浏览网页的，它属于应用层；再比如说请看这里 Wi-Fi，这个 Wi-Fi 是负责网络的物理连接的。在接下来的课程中，我将结合 ESP8266 NodeMCU 开发板来分别讲解这些分层的基本知识。

首先我们来看看 TCP/IP 协议中最底层的这个链路层。链路层的主要作用是实现设备之间的物理连接，比如 Wi-Fi 等等等等。什么是物理连接？这听起来有点抽象，其实说起来很简单。比如我们的手机，我们说这个手机现在连上网了，通过什么联网？通过 Wi-Fi 联网了。那这时候我们就可以说，我们的手机通过 Wi-Fi 和互联网实现了物理连接。也就是说，这个 Wi-Fi 的作用就是实实在在地让我们的手机和互联网连起来，就这么简单。

具体到我们这个 ESP8266，它利用 Wi-Fi 联网的时候一共有三种工作模式。那这三种工作模式具体都是怎么样的呢？请您慢慢听我讲。

首先我跟你讲第一种工作模式，这种模式叫做接入点模式。接入点模式是什么样子呢？请您现在在脑海中脑补一下：是不是说我们的手机，还有我们联网用的电脑，可以通过 Wi-Fi 连上 ESP8266 呢？正是这样的。请看，在接入点模式下，我们这个 ESP8266 NodeMCU 开发板是可以向外界发送 Wi-Fi 信号的，那我们的手机或者电脑等等这些联网设备，就可以通过 ESP8266 所发射出来的这个 Wi-Fi 信号和它进行连接，从而实现设备之间的通讯功能。

那么在这种模式下请大家注意，ESP8266 这个开发板是可以建立起一个 Wi-Fi 网络的，这个 Wi-Fi 的名称也可以设置，还可以设置一个密码。那么其他设备可以通过查找这个空间中的 Wi-Fi，找到 ESP8266 所建立起来的这个 Wi-Fi 网络，然后就可以跟它互相连接了。这个就是接入点模式。这个比较好理解，我就不说太多了。

我们接下来看下一种模式，下一个模式叫无线终端模式。什么是无线终端模式？有点抽象。所谓无线终端，就是假设我们现在在家里面用手机要想联网，这时候我们手机是可以通过 Wi-Fi 路由器，把这个手机通过 Wi-Fi 连接上以后，然后手机就可以通过 Wi-Fi 联网了。那么在这种情况下，我们这个手机就是一个无线终端。同样，比如我们这个 ESP8266 NodeMCU 开发板，它也是和我们的手机一样，可以通过连接我们这个家里的 Wi-Fi 路由器，然后就可以实现和互联网的通讯了。这种模式下，我们这个开发板我们就说它是以无线终端模式来工作的。

那最后我们再来看第三种工作模式，这种模式叫做混合模式。所谓混合模式，正是刚才我说的两种模式相互混合在一起。也就是说，NodeMCU 它既可以用无线终端模式来连接到我们的 Wi-Fi，同样它自己还可以发射一个 Wi-Fi 网络，让我们其他的设备跟它进行连接。这两种模式混合在一起同时工作，这种模式就叫做混合模式了。

关于链路层，我们需要记好的内容就是这些了。由于链路层主要涉及的是网络的物理连接，具体的实现以及相关知识已经超越了我们这个教程的范围，所以感兴趣的朋友可以在网上找一找相关的资源。到这里请注意一点，对于 ESP8266 来说，它有三种工作模式，也就是刚刚介绍的这三种模式。

我们继续往下看。刚才我给您介绍的是链路层方面的基础知识，接下来我们来看链路层上面这一层，也就是网络层，就是我们这个 IP 协议了。听起来很耳熟，那接下来我给你介绍一下关于这个 IP 协议的相关知识。

相信很多朋友都听说过「IP 地址」这么一个名词。为什么 IP 后面要增加一个「地址」这么一个名词呢？正是因为 IP 协议的主要功能就是为网络设备提供地址功能。我们知道，互联网最主要的功能就是实现信息传输，这些在互联网上所传输的信息要在我们这些设备之间进行互相传输。

我们在发送一个快递的时候，要写明收件人是谁，另外我们还要写明发件人是谁，这些信息都非常重要。这个信息里面就提供了我们作为发件人的地址以及收件人的地址。同样的，这个发送的地址是什么，以及是谁来接收的、这个接收的地址是什么，那么发送和接收的地址使用的是什么地址呢？就是这个 IP 地址了。这也就是 IP 协议它最主要的功能，它是为我们网络设备提供地址功能的。

IP 地址协议有两个版本。一种是 IPv4，这个 IPv4 是由四个十进制数字所组成的，每个十进制数字都是在 0 到 255 之间，这四个数字由小数点来进行分隔。另外还有一种 IP 地址协议，它的名字叫 IPv6，这个 IPv6 是由八组十六进制数字所组成的。IPv6 是 IPv4 的升级版本，为什么说是升级版本呢？因为 IPv6 可以为更多的网络设备提供地址。不过在本教程中，我们将着重讲解 IPv4，原因是 IPv4 是当今网络世界里面比较流行、比较通用的 IP 协议版本，所以我们在本教程中将着重讲解 IPv4。

为了便于大家更好地理解 IP 协议，我们看一个例子。假设我们有一个好朋友，这个好朋友他就叫李雷吧。那么在李雷家，它一共有三台网络设备，分别是什么呢？一台电脑、一个手机，还有一个是 ESP8266 NodeMCU 开发板。这三台设备都通过 Wi-Fi 连到了，请看这里，我鼠标所指的地方，这个就是我们的 Wi-Fi 路由器。

这三台设备当它们都连接到这个路由器以后，这个时候请注意，重要的地方来了：这个 Wi-Fi 路由器会为我们这三个网络设备分配一个 IP 地址。请看，在我们这个图中给大家标出来了：对我们这个 NodeMCU 开发板来说，它的 IP 地址是 `192.168.0.2`；手机呢，是 `192.168.0.3`；那电脑呢，是最后一位为 4，也就是 `192.168.0.4`。

那么这三个网络设备它们的 IP 地址有一个特点，我刚才跟大家说了，它们的地址是互不相同的。请看，这个开发板它的 IP 地址最后一位是 2，虽然前面都是 `192.168.0.` 这几个都相同，但是它们最后一位分别是 2、3、4，是不同的。为什么要让它们不同呢？这个很好理解，就好像我们现在要发快递一样，我们发快递的时候要填写地址，比如这个收件人他是北京市中华大街 1 号，那么全世界只有一个北京市中华大街 1 号，这个时候快递才能够得以正确地投放。那么同样的，对于我们这个 IP 世界来说，这样才能确保数据可以正确地发送，也可以正确地接收。

比如说，发给谁呢？发给我们这个 Wi-Fi 局域网里面的这个 NodeMCU 开发板。请注意，我一直在强调这个 Wi-Fi 局域网，是在强调这个局域网的概念，这是有原因的，后面我给大家讲。好，我们还是言归正传。刚才我说了，要给 NodeMCU 发送数据，这个时候它必须要怎么做呢？必须要知道哪一个 IP 地址。我们知道 NodeMCU 开发板的 IP 地址是 `192.168.0.2`，加上这个 IP 地址 `192.168.0.2`，有了这个 IP 地址以后，然后手机才能够把这个数据正确地投递给 NodeMCU。

说了这么多，我不知道有没有朋友会感到有点好奇：您在听课的这个网络设备如果是一台电脑的话，那么这台电脑它在局域网里面的 IP 地址是什么呢？怎么来查呢？接下来我来给您演示一下如何来查这台电脑在局域网里面的 IP 地址。请注意，我一直在强调局域网这个概念，这是有目的的。

请看我接下来的演示。假如您用的是一台 Windows 电脑的话，那请您跟我一起打开 Windows 电脑的这个「命令提示符」这个工具，并且在这个命令提示符中输入，请注意，`ipconfig` 这么一条指令，然后按下回车。好，这时我们可以看到屏幕中提示出了很多的相关信息，这些信息都是我们这台电脑的一些网络方面的信息。其中请看，我高亮的部分，这里所显示出来的正是「无线局域网适配器」。注意，这里又出现了局域网这个概念，这很重要。那么这里所出现的就是无线局域网适配器 Wi-Fi 相关的信息，其中请看，这里是提到了 IPv4 地址，这些都是我刚刚给大家讲过的。

好，这个地址是什么呢？`192.168.0.111`。那这称为什么呢？说明我现在给您讲课的这台电脑，它在当前这个无线局域网中的 IP 地址就是这个地址了。除了这个地址以外，请看，我们这里还有两行，这两个信息中，其中「子网掩码」这个信息很关键，还有一个请看「默认网关」，这两个信息都很重要。

其中，我先给大家讲讲默认网关是什么。这个默认网关，请看它的地址是 `192.168.0.1`，跟刚才这个 IPv4 地址非常接近，唯一的区别就是我们电脑是 111，而这个默认网关是 1。这个默认网关是什么东西呢？下面我给你讲一讲这个网关的概念。

请看，这个呢是刚才我给您讲解的示意图。我们刚才说了，我们现在这个局域网中有三台设备，这三台设备通过 Wi-Fi 连到什么上面了呢？连到我们这个 Wi-Fi 路由器上。那么这个 Wi-Fi 路由器正是我们这个局域网里面的网关。那么刚才我们在这个命令提示符中所看到的这个默认网关，也就是 `192.168.0.1`，它所指的是哪一个设备呢？它所指的正是我刚才跟大家说的这个 Wi-Fi 路由器。换句话说，我们这个 Wi-Fi 路由器它这个 IP 地址自然就是 `192.168.0.1` 了。

说了这么多，好多朋友就有点迷惑了：你说了这么半天，网关到底是什么东西？我再给你举个例子。比如我们明天要坐飞机出国了，这时候我们要带好什么呢？我们要带好护照。为什么要带护照呢？因为我们在出国的时候要经过海关，在海关的时候就会有人来查验我们的护照。这海关是什么呢？它是连接国与国之间的关口。回过头来我们再看这个网关，网关的概念就是连接网络与网络之间的关口。

在这节课中我强调了很多次，我们现在所需要的这个例子一直都是限制在一个局域网的概念中，也就是说是这个 Wi-Fi 路由器所建立起来的一个局域网。那么到现在为止，我们这个局域网还没有连接互联网，自然而然，我们这个 Wi-Fi 所建立起的局域网中这些设备是没办法和互联网连接的。如果要让这些设备能够和互联网连接的话，这时候怎么做呢？

我刚才说了，我们这个例子中的是李雷家的 Wi-Fi 路由器。假如这个李雷使用的是中国联通的互联网服务，那这个时候我们需要把这个 Wi-Fi 路由器和中国联通的服务器联系在一起，那么中国联通服务器是和互联网连接在一起的。通过这一系列的操作，我们这个 Wi-Fi 才能连到了互联网上。这就是为什么，请看我们的重点来了：这个 Wi-Fi 路由器为什么叫做网关？它是连接我们这个李雷家里的局域网和互联网之间的这个关口，因此这个路由器就是一个网关。

讲到这儿，我给你出个思考题。刚才说了，我们这个 Wi-Fi 路由器所建立的这个局域网会为每一个局域网上的设备分配 IP 地址，同时路由器它本身自己也有一个 IP 地址，没有重复的。那么问题就来了：相对于互联网来说，我们现在这个局域网里有这些 IP 地址，相对于互联网来说是不是还是同样的这几个地址呢？也就是说，请看，我们现在手机通过路由器一直连接到了互联网上，那么我们的这个手机是不是在互联网上它的 IP 地址就是 `192.168.0.3` 呢？是不是这样的？请你思考一下，是不是这样的？

当然不是了。这就是为什么我从这节课反复强调我们这些 IP 地址都是局域网中的 IP 地址。当我们这些设备通过网关连接到了互联网上的时候，这时候中国联通的服务器会为我们这个网关分配一个 IP 地址，那么这个 IP 地址和我们 Wi-Fi 路由器它本身自己建立的这个局域网的这个 IP 地址是不同的，一个是相对于中国联通服务器来说的，另外一个是在我们这个局域网中我们这个网关它本身有一个 IP 地址。

我讲到这里要给你强调一点：实际我们路由器连接到互联网这个流程，比现在我举的这个例子要复杂得多得多。可能我们这个路由器还要经过好几层的服务器才能够连接到互联网上，所以路由器上它相对于互联网来说，它的 IP 地址是什么，可能没有这么简单。不过在这里我想让你记住一点：对于我们路由器来说，它是可以建立起一个局域网，局域网里面每个设备都有各自的 IP 地址；而除了局域网以外，来到了互联网以后，在互联网上也分布着很多很多各种各样的服务器。

比如说，我们太极创客的网站，它有一个服务器，这个网站服务器它在互联网上的 IP 地址，假设它是 `11.66.88.88`。注意，我在这里强调，我们这个太极创客网站服务器在互联网上的 IP 地址是这个。假设现在李雷想要访问太极创客的网站，那么他打开电脑，通过电脑这个浏览器想要去浏览我们太极创客网站的这个首页。这个时候，这个浏览器将要向这个网站的服务器发送一个请求，这个请求的作用就是请求打开这个网站服务器的一个首页的请求。

那么这个请求它具体是一个什么样的东西呢？要想通过互联网发送到我们这个太极创客网站的话，要怎么做呢？首先，我们要知道我们这个太极创客网站的服务器的 IP 地址。有了这个 IP 地址以后，这个请求首先是发送到他家里的局域网的这个网关上，这个网关能看到 IP 地址，于是把它发送到互联网上，最终得以投递到我们太极创客网站的服务器上去。那么在我刚才描述的这整个过程中，正是因为有了 IP 地址，才得以从李雷家的这个电脑中把请求发送到太极创客网站的服务器上。以上就是关于这个 IP 协议以及 IP 地址的相关介绍知识了。

那么这节课到这里，我不知道大家有没有印象，刚才我曾经给您提过有一个叫做「子网掩码」这么一个概念。那么这个子网掩码是干什么用的呢？我们再来看一下上面这个例子。在这个例子中请看，我们这个局域网中所有的网络设备，它们的 IP 地址前三个数字都是相同的，都是 `192.168.0`。为什么它们是相同的呢？正是因为它们都属于同一个子网。而这个子网掩码正是用来限制 IP 地址中哪些是属于子网地址，而哪些是属于它这个设备本身独有的地址。

不过这个子网掩码这个概念和我们这套教程之间没有特别直接的关联，可是这个概念相对来说还是挺重要的一个知识。如果您想了解这个子网掩码具体是如何工作的，您可以来我们太极创客的网站，在我们太极创客网站关于「零基础入门学用物联网」这个教程的目录页面中，请看，在这个目录页面中有一个链接是专门进入这个 ESP8266 互联网基础知识的这么一个链接。进入这个链接以后，请看，在 2-3 这个网络层，我们进入这个页面，在这个页面中很多是我刚刚给大家介绍过的这些知识的文字说明。有这些文字说明是为了便于大家把这个知识作为参考来使用，而不是每次都来看视频。

刚才在我拉动页面的时候我们可以看到，在这一页中有专门这么一部分是讲述这个子网掩码这个知识的。如果您感兴趣的话，可以到这个页面里来看看这子网掩码是如何来发挥作用的。

那么这节课的内容到这里先告一段落，我们下一节课继续讲解有关 TCP/IP 协议，也就是互联网协议方面的相关知识。这节课内容到这里结束了，我们下一节课再见。

## 本节要点

- 物联网建立在互联网基础上，所以必须先学好互联网基础知识
- 协议是网络设备之间彼此都能理解的「通讯语言」，互联网上使用的就是互联网协议
- 互联网协议的名称是 TCP/IP 协议，它不是一种协议，而是一个协议组
- 常见的 TCP/IP 协议成员：IP、TCP、HTTP、Wi-Fi、mDNS 等
- TCP/IP 协议分为四层，如 HTTP 属于应用层、Wi-Fi 属于链路层
- 链路层的作用是实现设备之间的物理连接，Wi-Fi 就是让设备真正连上网的手段
- ESP8266 的 Wi-Fi 有三种工作模式：接入点模式、无线终端模式、混合模式
- 接入点模式下开发板自己发出 Wi-Fi 信号，供手机、电脑连接；可设置网络名称和密码
- 无线终端模式下开发板像手机一样去连接家里的 Wi-Fi 路由器，从而接入互联网
- 混合模式即同时具备上述两种模式的能力
- 网络层的核心是 IP 协议，IP 协议的主要功能是为网络设备提供地址功能
- IP 地址分 IPv4（四组 0～255 的十进制数字）和 IPv6（八组十六进制数字），本教程重点讲解 IPv4
- 同一局域网内各设备的 IP 地址不能重复，否则数据无法正确投递
- 在 Windows 命令提示符中输入 `ipconfig` 可以查看本机的 IPv4 地址、子网掩码和默认网关
- 网关是连接网络与网络之间的关口，家庭中的 Wi-Fi 路由器就是局域网的网关
- 局域网内的 IP 地址（如 `192.168.0.x`）不能直接用于互联网，接入互联网时由运营商另行分配地址
- 子网掩码用于界定 IP 地址中哪部分是子网地址、哪部分是设备自身地址，可作为扩展知识了解
