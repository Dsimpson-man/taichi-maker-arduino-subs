```cpp
void sayHi() {
  count++;
  Serial.print("Hi ");
  Serial.println(count);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  ticker.attach(1, sayHi);     // 每隔 1 秒调用一次 sayHi

void loop() {
  // 产生呼吸灯效果
  for (int i = 0; i <= 255; i += 5) { analogWrite(LED_BUILTIN, i); delay(10); }
  for (int i = 255; i >= 0; i -= 5) { analogWrite(LED_BUILTIN, i); delay(10); }
  delay(3000);
}
```

## 本节要点

- ESP8266 默认是「一条线式」的顺序执行：`setup()` 与 `loop()` 中的语句一条接一条跑完，完成一个任务才能执行下一个任务，无法真正并行。
- 多任务处理的含义：在执行某个任务的过程中还能响应其他任务，例如一边控制电机一边检测按钮是否被按下。
- `Ticker` 库是 ESP8266 内置的定时任务小助手，**不需要额外安装**，直接 `#include <Ticker.h>` 即可使用。
- 核心用法：先建立 `Ticker` 对象，再用 `ticker.attach(秒数, 函数名)` 让它每隔若干秒调用一次指定函数，函数由库自动定时调用，不用写在 `loop()` 里。
- `ticker.detach()` 用于停止定时调用，让 `attach` 失效；常配合计数变量使用，实现「只执行有限次数」。
- `attach()` 的参数单位是**秒**，`attach_ms()` 的参数单位是**毫秒**；两者除了时间单位不同，用法完全一致。
- 可以建立多个 `Ticker` 对象让 ESP8266 同时处理多个任务，例如一个控制 LED、一个每 100 ms 检测按键。
- `attach()` 最多只能向被调用函数传递**一个**参数，且类型只能是字符串、`short`、`int`、`float`、`void *` 或 `char *` 之一。
- 最重要的一点：`Ticker` 所调用的函数必须非常短小、能极快执行完，只适合做自加、串口输出、简单逻辑判断这类操作。
- 需要定时执行复杂操作（如发送 HTTP 请求）时，正确做法是让 `Ticker` 只做计数，在 `loop()` 中判断计数值到达阈值后再调用复杂函数，然后清零计数；把复杂函数直接放进 `Ticker` 回调里是无法正常工作的。
