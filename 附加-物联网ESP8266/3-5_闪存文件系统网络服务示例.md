## 本节要点

- 闪存文件系统不仅能通过程序控制文件、通过 Arduino IDE 上传文件，还可以用来搭建功能更丰富的网络服务器。
- 网页按钮与开发板函数之间的关联，是通过 HTML 中的 `form` 标签的 `action` 属性来实现的：`action` 指向的路径触发服务器端对应的处理函数。
- 服务端通过 `server.on("/ledControl", handleLEDControl)` 注册请求处理函数，其他所有请求由 `handleNotFound` 中的 `handleUserRequest` 统一兜底处理。
- 三目运算符 `ledStatus ? digitalWrite(LED_BUILTIN, LOW) : digitalWrite(LED_BUILTIN, HIGH)` 可以替代 `if...else`，一行语句完成引脚电平翻转。
- `server.send(303, ...)` 返回重定向状态码，让浏览器跳转回 `led.html` 页面，这就是每次按键后网页会整体刷新的原因。
- 程序中的请求路径带斜杠（如 `/ledControl`）代表根目录下的请求，HTML 中可不写斜杠，两者等价。
- 控制 PWM 使用 `esp8266Server.arg("ledPWM")` 读取浏览器地址栏问号后面的参数，返回值是字符串，需要用 `.toInt()` 转换成整数才能赋值给引脚。
- ESP8266 的 PWM 数值范围是 0～1023，而 Arduino 是 0～254，两者有区别。
- 带 `(AJAX)` 前缀的示例通过局部刷新页面来实时显示引脚状态，避免整页刷新造成的闪动；带 `(JavaScript)` 前缀的示例用图形界面（圆环、指针表）控制 PWM 或显示 A0 模拟读数。
- 指针表把 A0 的 0～1023 读数用 `map` 函数映射到 0～100，使显示更直观；示例程序还支持通过网页把文件直接上传到 ESP8266 的闪存文件系统。
