## 关于本字幕集

这是太极创客「零基础入门学用物联网」教程**基础知识篇**的完整字幕文稿，主线是**用 ESP8266 NodeMCU 开发板打通「联网」这一步**。

原视频共 **23 个分P，已全部整理交付**，总时长约 **14 小时 11 分钟**。

如果说四个 Arduino 部分教会你如何让硬件「动起来」，那么这个系列教会你如何让硬件「连起来」——从网线背后的 TCP/IP 协议讲起，一路走到 ESP8266 自建网络服务器、用 JSON 与远程 API 交换数据，最后收在配网、多任务与 OTA 升级这些实战技巧上。

**整理标准：**

- ✅ 去除口语语气词（"呢/啊/呃/那么"等）与口误重复
- ✅ 补充标点、按知识点与操作步骤分段
- ✅ 校正 ESP8266 / 物联网领域技术术语（`ESP8266`、`NodeMCU`、`WiFiClient`、`ESP8266WebServer`、`SPIFFS`、`ArduinoJson`、`OTA` 等）
- ✅ 保留讲解者的教学语气与全部实质内容（正文信息保留率 ≥ 80%，本册实测 85%–96%）
- ✅ 每集附「本节要点」便于复习
