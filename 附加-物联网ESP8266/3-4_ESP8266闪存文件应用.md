## 本节要点

- 上节课用程序操作文件系统的方法只能方便地处理文本文件；要让网页服务器显示图片、样式表、脚本等非文本资源，必须把电脑中的任意文件上传到闪存文件系统。
- 准备工作：安装闪存文件插件 `ESP8266FS`（可从 Arduino 官方 GitHub 或太极创客网站下载，示例版本为 0.5.0，新版本通常向下兼容）。
- 插件安装路径很关键：在「文件」→「首选项」中确认项目文件夹位置，在该项目文件夹下新建 `tools` 目录，把解压后的 `ESP8266FS` 文件夹放入其中（即 `tools/ESP8266FS/tools` 这一层结构），然后重启 Arduino IDE。
- 重启后「工具」菜单中会出现 `ESP8266 Sketch Data Upload` 选项，用它可以把工程目录下 `data` 文件夹中的所有文件一次性上传到开发板闪存文件系统的根目录。
- 上传 `data` 前必须在「工具」菜单中把 Flash Size 设为 `FS: 1MB` 或更大；如果选成 `None`，上传一定会失败。选择容量的依据是 `data` 文件夹的总大小（示例工程只有 54K，一兆已足够）。
- `data` 目录的组织方式：`index.html` 作为网站首页，`main.css` 定义字体、大小、颜色等样式，`clock.js` 与 `javascript.js` 实现页面上的日期与时间，`img` 目录存放图片资源。
- 用 `onNotFound(handleUserRequest)` 通吃所有请求：程序里不写任何 `on` 函数时，所有请求（无论能否匹配资源）都交给 `handleUserRequest` 处理，这是一种更通用、可当模板使用的写法。
- 请求资源的概念：浏览器请求的每一个文件（首页、CSS、JS、图片）都是服务器上的一个资源，可以通过 `server.uri()` 取得请求的资源名称，并用串口监视器输出以便调试观察。
- `handleFileRead` 的两个作用：判断能否在闪存文件系统中找到请求的资源（返回布尔值），找到则建立 `File` 对象读取并把资源发送给浏览器。请求根路径 `/` 时要特殊处理，把它转换为 `/index.html` 才能对应到实际文件。
- 用 `server.streamFile(file, contentType)` 把文件内容发送给浏览器，两个参数分别是文件对象和内容类型；发送完成后调用 `file.close()` 关闭文件。
- `getContentType` 通过判断请求文件名的扩展名返回对应的内容类型：`.html` 返回 `text/html`、`.css` 返回文本类型、`.jpg` 返回 `image/jpeg`，都不匹配时返回普通文本类型；这样浏览器才能正确解析和显示不同类型的资源。
