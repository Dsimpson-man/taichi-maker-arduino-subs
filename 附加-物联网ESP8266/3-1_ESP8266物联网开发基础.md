大家好。在之前的课程中，我们已经学习了 NodeMCU 开发板的基础知识，以及互联网相关的基础知识。从这一节课开始，我们就要进入实际动手操作的阶段，正式开始使用 ESP8266 这块芯片来做开发了。这一节课我主要讲解在开发 NodeMCU 开发板之前需要做的准备工作，具体来说包括两件事：第一，为我们的电脑安装 NodeMCU 开发板的驱动程序；第二，为 Arduino IDE 做相应的设置，让我们可以通过 Arduino IDE 为 NodeMCU 烧写程序。

先来介绍如何为电脑安装开发板的驱动程序。相信很多朋友都安装过电脑驱动，这个工作的第一步自然是要先把驱动程序下载到我们的电脑里。那么从哪里下载呢？可以通过我们太极创客网站的首页，那里有一个「下载」链接。我们点击这个下载链接进入下载页面，在这个页面里面有很多关于 Arduino 或者是 NodeMCU 开发板等等相关的下载资源。请看页面的上方，这里有一个「NodeMCU ESP8266 驱动下载」，我们点击这个链接。

点击以后，页面会带我们到驱动的下载位置。在这个位置我们可以看到两个操作系统的下载链接，您点击与自己电脑操作系统对应的那个链接就可以了。我现在使用的是 Windows 操作系统，所以我点击这里。现在我们进入的这个页面，是 Silicon Labs 公司 CP210x 芯片的驱动下载页面。可能有的朋友还不知道 CP210x 是什么，这里先解释一下：CP210x 是一颗芯片，它被安装在我们这块 NodeMCU 开发板上，它的功能就是负责实现开发板和电脑之间的数据通讯。我们现在要为这颗芯片安装驱动程序，安装好之后，我们才能在电脑上和开发板之间实现数据通讯。

我们继续往下看。在页面下方您可以找到很多不同版本的驱动程序下载链接，您可以根据自己电脑的版本下载相应的驱动程序。我使用的是 Windows 10 操作系统，那么我就点击这里，下载专门用于 Windows 10 的驱动程序。现在这个文件已经开始下载了。

文件下载完成以后，我们打开这个文件的下载路径。在这里可以看到我们刚刚下载的程序，名称是 CP210x Universal Windows Driver，我们来打开这个 zip 压缩文件。打开压缩文件以后，我们可以进入它的目录，在目录里面可以看到有两个可执行文件，这两个文件就是我们要安装的程序了。那么这两个文件有什么区别呢？首先，以 `x64` 结尾的这个文件是给 64 位操作系统用的，而以 `x86` 结尾的这个文件是针对 32 位操作系统的安装文件。您可以根据自己的操作系统具体是 64 位还是 32 位，来选择相应的安装程序。

安装方法比较简单，双击它执行这个可执行程序，然后在安装向导中一路点击「下一步」。在最后的页面中，只要显示了这个 Silicon Labs 开头的驱动程序后面显示「可以使用了」，就说明您已经成功地安装了这个驱动程序，点击「完成」结束安装。

在这里，我们顺便回顾一下前面讲过的端口这个概念。所谓端口，在这里指的是电脑和开发板之间进行串行通讯的通道编号。当我们的电脑上同时插了不止一块串口设备的时候，设备管理器里就会出现好几个 `COM` 端口，这个时候就需要我们自己去分辨，哪一个才是我们这块 NodeMCU 开发板。分辨的办法很简单，把开发板的 USB 线拔掉，看看设备管理器里的哪一个端口消失了，那个端口就是它；再插上，端口又出现了，那就更加确定了。连接好开发板以后，请回到我们的资源管理器。这里是「此电脑」，刚才我们曾经右键点击它来查看电脑的操作系统是多少位的，现在我们再次右键点击它，同样还是选择「属性」。在这个弹出的页面中，请看左上角这里有一个「设备管理器」，我们点击它。

接下来弹出的对话框中，我们要找一项叫做「端口（COM 和 LPT）」。在这一项前面有一个小小的箭头，我们点击这个小箭头把它展开。展开以后我们可以看到这里多出了一条新的信息，这条信息是 Silicon Labs 开头，后面括号中请注意，这里显示的是 `COM3`，这个信息很重要。当您可以看到这条信息以后，说明您已经真真正正地成功安装好了开发板的驱动程序了。

假如您没有办法在这里看到和我这里一样的信息，那么我来帮您找找问题的原因。首先第一条，您一定要确认您的开发板和电脑已经用数据线非常牢固地连接好了，如果没有连接好，这里是不会显示这条信息的。第二点，您要确定您手中的这块开发板的确是通过 CP210x 这颗芯片来实现开发板和电脑之间通讯的。我这么说是因为 NodeMCU 有很多个版本，其中有的版本使用的并不是 CP210x，那就不会出现在这里。所以您一定要确认您手中的这块开发板上面装配的是 CP210x 这颗芯片，是通过这颗芯片来实现电脑和开发板之间通讯的。

可能有的朋友会说：我怎么知道我这个开发板上面用的通讯芯片到底是不是 CP210x 呢？这一点您可以通过我们太极创客网站的下载页面中找到相关的说明来核对。完成了以上准备工作以后，接下来我们就要开始对 Arduino IDE 进行一些设置了，这样我们就可以通过 Arduino IDE 来为 NodeMCU 上传程序了。

好了，现在我这里已经安装完成了。怎么判断已经安装完成了呢？请看这里右上角，2.6.3 这个版本号后面写着 `INSTALLED`，这就说明我们已经把开发板管理器中 ESP8266 相关的扩展程序安装好了。接下来我可以关闭这个对话框了。

作为一款物联网开发板，这块 ESP8266 NodeMCU 开发板自然是可以联网的。下面我来给大家介绍如何实现这个开发板的联网功能。首先我给大家介绍的是 NodeMCU 开发板的接入点工作模式。下面我来点击鼠标所指的「NodeMCU 开发板接入点模式」这个链接，进入接入点模式的介绍页面。我们一点一点来看。首先我们来看一下接入点模式是什么。在之前的课程中我给大家介绍过，所谓接入点模式，就是 NodeMCU 可以建立一个 WiFi 网络，供其他设备连接，也就是大家在图中所看到的这个样子。

那么具体如何让 NodeMCU 实现接入点模式呢？是通过下面这段示例程序。下面我把这段示例程序复制并且粘贴到我们的 Arduino IDE 中。好了，程序已经成功地复制粘贴到我们的 IDE 中了。我们先来看看这段程序的基本介绍内容。这个程序是用来演示如何将 NodeMCU 以接入点模式来工作，通过这个程序，您可以使用电脑或者手机来连接 NodeMCU 所建立的 WiFi 网络。这个 WiFi 网络的名称是 `taichi-maker`，就是太极创客名称的英文写法；密码是 `12345678`。

下面我们把这段程序编译并且上传给我们的 NodeMCU 开发板，我们来看看这个程序控制开发板所工作的状态。为了节省时间，我先把这个录制暂停一下，一会儿成功完成上传以后我再切换回来。好了，现在程序已经成功上传给 NodeMCU 了。下面我们来尝试用电脑连接一下 NodeMCU 所建立的这个 WiFi 网络。实现这个功能和平常我们用电脑连接 WiFi 是一样的，我们点击 WiFi 连接的设置地方，找到 NodeMCU 所建立的这个 WiFi 网络，就是这个 `taichi-maker` 这个 WiFi，我们勾选自动连接，然后点击连接。这时候电脑让我输入密码，我刚才说了，是 `12345678`，这个是在程序的注释中已经说明了的。点击下一步，允许其他设备发现，好，稍等片刻，我们的电脑正在尝试连接到 NodeMCU 所建立的 WiFi 网络。

请注意，这个 WiFi 是我们的 NodeMCU 自己建立出来的，所以它本身是没有任何互联网服务的，这很正常，因为 NodeMCU 本身只是一块小小的开发板，它并不提供互联网服务。现在我的电脑已经可以看到连接到 `taichi-maker` 这个 WiFi 网络了，也就是 NodeMCU 所建立的 WiFi 网络了。同时呢，电脑提示我说这个网络是没有 Internet 服务的，也就是没有互联网服务，这很正常，没有关系。当您看到这个画面以后，说明我们的电脑已经连接到 NodeMCU 了。

是不是真的已经连接好了呢？我们来验证一下。如果您使用的是 Windows 10 操作系统，也请跟我一块来做一下。我们点击电脑的搜索栏，在这里输入 `cmd`，也就是打开我们电脑的命令提示符，然后输入指令 `ping`，注意后面输入 `192.168.4.1`，然后按下回车。通过这一系列操作，我们可以看到我们的电脑已经成功地和 `192.168.4.1` 这台网络设备建立了网络连接了。那么 `192.168.4.1` 这个设备是什么呢？正是我们的 NodeMCU，因为 NodeMCU 在接入点模式下的默认 IP 地址就是这个 `192.168.4.1`。关于这个信息，一会儿我在讲解程序的时候大家可以看到。现在我们已经 ping 通了 `192.168.4.1`，说明我们的电脑已经成功地和 NodeMCU 建立了网络通讯。

可能有的朋友是第一次见到 `ping` 这个工具，那我给您简单介绍一下 `ping` 的工作原理。`ping` 就是用来测试我们的电脑和某一个网络设备是不是已经成功地建立了网络连接。它的工作原理是向目的 IP 地址的这台网络设备发出一个请求，当对方网络设备成功地接收到以后，会返回一个回复，通过这一发一收，我们的电脑就可以判断出来，现在电脑和目的地 IP 地址的这台网络设备是不是已经成功地连接好了。需要注意的是，能 ping 通说明网络链路是通的；而 ping 不通并不一定说明设备坏了，也可能是对方和我们在不同的网段，或者对方屏蔽了 ping 请求，这些细节我们在后面的学习中会慢慢体会。这些可以通过下面这些文字信息看到，比如「来自 `192.168.4.1` 的回复」，通过下面的时间等等信息，我们可以看得出来这个网络连接的状态。通过底下这里的统计简报，可以看到已经接收了四个、丢失零个、丢失率 0%，说明我们这个网络是已经连接成功的。

好，下面我们就来看一看这段示例程序的主要内容。其实这段程序很简单。首先我们看程序的第一句，`#include <ESP8266WiFi.h>`，这句是告诉 Arduino IDE，我们接下来程序中要用到 `ESP8266WiFi` 这个库中的内容，这没什么太多可说的。我们继续往下看。下面这两条程序很简单，上面这个是定义了 WiFi 名称 `taichi-maker`，下面这个是定义了 WiFi 的密码。这两个是字符指针，假如您对指针的概念比较了解，那太好了；假如您不了解，也没有关系，我们在未来的课程中会给大家讲到指针的概念。到这里请您记住一点，就是通过这两条语句，我们建立了 WiFi 的名称以及 WiFi 的密码。

我们继续往下看，接下来就进入到整个程序的 `setup` 函数部分了。`setup` 函数中的第一句是 `Serial.begin(9600)`，这是启动串口通讯，通讯速率是 9600。下面这一条语句是一个重点语句，它的作用就是用来启动 NodeMCU 的接入点模式。其中请看这个语句括号里面的这两个参数，这两个参数是什么呢？我们刚才见过它们，一个是 password，也就是密码，在哪里呢？在这里是 `password`；还有一个是 ssid，在哪里呢？在这里是 `ssid`。估计不用多说您也明白了，它就是用来启动 NodeMCU 的接入点模式，同时启动接入点模式以后要建立一个 WiFi 网络，这个 WiFi 的名称以及 WiFi 的密码是什么，就是通过这条语句来控制的。

另外值得一提的是，就是这条语句中的 `WiFi.softAP()` 这个库函数，它调用的是我们 ESP8266 的 WiFi 库里面相应的内容。虽然我们只是简单地调用一个库函数，但这背后还是有很多工作要做的，所以在这里我们要先感谢一下为我们开发 ESP8266 WiFi 库的朋友们，他们的付出让我们可以很简单地通过调用函数就实现对 NodeMCU 的控制。

接下来我们再往下看，接下来是一系列通过串口通讯来显示信息的语句。显示的信息是什么呢？请看第一句，这里是 `Access Point:` 后面跟着 ssid，它显示的内容自然就是我们所建立的 WiFi 的名称是什么。第二个，这里所输出的 `IP Address:` 这个 IP 地址，它具体显示的内容是什么呢？同样是调用了一个库函数，因为我们刚才这里见到的这一句非常像，都是 `WiFi.` 后面跟一个函数名，只不过刚才那一句是 `WiFi.softAP()` 启动接入点模式，而这里请看是 `WiFi.softAPIP()`。通过调用这个库函数，它的返回值就是当前 NodeMCU 所建立的这个 WiFi 网络中，NodeMCU 本身它的 IP 地址是什么。

我们刚才通过 `ping` 工具 ping 的是 `192.168.4.1`，那么 NodeMCU 它的 IP 地址到底是不是 `192.168.4.1` 呢？接下来我们通过一系列操作来验证一下。下面我们打开串口监视器，通过串口监视器让我们的 NodeMCU 输出一下它的网络名称以及它的 IP 地址信息，也就是这个库函数的返回值。我来点击串口监视器按钮。

## 本节要点

- 开发 NodeMCU 前的两项准备工作：为电脑安装驱动（CP210x / CP2102 芯片驱动），以及为 Arduino IDE 配置 ESP8266 开发板支持。
- `CP210x` 是装配在 NodeMCU 开发板上的 USB 转串口芯片，负责开发板与电脑之间的数据通讯，必须先装驱动才能在设备管理器的「端口（COM 和 LPT）」下看到设备。
- 区分 32 位与 64 位系统：右键「此电脑」→「属性」→「系统类型」查看；驱动安装文件以 `x64` 结尾对应 64 位系统，`x86` 结尾对应 32 位系统。
- Arduino IDE 配置三步：在「文件」→「首选项」的「附加开发板管理器网址」填入 ESP8266 扩展网址（用 `Ctrl+V` 粘贴），再在「工具」→「开发板管理器」搜索 `esp8266` 并安装（推荐 2.6.3 版本），最后在「工具」中把开发板选为 `NodeMCU 1.0（ESP-12E Module）`、端口选为设备管理器中看到的 `COM` 端口。
- 用「文件」→「示例」→`01.Basics`→`Blink` 验证配置是否成功：编译上传后板载 LED 闪烁即表示环境正常。
- 接入点模式（`WiFi.softAP()`）：NodeMCU 自己建立一个 WiFi 热点供其他设备连接，该网络不提供互联网服务；其默认 IP 地址为 `192.168.4.1`，可用 `WiFi.softAPIP()` 查询。
- 无线终端模式（Station 模式，`WiFi.begin()`）：NodeMCU 连接到 WiFi 路由器，从而可以访问互联网，也可被同一局域网内的手机、电脑访问。
- 连接状态判断：`WiFi.status()` 返回 `WL_CONNECTED` 表示连接成功，`while` 循环配合延时不断轮询，可在等待期间用串口输出已等待的秒数。
- NodeMCU 点击串口监视器后不会自动复位（与 Arduino 不同），需手动按开发板上的 `RST` 键才能看到串口输出。
- 连接成功后在客户端模式下用 `WiFi.localIP()` 获取本机 IP，注意与接入点模式下的 `WiFi.softAPIP()` 区分；IP 地址由路由器动态分配，因此每次可能变化，可用 `ping` 验证连通性。
- 多网络自动连接（`ESP8266WiFiMulti`）：用 `wifiMulti.addAP()` 添加多组 SSID 与密码，再用 `wifiMulti.run()` 替代 `WiFi.begin()`，即可让开发板自动连接当前环境中可用的、信号最强的 WiFi 网络。
