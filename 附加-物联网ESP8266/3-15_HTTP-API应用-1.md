大家好，这一节课我们来讲 ESP8266 的 HTTP API 应用。首先我们一起来看看 HTTP API 的概念。所谓 HTTP 正是 HTTP 协议的意思，那 API 是什么东西呢？可能这个词很多朋友看到有一种似曾相识的感觉。实际上 API 是「应用编程接口」这几个单词的缩写：应用是 application，编程是 programming，接口是 interface。但是可能很多朋友看到「应用编程接口」这几个词以后，还是不能理解什么是 API。

好，那么首先我们先来看看这几个词。应用，那么这个 API 一定是可以用的，它就像我们手机里边某一个应用似的，我们可以用它。好，这是 application。编程，也就是这个 API 一定是针对我们编程的时候来使用的这么一种应用，并不是像我们使用手机一样，打开手机我们就可以打开这个应用，不是这样的，这个 API 它是必须要应用于编程里面的。我们再来看最后一个词，接口 interface。这里这个接口的概念是一种抽象的接口，它不像我们电脑上有一个 USB 接口一样，我们可以通过连接 USB 设备来使用这个接口。这里这个接口是针对我们这个编程来说的，我们在编程中可以通过这个接口来利用这个应用。

好，我再说一遍，我们在编程过程中可以通过某一个接口来利用某一个应用，那这个接口是这个抽象的接口的概念。好，这么说呢，可能有的朋友有点糊涂了，我们下面给大家举一个实例来讲讲什么是 API。先回忆一下，我们之前给大家讲解 JSON 数据格式的时候，曾给大家举过一个实例，在这个实例里面，我们的 ESP8266 的客户端将会通过互联网向服务器发送请求信息，那么服务器接收到请求信息后将会把当前的天气信息以 JSON 数据格式来响应给客户端。

## 本节要点

- API 是「应用编程接口」（Application Programming Interface）的缩写：应用指明它是可用的服务，编程指明它必须在程序中使用，接口是一个抽象概念，程序通过接口去调用服务。
- 用 ESP8266 客户端经互联网向服务器请求天气信息，这个过程完整符合 HTTP API 的三个要素：HTTP 协议、application（天气应用）、programming（编写程序调用）。
- HTTP API 能获取的信息远不止天气，例如哔哩哔哩 API 可以取到视频观看数、硬币数、UP 主信息；搜索「免费 API」可以看到更多开放平台。
- 物联网平台分两类：只提供信息的平台（如心知天气）和可以反向控制开发板的物联网应用平台（本节预告了 OneNET 与阿里云）。
- 使用心知天气前要先注册账户，并在控制台的「添加产品」中申请免费版服务，可获取国内 370 个主要城市的天气实况、三天预报和生活指数等数据。
- 控制台基本信息页中的「私钥」是访问心知天气服务的通行证，必须复制并填入程序；私钥是私密信息，不能随意泄露给他人。
- 程序关键配置项：主机地址 `api.seniverse.com`、端口 `80`、私钥变量 `reqUserKey`、城市变量 `reqLocation`（汉语拼音、首字母大写）、温度单位变量 `reqUnit`（`c` 摄氏度 / `f` 华氏度）。
- `loop()` 中拼接出的请求地址由几部分组成：`v3/weather/now.json?key=` 加私钥，再加 `&location=` 加城市，再加语言的 `en` 和单位的 `c`，然后用 `httpRequest()` 每三秒发送一次。
- `httpRequest()` 中要建立 `WiFiClient` 对象，拼接 `GET` 请求行与 host、connection 等请求头，连接服务器后用 `find` 跳过响应头，再调用 `parseInfo()` 解析响应体中的 JSON。
- 请求方法要看平台文档要求：文档若指明不能用 `GET` 则改用 `POST`，未指明时默认用 `GET` 即可。响应状态行要先判断是否为 `200 OK`，否则说明请求未成功。
- `parseInfo()` 由 ArduinoJson 在线工具生成，从返回结果中提取 `text`（天气现象文字）、`code`（天气现象代码）、`temperature`（温度）和 `last update`（更新时间）等信息。
- 天气现象用数字代码表示更便于程序处理（如 0 表示晴、4 表示多云），完整的代码对照表可在心知天气产品文档的「天气现象代码」页面查到。
