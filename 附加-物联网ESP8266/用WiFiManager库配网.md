## 正文

大家好，这节课我们来讲一个 ESP8266 开发时非常实用的应用技巧。这个技巧解决的是什么问题呢？就是我们不再需要使用 Arduino IDE 来编写程序，而是直接用我们的手机或者电脑，就可以为 ESP8266 配置 WiFi 连接信息。

我们先来设想一个场景。假设你现在完成了一个物联网项目，比如说 B 站上那个最萌小电视。这个小电视可以连接互联网，通过网络获取天气和时间信息，并把这些信息显示在屏幕上。那么这个项目，我们把它送给朋友了。送给朋友以后，如果朋友想让它联网，就肯定要对它进行设置。假如我们的朋友不会编程，那这时候该怎么来设置呢？这就要用到我们这节课要教给你的这个技巧了。我们将学会如何使用手机或者电脑，而无需编写程序，就能够完成设备的网络配置。

那么这个方法是具体如何实现的呢？请大家看好。在我们太极创客网站的首页，点击「学用物联网」这个链接，进入「CC++ 开发物联网」这个链接，然后在这里有一个「ESP8266 应用技巧」的链接，点击它。在这里我们将为你介绍一系列的 ESP8266 应用技巧，而本节课主要介绍的是 ESP8266 的自动配网，也就是 `WiFiManager` 这个库的使用方法。

好，我们来点击这个链接。首先我们来看看 `WiFiManager` 库是如何让我们无需电脑编程，只需要用手机或者用电脑就可以直接完成配置的。请看这里有一个 `WiFiManager` 的配置流程，我们点击放大它，这样你能看得更清楚一些。接下来我们就来看一看 `WiFiManager` 库的一个基本工作流程。

在 `WiFiManager` 库的控制下，当我们启动了 ESP8266 以后，紧接着我们的 ESP8266 就会利用闪存信息来连接 WiFi。这个闪存信息，是它自动存储的 WiFi 连接信息。我们说自动存储，其实这个信息是在不知不觉的情况下就存储好的。每当我们为 ESP8266 写程序让它联网的时候，一旦 ESP8266 成功连接网络以后，它就把这个信息自动地存储到闪存中去。那么下一次，即使我们把这个程序重新上传、重新清除以后，这个信息还是固定保留在闪存中的。

在 `WiFiManager` 库的控制下，当 ESP8266 启动以后，紧接着 ESP8266 就会使用刚才我说的这个闪存信息去连接 WiFi。如果一旦成功连接 WiFi，那太好了，这时候 `WiFiManager` 库就不会采取进一步的措施了，因为 WiFi 已经连接成功了。但是如果利用闪存中的这个信息连接 WiFi 失败了，那么紧接着 `WiFiManager` 库就可以采取一系列操作，让我们可以不需要编程就直接连接 WiFi。具体是什么操作呢？我们来看一下。

首先，我们的 ESP8266 如果 WiFi 连接失败，它就会启动 AP 模式让用户来连接。什么是 AP 模式，还记得吗？在我们零基础入门学用物联网教程早期的部分中，我们给大家介绍过，这个 AP 模式就是无线接入点模式，也就是我们的 ESP8266 将会建立一个 WiFi 网络，让我们可以用手机或者用电脑来连接它。一旦我们用手机或电脑连接到这个 ESP8266 所建立的 WiFi 网络以后，这时候我们就可以打开 ESP8266 所建立的一个网页，通过这个网页我们就可以输入 WiFi 的配置信息了。

输入完 WiFi 配置信息以后，这时候 ESP8266 将会使用我们输入的信息来再次尝试 WiFi 连接。如果这次 WiFi 连接成功，那没有问题，`WiFiManager` 库就结束任务。如果这个 WiFi 再次连接失败，那么 ESP8266 就会再次启动这个 AP 模式，让用户再次进行 WiFi 配置。这样循环往复，直到我们的 WiFi 连接成功，`WiFiManager` 库才会结束工作。通过这个流程我们可以看到，使用 `WiFiManager` 库，我们无需为 ESP8266 编程，而只用手机或者电脑连接 ESP8266 所建立的 WiFi 网络，就可以实现 ESP8266 的网络配置这么一个操作了。

接下来我们就来看看如何使用这个 `WiFiManager` 库。首先，在使用 `WiFiManager` 库之前，我们需要把这个库下载到我们的电脑中，并且把它安装到我们的 Arduino IDE 中。具体的一个下载地址，你可以通过这个网页中的链接获取。请看这个 GitHub 的页面，这是它官方的下载位置。同时，如果你访问 GitHub 不太方便，也可以通过我们页面上提供的一个网盘链接来下载。这里可以把 `WiFiManager` 库下载到你的电脑中，然后你就可以把它安装到 Arduino IDE 中去了。

不过首先，我们先看第一个程序。这个程序并不是用来配置 WiFi 的，而应该说是一个预备程序，它的作用是用来清理 ESP8266 所存储的 WiFi 连接信息的。我们知道，ESP8266 的 WiFi 设置是储存在它的闪存系统中的。刚才我给大家讲过，为什么 ESP8266 在一启动的时候就会尝试使用闪存信息连接 WiFi，因为这个 WiFi 信息就是存储在它的闪存系统中的。当我们使用 `WiFiManager` 库的时候，如果 ESP8266 一启动马上就顺利连上 WiFi 了，那这时候 `WiFiManager` 库就发挥不了任何作用了。所以我们需要把 ESP8266 闪存中所存储的 WiFi 连接信息先把它清理掉。

那怎么清理掉呢？请看我们这里的程序，通过这个示例程序就可以清除掉这个 WiFi 存储信息了。下面我们把这段程序复制并粘贴到我们的 Arduino IDE 中。好了，程序粘贴好了。首先，程序上来使用了四个 `#include`，其中请看鼠标高亮的地方，这就是刚安装好的 `WiFiManager` 库的头文件了。另外，我们这个 `WiFiManager` 库是需要用到前面这三个库文件的，所以我们在这里用三个 `#include` 来告诉 IDE，这个程序中将会用到哪些库。这些我们以前都见过，没什么好说的。

我们接下来往下看。在 `setup` 函数中，首先启动串口通讯。然后这一点也很重要，这里我们是建立了一个 `WiFiManager` 的一个对象，这个对象名称就叫做 `wifiManager`。因为这个对象，我们就可以实现 `WiFiManager` 库的所有功能。比如说，请看紧跟这条语句，这里就用我们这个 `WiFiManager` 库这个对象，让它来调用 `WiFiManager` 库中的这个函数，叫什么？`resetSettings`。这个 `reset` 是复位的意思，`settings` 是设置的意思，那么将所有的设置把它复位，就是把 ESP8266 所存储的 WiFi 连接信息清除掉。

```cpp
#include <ESP8266WiFi.h>
#include <DNSServer.h>
#include <ESP8266WebServer.h>
#include <WiFiManager.h>

WiFiManager wifiManager;

void setup() {
  Serial.begin(115200);
  wifiManager.resetSettings();          // 清除闪存中保存的 WiFi 连接信息
  Serial.println("WiFi 设置已清除");
}
```

紧接着请看，通过这个 `wifiManager` 对象，我们来调用 `WiFiManager` 库中的一个库函数，这个库函数很重要，它的库函数名称叫做 `autoConnect`。`auto` 是自动的意思，`connect` 是连接的意思。通过这个库函数，我们这个 `WiFiManager` 库将会实现刚才我给大家讲的这么一个过程：当启动以后首先使用闪存信息连接 WiFi，如果连接失败将会启动 AP，然后让我们的手机可以连接这个 AP 建立的网络，然后进行配置；如果配置成功了就结束，配置失败了就再次进入这个 AP 模式。正是通过 `autoConnect` 这个函数就可以实现刚才我们整个的流程了。

那么这个 `autoConnect` 函数它有一个参数，请看括号中这个参数，这个参数的作用就是当我们的 ESP8266 在建立这个 AP 接入点的时候，它的 WiFi 名称是什么。那这里我们这个双引号中的这个 WiFi 名称叫做 `AutoConnectAP`，请你注意，一会儿再给你演示的时候，我们将用手机连接一个叫做 `AutoConnectAP` 这么一个名称的 WiFi，这个 WiFi 就是 ESP8266 所建立的。当然了，假如你不太喜欢这个名字的话，你可以把它改一下，比如说改成 `TechMaker` 这样的名字感觉也可以，不过我们还是把它恢复回来，用这个名称比较容易观察。我们接下来就会用我们的手机来尝试连接叫做 `AutoConnectAP` 的这么一个 WiFi 了。

```cpp
void setup() {
  Serial.begin(115200);
  wifiManager.autoConnect("AutoConnectAP");     // 不需要密码
  Serial.println("WiFi 连接成功");
  Serial.println(WiFi.SSID());
  Serial.println(WiFi.localIP());
}
```

那么假设比如说我们现在想要修改一下这个页面中按钮的这些按键的说明信息，那好，那么只要把这个 `WiFiManager.h` 这个头文件开头的这部分信息中找到一个什么地方呢？找到一个叫做 `HTTP_PORTAL_OPTIONS` 的这么一个数组。那么找到这个数组以后调整它的内容就可以了。我们看一看，`HTTP_PORTAL_OPTIONS` 在这里，我们看到这个数组中的内容，在这个数组中请看这里 `Configure WiFi`，这个就是英文版的按键上面所显示出来的信息。那么通过我们把这个 `Configure WiFi` 这个信息，比如说请看后面我们这里是修改后的内容，我们通过把这个 `Configure WiFi` 的内容把它变成「配置 WiFi」这样的字样，就可以把这个按键上的这个说明改成中文的了。

## 本节要点

- `WiFiManager` 库解决的痛点：设备交付给不会编程的用户后，无需电脑、无需重新烧录程序，只用手机或电脑即可完成 WiFi 配置。
- 配网完整流程：设备启动 → 用闪存中保存的信息连接 WiFi → 连接失败则启动 AP 模式（建立热点）→ 手机或电脑连上热点 → 打开配置页面输入 SSID 与密码 → 保存后设备再次尝试连接，失败则循环重来。
- ESP8266 在联网成功后会**自动把 WiFi 连接信息写入闪存**，即使重新上传程序、清除程序，该信息仍然保留，这是自动配网的基础。
- 配网前通常先运行预备程序，用 `wifiManager.resetSettings()` 清除闪存中已保存的 WiFi 信息，否则设备一启动就连上了，`WiFiManager` 库不会介入。
- `wifiManager.autoConnect("AutoConnectAP")` 是配网的核心函数：只给一个参数时表示热点无密码；给两个参数时，第二个参数就是热点的密码。
- 设备进入 AP 模式后，热点默认 IP 是 `192.168.4.1`。手机连接时一般会自动弹出配置页面，电脑连接则需要手动在浏览器地址栏输入该 IP。
- 配置页面中点击 `Configure WiFi` 按钮后，可手动填写 SSID 与密码，也可用 Scan 扫描周边 WiFi 后点选。
- 太极创客提供了 `WiFiManager` 库的汉化版，界面按钮显示为中文，英语不熟悉的朋友可直接使用。
- 汉化原理：修改库文件夹中 `WiFiManager.h` 头文件开头的字符数组（本质是 HTML 代码），例如把 `HTTP_PORTAL_OPTIONS` 数组中的 `Configure WiFi` 改成「配置 WiFi」。
- 想了解更高级的用法（如设置 AP 模式的持续时间），可在 Arduino IDE 的「文件」→「示例」中找到 `WiFiManager` 库自带的示例程序。
