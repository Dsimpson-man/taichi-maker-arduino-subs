我们来接着看。JSON 它是 JavaScript Object Notation 的缩写，也就是 J-S-O-N。它是一种通用的轻量级数据交换文本格式。这句话有点绕嘴，但是这句话其实包含了很多信息内容，非常重要。首先我们看，JSON 是一种文本格式，符合 JSON 文本格式的数据都可以叫做 JSON 数据。那么这种文本格式它有几个很重要的特点。

第一个特点，请看它是一种通用的。为什么说是通用的呢？因为在很多很多编程语言中都可以用到它。第二，我们看它是轻量级的，也就是使用 JSON 这种文本格式来传输数据，比其他的一些数据格式要更轻、更小。这个也更加让 JSON 更适合物联网数据传输。讲这请您注意一点，并不是所有的物联网数据都是用 JSON 这种格式来传输的，但是在物联网数据传输中，JSON 是一种常用的格式。以上就是 JSON 格式的几个重要特点了。我们可以这样理解：正因为 JSON 又通用又轻量，它才能够在五花八门的设备和语言之间充当一种大家都听得懂的「普通话」。

另外要提一下的是，虽然 JSON 它的名称中有个 JavaScript，但事实上这个只代表它是用 JavaScript 的语法来存储和描述数据对象，就是它是用的 JavaScript 的语法，但并不代表 JSON 只适用于 JavaScript。事实上它适用于很多很多种流行的编程语言，包括数据传输也经常用到 JSON 这种格式的文件，所以我们在这儿重点给大家介绍一下 JSON。

接下来我们继续看 JSON 的几个重要概念。JSON 有三个重要的概念，分别是数据、对象和数组。在后续课程中我会给大家具体介绍这三个重点概念是什么，不过在介绍这几个重点概念之前，我们先来看看 JSON 的语法规则要点，具体这几个语法规则要点我现在给你简单介绍一下，后面我会给您详细介绍这些内容。这里也请大家注意，JSON 的这些规则并不难，但一定要记准，因为一旦某个符号写错了，比如该用双引号的地方用了单引号，或者该用逗号的地方用了分号，那么整个 JSON 就是不合法的，解析的时候就会直接报错，这一点在后面的实操中大家会体会得更深。

首先我们看第一个，JSON 的数据是以名值对来呈现的。什么叫名值对啊？就是一个名、一个值凑成一对，就是名值对。这些数据的名和值之间是用冒号来做分隔的。在 JSON 数据中的大括号，你看，大括号是用来标注 JSON 对象的。还记得对象吗？我刚才说了它是一个 JSON 的重点概念之一，JSON 对象一会儿我给大家做详细介绍。好，大括号，JSON 对象；那中括号呢，用来标注 JSON 的数组；另外呢，逗号是用于分隔数据、对象、数组这些内容的。可能看完这几条以后大家还不是很清楚我在说什么，我们先来看 JSON 中的第一个重要的概念，也就是 JSON 数据。

另外可能细心的朋友就发现了，我们这两个例子中数据的名，请看这两个数据名都是使用一个双引号把这个名称给括起来，这个是必须的。我们这一层数据中的一个数据名呢，是必须要用双引号把它括起来的。但是在这个数据值这个部分呢，请看上面这个 2016 是没有双引号的，而底下这个地方 `www.taichi-maker.com` 这个地方是有双引号的，为什么呢？通常对数字来说我们是不需要给它加双引号的，但是请看这里是一个字符串，字符串是需要双引号的，这一点和我们 C/C++ 语言编程的时候习惯是完全一致的。

那接下来我们再来看看，对于 JSON 数据来说，它的数据值都可以是哪些内容。首先它可以是数字，可以是整数，或者有小数点的浮点数；或者呢它可以是字符串，这两个我们刚刚见过。接下来呢它也可以是逻辑值，也就是布尔型的 `true` 或者 `false`，用布尔型的数值。另外呢也是一个数组，注意这里的数组指的是 JSON 的数组，JSON 数组刚才说了是要在中括号中的，这个内容我一会给大家详细介绍。另外呢请看，JSON 的数据值还可以是对象，是在大括号中的对象。还有呢它可以是 `null`。这 `null` 什么意思呢？它代表这个数据只有名没有值，也就是无值或者空值，但是这个地方呢我们不能只留空，我们还要写一个 `null`，用这个 n-u-l-l 来代表无值。

另外请您留意，对于 JSON 数据来说，一个名称只能对应一个值，在 JSON 数据中不能用一个名称来对应多个值，这是不允许的，一个名一个值这么对应的。另外有些朋友在描述 JSON 数据的时候，他对这个 JSON 数据的名字的这个称呼叫做「键」，就是键盘的键，比如说我们这个 JSON 数据是一个键值对，这个名称有朋友会管它叫键，键盘的键。这个呢也很常见，我在这提一下呢，是希望您将来听到这样的称呼不会感到陌生。

对于数组来说，它还有一个非常重要的特点，那就是数组中的元素是有序号的。我们知道数组里面的元素都是有序排列的，那么每一个元素它都有一个序号，而且这个序号是从 0 开始的。请看这个例子，我这里有一个数组，其中有三个元素，这三个元素都是字符串：

## 本节要点

- JSON 是 JavaScript Object Notation 的缩写，是一种通用的轻量级数据交换文本格式，在物联网数据传输中十分常用。
- 虽然名字里带有 JavaScript，但 JSON 只借用 JavaScript 的语法来描述数据对象，实际上适用于众多编程语言。
- 名值对（键值对）是 JSON 数据的基本单位，名和值之间用冒号分隔，名必须用双引号括起来。
- JSON 的数据值可以是数字（整数或浮点数）、字符串、布尔值、数组、对象以及 `null`；一个名称只能对应一个值。
- 大括号 `{}` 用于标注 JSON 对象，对象中可存放多个名值对，各名值对之间用逗号分隔。
- 对象不能直接存放对象，也不能直接存放数组，只能直接存放数据。
- 中括号 `[]` 用于标注 JSON 数组，数组元素之间用逗号分隔，且数组元素可以是值、对象或另一个数组，但不能直接存放 JSON 数据条目。
- 数组中的元素是有序号的，序号从 0 开始；而对象中的名值对没有序号。
- 借助在线 JSON 格式化与解析工具，可以直观地查看复杂 JSON 文档的结构与层级。
