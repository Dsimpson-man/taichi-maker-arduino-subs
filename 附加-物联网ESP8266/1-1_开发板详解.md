在上一节课里，我为您介绍了整套教程的一些基本信息。这节课我们将一起来开始学习物联网开发。物联网开发将基于您面前所看到的这个开发板，也就是 ESP8266 NodeMCU 这块开发板。这个开发板是一款开源的物联网开发板。说起开源开发板，可能有的朋友脑子里会想到 Arduino 开发板，没错，这个开发板和 Arduino 开发板非常相似，而且您目前所看到的这个 NodeMCU 开发板也可以使用 Arduino IDE，也就是 Arduino 开发环境来对它进行开发。这些信息我在上一节课里都给大家讲过了。在这节课接下来的学习中，我将为您介绍这个 ESP8266 NodeMCU 开发板，以便我们后面的课程能够更好地对它进行学习。

相信很多细心的朋友已经发现了，我们这个开发板的名称是由两部分组成的：前半部分是 ESP8266，后半部分是 NodeMCU。我们分别看看这两部分代表什么含义。

首先我们来看看 ESP8266 长什么样子。屏幕上所看到的这幅照片就是 ESP8266 的样子了，这是一个芯片，这个芯片是整个开发板最核心的元件。换句话说，我们这个开发板上所有的电子元件都是围绕着这块 ESP8266 芯片所服务的。

ESP8266 后面这个 NodeMCU 这半部分名称指的又是什么呢？NodeMCU 这个名字就是我们这个开发板本身的名称。市场上有很多很多基于 ESP8266 的开发板，为了区分这些开发板，我们会为每种开发板单独起个名字。您在屏幕上所看到的这种开发板，有两排插针，这里有一个可以连接 USB 数据线的端口，另外还有两个按钮等等，以这种样式所制作生产的开发板就是 NodeMCU 开发板了。换句话说，整个这个名字，前半部分是这个开发板的核心元件，也就是 ESP8266 芯片；后半部分就是开发板本身的名称了。

可能有的朋友会问：那我在这开发板上到哪里能找到 ESP8266 这个芯片呢？这个芯片请看，它被封装到这个金属壳里面去了，所以我们现在在这个画面中是看不到它的。那么您现在只需要记住一点：我们这款开发板的核心元件就是 ESP8266 这个芯片。另外，这个开发板的名称有点长，我在后面的讲解中就只用 NodeMCU 这半部分名字来取代整个开发板的全部名称。我一说 NodeMCU，指的就是 ESP8266 NodeMCU 开发板。

讲到这儿，不知道有没有朋友会感到好奇：既然我们已经有了这个芯片，为什么还要一个 NodeMCU 开发板，然后再把这个芯片装到这个开发板上？这个开发板的意义何在呢？请您留意，我们这个 ESP8266 芯片的大小只有我们小拇指的指甲盖大小。请看这边，这是芯片的正面，上面写着 ESP8266 这个芯片的名称；再看这幅画片，这是这个芯片的反面。在芯片的反面，芯片的四周分布着这个芯片的引脚。您想一想，我们这个芯片的大小只有小拇指的指甲盖那么大，那么这一个个引脚之间的距离是非常非常近的，如果我们想直接对这个芯片进行操作是很难的，所以我们才有了一个开发板。

那么开发板请看，它有两排插针，这两排插针是把芯片的这些引脚引出来了。这样做的好处是：我们在操作的时候就会比较容易，可以拿杜邦线直接插到这个插针上去，或者把这个开发板插到面包板上去，就可以很容易地对这个芯片进行操作了。所以我们才有了这个 NodeMCU 开发板。

另外还请注意，这个 NodeMCU 开发板除了有两排插针便于操作以外，还有其他的一些外围元件。请看这里有一个数据线接口，这个数据线接口配合板上的一些电子元件，可以便于我们对这个芯片烧写程序。当然，NodeMCU 开发板上的电路功能还远远不止这些，我就不再继续延伸下去了。

不过说了这么多，请您务必记住一点：这个 NodeMCU 开发板上这两排插针，是与 ESP8266 芯片的引脚连在一起的，这一点请您务必记住，我们后面的课程中还会讲解到。

另外还要提一点，这款 ESP8266 芯片是由一个中国企业所研发的，这个企业的名称叫乐鑫科技。如今这款 ESP8266 芯片在全世界获得了很大的成功，很多来自世界各地的创客朋友非常喜欢用 ESP8266 来开发各种各样的创客项目，这一点还是很值得我们中国创客骄傲的事情。还有一点请大家注意，乐鑫科技除了有 ESP8266 这个芯片以外，他们还有其他产品都非常酷炫，我在这里建议您感兴趣的话，可以到乐鑫科技的官网上看一看。不过说这么多也有一点请注意：我们没有收乐鑫科技一分钱的广告费，我说这么多，纯粹是因为我为这家企业感到自豪，所以想多给您介绍一下。

好，我们书归正传，继续回到物联网教程中来。接下来我们来仔细观察一下这个开发板。假如您现在手边正好有一个 NodeMCU 开发板的话，那请您拿出来，您可以看一下：这个开发板两排插针旁边的电路板上面印有两排文字，这两排文字的作用就是来向我们说明两排插针每一个插针引脚的名称。比如请看，我鼠标所指的这个引脚，它旁边印刷的这个文字是 `D2`，那么意思就是说这个引脚的引脚名称是 `D2`。可能这么看有点不是很明显，我们换一张图来看一下。好，那么这张图就明显多了，在这张图里面请看，在这两排插针旁边，这个文字就是各个引脚的名称了。现在请看，在屏幕中箭头所指的这个地方，这个 `D2` 指的就是它旁边这个引脚的引脚名称。

另外请留意，在这两排插针旁边有很多很多说明信息，这些说明信息是说明每个引脚它们的功能以及它们的编号。其中请您留意，这些蓝底白字、以 `GPIO` 为开头的编号它们也很关键。所谓 `GPIO`，就是通用输入输出的意思。那么这个 `GPIO` 后面的数字，比如请看这里，我们刚才说这个 `D2` 旁边这个 `GPIO`，这个呢指的是 4 号通用输入输出引脚。

刚刚讲到这儿，有朋友会糊涂了：明明我们已经有一个引脚名称了，就是 `D2` 了，我们干嘛还要再单独给它起一个名字，要叫它 `GPIO4` 呢？这么做是非常有必要的。原因是我们这个 NodeMCU 开发板的核心元件是 ESP8266 芯片，而这个 `GPIO` 编号，也就是刚才这个图里蓝底白字的、以 `GPIO` 为开头的编号，指的是 ESP8266 芯片上的引脚编号。换句话说，我们这个 NodeMCU 开发板上这个 `D2` 引脚，它所引出的正是 ESP8266 芯片上的 `GPIO4` 这个引脚。

所以，如果我们想要控制芯片上的任何一个引脚，比如想控制 `GPIO4` 这个芯片引脚的话，我们可以对 NodeMCU 开发板上这个 `D2` 引脚进行操作，就可以控制到芯片上的 `GPIO4` 这个引脚了。蓝底白字的是芯片引脚名称，开发板上印刷的是开发板的引脚名称。这两套引脚的命名系统对于很多初学的朋友来说经常搞混，请大家留意，一定要能明白我刚才所说这段话的意思。

说了这么多，我来给您出个思考题，考一考您对我刚才讲的这些是不是理解了。假设我们现在要对这个 NodeMCU 开发板控制这个 `D2` 引脚，我们把这个 `D2` 引脚设置为高电平。您在屏幕上可以看到我们只有两条语句：一条是 `digitalWrite(2, HIGH)`，也就是用第二个引脚名称 `D2`；另外一条语句是 `digitalWrite(4, HIGH)`，也就是这个 `GPIO` 后面这个数字 4。如果我们现在要控制这个 `D2` 引脚，把它设置为高电平，这两条语句哪一个是正确的呢？答案是：这两条语句它们的作用是相同的，都能够实现将 `D2` 这个引脚设置为高电平。不过我更习惯使用上面这个方法，因为用这个方法，跟我们直接想控制哪一个开发板的引脚，就直接写上这个开发引脚的名称就可以了，非常直观，一目了然。

另外，不知道有没有朋友已经注意到了，在众多蓝底白字的这些引脚中，有一个「家伙」的画风比较清奇，请看，其他的都是 `GPIO` 开头的，只有它是 `ADC`，和其他的这个文字完全不同。那么这个 `ADC` 代表的是什么呢？好，这个 `ADC` 旁边所标注的音节，请看上面写的是 `A0`。我不知道您看到这个 `A0` 以后，是不是就明白为什么它和别人都不太一样了。这个 `A0` 是模拟引脚，而其他以 `D` 字开头的这些引脚，它们是数字引脚。

假如您现在不知道什么是模拟引脚、什么是数字引脚的话，那说明一点是什么呢？就是您对微控制器的一些基础知识还有所欠缺。这样的话，请您暂停我们这个教程的学习，我现在强烈地建议您好好地看一看我们太极创客团队所开发的「零基础入门学用 Arduino」教程的基础知识篇。这一点我在上一节课给大家讲过，假如您现在对微控制器的一些基础知识都不太了解的话，那么后面的课程您会越学越糊涂，完全是在浪费时间。所以请您先把基础知识打扎实，然后再继续我们这个教程后续的学习。

好，我们接下来书归正传。我们 `ADC` 这个引脚所对应的 `A0`，这个 `A0` 音节呢是模拟引脚。很遗憾的是，这个 NodeMCU 开发板上有很多很多的数字引脚，而模拟引脚只有一个，这个资源还是比较珍贵的，所以未来我们在开发的时候要留意：只有一个模拟引脚。

关于这几种蓝底白字的引脚，我要介绍的就是这些了。接下来请您看一看这几个红底白字的引脚。首先我们来看看，这几个红底白字的引脚上面写着三个字母 `GND`，这里一共有四个 `GND` 引脚，这个不用多说了，它们就是接地引脚。另外请看，这还有几个白字的，上面写的是 `3V3`，这三个 `3V3` 引脚，它们代表的是：当 NodeMCU 在通电工作的时候，这几个 `3V3` 引脚是可以为外界提供 3.3 伏特电压的。

另外我们来看，这里还有一个红底白字的引脚，上面写着 `VIN`，它所对应的这个引脚上面所印刷的也是 `VIN`。这个 `VIN` 引脚的作用，可能朋友也知道了，它的作用是可以用来为 NodeMCU 供电。我们有两种办法来为 NodeMCU 供电：一种是通过 USB 这个数据接口，另外一种方法就是通过这个 `VIN` 引脚了。具体使用方法，后续我们在开发项目的时候会给大家做详细的介绍。现在请您记住两种方法：一种是我们用数据线连到 NodeMCU 上以后，这个数据线是可以为 NodeMCU 供电的；另外一种就是可以通过这个 `VIN` 引脚。

讲到这里，我就要给大家提一下关于 NodeMCU 开发板它的数字引脚的电平问题了。请大家回忆一下，我们在之前的课程中经常使用 Arduino UNO R3 这个开发板，它的数字引脚工作电压是 5 伏特。而对于我们这个 NodeMCU 开发板来说，它的数字引脚的电压不再是 5 伏特了，注意，比 5 伏特要小，是 3.3 伏特。

这意味着什么呢？这个要分两种情况来看。首先我们来看，假如我们这个引脚是以输出模式来工作的话，我们现在通过 `digitalWrite()` 这条语句让 `D2` 这个引脚设置为高电平，这个时候通过这条语句，我们这个 `D2` 引脚上面将会变为 3.3 伏特。这一点和 Arduino UNO 开发板是有所区别的：UNO 开发板我们每次将它设置为高电平的时候，引脚上的电压是 5 伏特；而对于 NodeMCU 开发板来说，这个电压是 3.3 伏特。

好，那我们继续来看。假设我们还是用这个 `D2` 引脚来作为例子，现在这个 `D2` 引脚是以输入模式来工作，这个时候我们可以通过 `digitalRead()` 这条语句来读取 `D2` 引脚上所连接的电平是高电平还是低电平。那么这个引脚所连接的电平允许的电压范围是多大呢？请注意，这允许的连接电压是不能够超过 3.3 伏特的，这一点非常非常重要。假如我们给它接了一个大于 3.3 伏特的电压的话，很有可能会把这个开发板搞坏，所以这一点非常非常关键，请大家务必注意。

对于 NodeMCU 开发板，输出模式的时候输出的高电平电压是 3.3 伏特；那么对于它是输入模式的时候，我们给它接的电压是不能够超过 3.3 伏特的。3.3 伏特这个数很重要。另外请大家注意，我在这里举例使用的是 `D2` 引脚，事实上这个规则是适用于所有的 NodeMCU 数字引脚的，不光是 `D2` 引脚有这个电压的要求，比如 `D0`、`D1`、`D3`、`D5` 所有这些数字引脚都有这个电压的要求，务必要记住：3.3 伏特，不要超过它，否则的话会对这个开发板造成伤害。

以上就是这个 NodeMCU 开发板数字引脚的电压要求。对于这个开发板的模拟引脚，同样也有要求。NodeMCU 开发板的模拟引脚可以读取的电压范围是 0 到 1 伏特之间。注意，0 到 1 伏特之间，不能够给这个模拟引脚施加超过 1 伏特的电压，否则的话同样会对这个开发板造成永久性的伤害。注意，0 到 1 伏特，不要超过这个范围。

首先我们来看，这种浅蓝背景黑色文字的这些引脚，这些以浅蓝背景黑色文字所指示的相关引脚，是 NodeMCU 开发板的通讯类型的引脚。所谓通讯，就是 NodeMCU 和其他的设备进行通讯用的这些引脚。这些通讯方式有串口通讯、SPI 通讯、I2C 通讯，其中比较常用的是串口通讯。

NodeMCU 开发板有两个硬件串口，这一点是和我们的 Arduino UNO R3 是不一样的。对于 Arduino UNO R3 来说，它只有一个硬件串口，而 NodeMCU 它有两个硬件串口。那么这两个硬件串口在哪呢？我们先看第一个。请看这里，我鼠标所指的地方，`U0TXD`、`U0RXD` 这两个所对应的引脚，请看在我们的 NodeMCU 开发板上也有说明，一个是 `TX`，一个是 `RX`。`TX` 是 NodeMCU 向外发送数据的，`RX` 是 NodeMCU 接收数据的。这两个引脚所组成的这个串口，可以说是 NodeMCU 最重要的串口了。为什么这么说呢？因为我们的电脑当用数据线和 NodeMCU 开发板连接在一起的时候，比如我们要向 NodeMCU 上传我们写好的程序，或者我们通过 IDE 中的串口监视器来检查这个 NodeMCU 所发送过来的这些数据信息，都是通过这个串口。因此我们在使用 NodeMCU 开发板的时候，要尽量避免使用 `RX` 和 `TX` 这两个引脚，否则的话，可能我们用电脑再给这个 NodeMCU 开发板上传程序的时候会出现问题。这一点很重要。

好，以上是这个第一个串口，也就是 `U0TXD`、`U0RXD` 这两个。那么第二个串口在哪呢？请看这里，`U1TXD` 还有 `U1RXD` 这两个引脚，它们是 NodeMCU 开发板的另外一个硬件串口。假如我们使用 NodeMCU 和其他的开发板，比如 Arduino 的开发板进行通讯的时候，我们就可以使用这第二个硬件串口来和其他的开发板进行通讯了。

但是在这里我要强调一点，我们知道 Arduino 开发板它的串口电压是 5 伏特，而且我们这个 NodeMCU 开发板的电压是 3.3 伏特。如果我们直接用 Arduino 的开发板和 NodeMCU 开发板进行直接连接进行串口通讯的话，会对 NodeMCU 开发板造成伤害。为什么呢？NodeMCU 开发板它这些引脚上最多只能连接 3.3 伏特，不能超过这个电压，所以我们要通过其他的手段。不过关于这方面知识，我们在后续的课程中会给大家做介绍。

关于 NodeMCU 硬件串口的相关知识，我要讲的就是这些了，后面我们在课程中如果接触到的话，我会再给大家做一些更多的补充。另外请看，除了这几个硬件串口，还有其他一些浅蓝底黑字的这些引脚，这些引脚分别是 I2C、SPI 等等其他的通讯端口，那么这些通讯端口我们在后续的课程中也会给大家讲到。现在请大家注意，浅蓝底黑字的都是通讯端口。

那么接下来我们来看看这些黑底白字的这些引脚。这些引脚都是 NodeMCU 开发板用来操作它内部存储单元的引脚。刚刚这么说大家有点糊涂，我给大家举个例子。当我们把程序上传到 NodeMCU 开发板以后，这个程序它会存储在开发板中，每次我们一开机，这个 NodeMCU 开发板就会从它的存储单元中来读取程序，并且按这个程序的指令内容来执行相应的工作。那么这个程序所存储的地方，正是 NodeMCU 开发板的这个存储单元。关于这个存储单元的操作，我在后续课程中还会给大家讲更多的内容，所以我在这里就先不讲太深了。

## 本节要点

- 开发板名称由两部分组成：`ESP8266` 是核心芯片型号，`NodeMCU` 是开发板本身的名称
- ESP8266 芯片只有小拇指指甲盖大小，引脚间距极近，无法直接操作
- 开发板的作用是把芯片引脚通过两排插针引出，便于用杜邦线或面包板连接
- 开发板上两排插针与 ESP8266 芯片的引脚是一一相连的
- ESP8266 芯片由中国的乐鑫科技研发，在全球创客圈广泛使用
- `GPIO` 是通用输入输出，蓝底白字为芯片引脚编号，开发板印刷的是开发板引脚名称，如 `D2` 对应 `GPIO4`
- `A0` 是模拟引脚，`D` 开头的都是数字引脚；NodeMCU 只有一个模拟引脚
- `GND` 为接地引脚，`3V3` 可对外提供 3.3V 电压，`VIN` 可用于给开发板供电
- 供电方式有两种：USB 数据接口供电，或通过 `VIN` 引脚供电
- 数字引脚高电平输出为 3.3V（Arduino UNO 为 5V），输入电压不得超过 3.3V
- 模拟引脚可读取的电压范围为 0～1 伏特，超过会永久损坏开发板
- 浅蓝底黑字为通讯端口（串口、SPI、I2C）；`U0TXD`/`U0RXD` 是上传程序和串口监视器使用的串口，应尽量避免占用
- 黑底白字的 6、7、8、9、10、11 号引脚用于控制内部存储单元，项目中不能使用
- 板上两个按键：`RST` 为复位键，`FLASH` 用于刷固件
- 引脚参考图纸可在太极创客官网搜索「NodeMCU 硬件」获取
