大家好。这节课我们讲一个开发技巧，也就是 ESP8266 的 OTA 操作。什么是 OTA 呢？OTA 就是 Over-The-Air 的缩写，有人把它翻译成「空中下载」，也有人把它翻译成「隔空传输」。不管这个翻译是什么，它的意义就在于我们可以实现无线的数据传输。那么对于我们的 ESP8266 来说，通过 OTA 这个技术，我们就不再需要数据线才能够把电脑里的程序上传给 ESP8266，而只需要把我们的 ESP8266 和电脑都连到同一个 WiFi 下，那么通过 WiFi 就可以把我们电脑中的程序上传给 ESP8266 了。

那么 OTA 的意义又何在呢？假设我们现在用 ESP8266 开发好了一个物联网产品，并且把它用外壳封装起来。过了一段时间，我们突然想要对这个 ESP8266 的程序进行升级。如果没有 OTA，我们就必须把这个外壳打开，用我们的数据线把 ESP8266 和电脑连在一起，然后才能够实现 ESP8266 的程序升级，这是挺麻烦的一件事情。但是有了 OTA 以后，我们就不用那么麻烦了，直接把 ESP8266 和我们的电脑连到同一个 WiFi 里，之后就可以实现无线的程序升级了。

```cpp
void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  digitalWrite(LED_BUILTIN, HIGH);

  ticker.attach(blinkInterval, tickerCount);
  connectWiFi();

  ArduinoOTA.setHostname("ESP8266");    // 设置 OTA 主机名
  ArduinoOTA.setPassword("12345678");   // 设置 OTA 上传密码

  ArduinoOTA.begin();                   // 启动 OTA 功能
  Serial.println("OTA 已启动");
}

void loop() {
  ArduinoOTA.handle();                  // 必须放在 loop 中频繁调用
}
```

## 本节要点

- OTA 是 Over-The-Air 的缩写，即「空中升级／无线升级」：不再需要数据线，只要开发板和电脑连在同一个 WiFi 下，就能把程序无线烧录到 ESP8266。
- OTA 的典型价值：已经用外壳封装好的物联网产品，不用拆壳、不用接数据线，就能远程升级固件。
- 实现 OTA 只需在原有程序中引入 `#include <ArduinoOTA.h>`，并配合 `ESP8266WiFi.h`（联网）与 `Ticker.h`（定时任务）一起使用。
- `ArduinoOTA.setHostname("ESP8266")` 用于设置主机名，这个名称会显示在 IDE 的网络端口列表中，便于识别设备。
- `ArduinoOTA.setPassword("12345678")` 用于设置上传密码，只有密码认证成功，ESP8266 才会接收电脑上传的程序，否则拒绝上传。
- `ArduinoOTA.begin()` 放在 `setup()` 中启动 OTA 功能；`ArduinoOTA.handle()` 必须放在 `loop()` 中被频繁调用，否则处理 OTA 请求时会明显滞后。
- 第一次必须先通过数据线烧录带有 OTA 功能的程序，之后才能改用无线方式上传。
- 无线上传的操作步骤：断开数据线并用充电宝等方式独立供电 → 重启 Arduino IDE → 在「工具」→「端口」中选择 `ESP8266 at 192.168.x.x` 网络端口 → 点击上传 → 输入密码 `12345678` → 上传成功后固件即刻生效。
- OTA 的三个局限性：一是新旧程序需同时保存，程序占用空间翻倍；二是 IDE 选用网络端口后无法再与开发板做串口通讯（开发板端串口本身不受影响，可改用 PuTTY 等串口软件）；三是电脑与 ESP8266 必须处于同一个 WiFi 网络。
- `BasicOTA` 示例中还演示了 `onStart`、`onEnd`、`onProgress`、`onError` 等回调函数，可在传输开始、结束、进行中和出错时执行自定义操作，属于使用频率较低的高级用法。
