## 本节要点

- 用一串 if 判断显示数字：Arduino 每次都要逐条判断，显示 3 需三次判断，效率低、浪费资源。
- 把第 2 条起的 if 改成 else if 后，条件一旦匹配就立即执行，后续判断全部跳过：显示 1 只判一次、显示 2 只判两次，程序更流畅高效。
- 优化代码很有必要：若将来程序的时序以微秒、毫秒计，代码效率直接决定程序能否正常运行；但 else if 层数太多时既不便于阅读，编译和运行也可能出问题。
- switch...case 结构：`switch(变量)` 的圆括号里放一个变量（v2 即 variable 变量），大括号内用 `case 值:` 匹配，用 `break` 跳出整个语句块；所有 case 都不匹配时执行 `default` 分支。
- 本例中 `switch(myNumber)` 分别在 myNumber 为 1、2、3 时显示对应数字，为其他值（如 9）时走 default，在数码管上显示一个字母 d。
- 用 random(0, 4) 产生随机数：两个参数分别是最小值和最大值，返回 min 到 max-1 之间的整数，因此 0~4 会得到 0、1、2、3，不会取到 4，取到 0 时即走 default 显示 d。
- 显示完后要清理显示内容并再延时半秒，否则上次的内容会与本次数字重叠，显示不正常；清屏加延时也让数字呈现闪烁效果。
