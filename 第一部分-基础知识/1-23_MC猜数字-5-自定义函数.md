## 本节要点

- 自定义函数的意义：delay()、digitalWrite() 等是 Arduino 官方写好的函数，而我们自己反复拷贝粘贴的代码（如清理数码管显示）应该封装成自己的函数，避免程序冗长、便于阅读和修改。
- 第一个函数 displayClear：定义在 loop() 函数的大括号之外，结构为 `void 函数名(){ 函数体 }`；调用时写 `displayClear();`，名称后的圆括号和分号不能忘。
- 这个函数简单在两个地方：一是没有参数，所以圆括号里是空的；二是没有返回值，只执行一系列动作，所以前面写 void（空）。setup() 和 loop() 前面也都是 void。
- 带参数的函数 displayNumber：`void displayNumber(int ledNumber){ switch...case }`，定义参数时必须写明参数的类型（如 int），需要多个参数时用逗号分隔，两个参数名不能相同。
- 非常关键的一点：函数内部使用的参数名（ledNumber）必须与函数体里 switch 所判断的变量名统一，否则函数不能正常工作；调用时传入实际变量，如 `displayNumber(myNumber);`，Arduino 会把参数传递进函数并在整个函数运行中使用它。
- 既有返回值又有参数的函数 getRandomNumber：函数名前的 int 表示返回值的类型（若返回浮点型就写 float），圆括号里声明参数类型与名称（int minNumber, int maxNumber）。
- return 的作用：函数执行到 return 就立刻终止，并把 return 后面的数值返回给调用位置；return 后什么都不写则返回默认值 0，也可以直接 return 一个具体数值。
