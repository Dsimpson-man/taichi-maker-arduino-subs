# 1-3 Arduino 开发板基本介绍

> 时长：约 9 分钟

## 正文

大家好，这节课我们主要学习 Arduino 开发板的一些硬件知识，主要分成这么几个部分：首先我们要学一些关于开源硬件是什么以及它的一些基本概念；还有 Arduino 开发板上面有哪些引脚以及它们的类型；最后我们再来讲一些关于学习 Arduino 过程中要注意的一些事项。

假如您对 Arduino 感兴趣的话，那么相信您对"开源"这个概念也不陌生了。到底什么是开源呢？这个概念确实很庞大，我在这简单说一下。开源就是说，一个产品从研发、设计到最终做成成品、最终投向市场，整个各个环节所有的产品细节都开放给公众，这种情况下它就可以叫做一个开源产品。

比如我们市面上经常能喝到的凉茶这种饮料，南方的朋友可能对凉茶非常熟悉了，街边就能买到凉茶。那这个凉茶里面的配方是什么样子的呢？有很多很多种，很多凉茶用户也会根据自己的喜好对凉茶的配方进行改变或者改进，那这个凉茶就可以说是一种开源的产品。

那什么是非开源的呢？很简单了，比如像可口可乐公司的可口可乐。我们谁也不知道这个可口可乐里面到底有什么，虽然有很多仿造可口可乐公司的饮料，但具体它是什么我们也不知道。

那么 Arduino 产品就是最成功的开源硬件产品之一了。因为 Arduino 公司把产品硬件方面的设计，包括开发板的电路、尺寸、细节，或者它的软件源代码，全部都开放给公众。所以说 Arduino 公司真的是为我们做了一件非常非常伟大的事情。

您可能会说，那都开放给大家了，它挣什么钱、吃什么呢？我个人觉得，真正热衷于开源事业的人们，他们所追求的最终目标绝对不是利益、不是金钱。我想他们的理想是让整个人类、让这个世界变得更美好一些。我估计你可能听着会想笑，但这真的是我个人的感觉，我也相信热衷于开源的人们都有这样的理想。

由于 Arduino 开发板是开源的产品，所以在市场上有很多不同类型的 Arduino 开发板：有的呢是官方生产的，有的呢是厂商采用了 Arduino 公司的产品设计复制出来的——我在这里管它叫克隆板。官方产品叫官方版，克隆产品我叫的克隆板。那对于官方版还有克隆板来说，它们各有各的特点。

对于初学者来说，我个人还是推荐使用官方版，因为这样能够确保产品的质量。当然我们在学习过程中难免会出一些错误，比如说写程序哪里写错了，或者代码哪里写得不够完善，那么在这种情况下，当我们使用官方版的话，我们可以保证在发生错误的时候，这个错误源自于我们的程序，而非产品硬件。但是对于非官方版来说，当我们对 Arduino 产品熟悉到一定程度了以后，我觉得可以用，为什么呢？因为毕竟我们要考虑到钱包这个因素了。不过说到底，我还是觉得 Arduino 公司为我们做了很多很多非常出色、非常伟大的事情，我们无论是从物理还是从人力上来说，应该多多为他们做一些贡献，所以多多支持 Arduino 官方产品。

那么现在大家在屏幕左侧看到的这一排公司名称，是目前 Arduino 中国官网上列出的代理商的名称，通过他们能够买到保证质量的 Arduino 官方版。

接下来我们一起来学习 Arduino Uno 开发板基本的硬件知识。首先我们来看 Arduino 开发板中最核心的——Microchip ATmega328 微控制器，也就是现在您看到的这个橙色方块中标注出来的芯片。这块芯片是由 Microchip 公司开发出来的，而 Arduino 公司把这块芯片植入到自己的 Arduino 开发板上。换句话说，这块芯片是整个开发板中最核心的元件，所有其他的电子元件都是围绕着这块微控制器来工作的。

这个微控制器从名字上来看，确实显得挺遥远、挺高大上的，其实它没有那么离我们遥远。可能在我们家里面的空调，或者家中的微波炉里面，都有可能使用这块微控制器进行控制。

我们看到微控制器两端有两排金属片，这个金属片的学名叫做**引脚**。可以说，这个微控制器和外界是怎么沟通，或者说这个微控制器是如何来控制外界元器件的，它就是通过这些引脚来控制的。比如微控制器要给一个 LED 发控制信号，它是通过这种硬件的引脚；或者这个微控制器要读取一个传感器的读数，那么它是通过这个引脚；甚至这个微控制器和我们使用的电脑进行通讯，它也是通过这个引脚。这个引脚，请记住，对于微控制器来说是非常非常重要的。

在没有 Arduino 开发板以前，我们要学习和使用这个微控制器的话，就需要通过焊接的方法，把元器件比如像 LED 或者传感器这种电子元器件焊接到这个微控制器的引脚上，但这是很麻烦的一件事情。有了开发板以后，我们只需要把这些电子元器件插入到相应的端口位置上去，也就是这两排塑料的小片。那么插入以后，这个微控制器就可以对我们的电子元器件进行控制了，就简单得多了。

那这两排端口一共分成三组：第一组叫做数字输入输出端口，第二组叫做模拟输入端口，第三组叫做电源端口。

首先我们来看上面这一排最长的端口，也就是数字输入输出端口。首先我们说这个概念：输入、输出。什么是输入，什么输出？输入输出这都是相对于 Arduino 开发板来说的。对于这块开发板来说，如果我们向开发板发送信号，那么相对于开发板来说，这个开发板在接收信号，那么这个过程对于开发板来说就是输入；那么如果开发板向我们发送信号，也就是这个信号是从开发板输出的，那么这种情况下就是输出。也就是说，输入输出都是针对这个开发板的。

那接下来我们再说什么叫"数字"。所谓数字，说白了就是只有两种状态，要么就是 0，要么就是 1。我们可以想一下家里电灯的开关：我们打开电灯的时候就是 1，关闭电灯的时候就是 0。那在这种状态下，这个信号就可以称为数字信号，也就是 0、1，只有这两种状态，没有别的状态。

在数字输入输出端口中，有两个端口比较特殊，它们是端口 0 和端口 1。我们看到端口 0 旁边写着两个字符 RX，端口 1 写着 TX，这两个端口是 Arduino 用来和电脑进行传输数据使用的。那具体如何用电脑和 Arduino 进行数据传输，这些知识我们后续的教程会详细地跟大家介绍。现在请一定记住一点：端口 0、端口 1 这两个数字端口一定要最后使用，就是没有别的端口了、没办法了，再用端口 0 和端口 1。

接下来我们来看右下角这个模拟输入端口。模拟输入是相对于数字输入的。我们刚才说到数字输入只有两种状态，要么就 0，要么就 1，要么就开，要么就关，或者说要么就黑，要么就白。但事实上我们现实世界里面不光是只有这两种状态，会有很多其他的状态，比如说不光是黑也不是白，它是灰色的，那在这种情况下我们就必须要用到模拟输入了。

最后我们来说 Arduino 的电源端口。首先我们看这两个端口，上面写着"接地"（GND），顾名思义，这两个端口就是接地的。同时旁边的这个地方，这个端口上写着 5V，那么这个端口当 Arduino 开发板通电以后，会提供 5 伏的电压。同时旁边这个端口写着 3.3V，就是它会提供 3.3 伏特的电压。

Arduino 开发板上的硬件基本上就讲到这里了，还有其他的一些硬件部分，我们会随着课程的进展陆陆续续地跟大家讲述。那目前各位只要知道这些就够了。

最后，在这节课结束的时候，我想跟大家分享一些我在学习和使用 Arduino 开发板的一些心得体会。首先我想说，学习 Arduino 开发板是一件非常令人激动的事情。为什么呢？我本人是一个非常喜欢玩电脑游戏的人，我感觉学习使用 Arduino 的开发板就好像我学了一个新的法术技能，我可以用我的大脑、用我的双手，让这个世界上一个实实在在的东西按照我的意愿来工作，就好像我有法术一样。

不过呢，学习毕竟是学习，有的时候它可能会很枯燥，这就要求我们一定要有恒心，要相信自己能把它学会，我也相信我们各位一定能把它学会。

再有我想跟大家说的就是"细心"这两个字。我们在学习 Arduino 开发板的过程中要写很多很多的程序，这些程序一定要求我们特别细致、特别认真地小心每一个环节，否则的话，我们在毛毛草草地写完一个程序，或者做好一件事情以后，会出现很多很多的问题、很多的错误，再去找这些问题、找这种错误，这是非常浪费时间的。那不如我们在从一开始做这件事的时候就细心认真地把它做好，这样的话也可以节约很多时间、提高很多效率。

## 本节要点

- 开源：产品从研发、设计到成品上市的各个环节，所有细节都开放给公众（如街边凉茶的配方）；Arduino 是最成功的开源硬件产品之一。
- 市场上 Arduino 开发板分官方版和克隆板。初学者建议用官方版，出错时可确定是程序问题而非硬件问题；熟悉后可考虑克隆板。
- Uno 的核心是 **ATmega328 微控制器**，它是整块板子的核心元件，其他元件都围绕它工作。
- 微控制器通过**引脚**与外界通信：发控制信号、读传感器、与电脑通讯都靠引脚。有开发板后，元器件直接插在端口上即可，无需焊接。
- 端口分三组：**数字输入输出端口**、**模拟输入端口**、**电源端口**。
- 输入/输出以开发板为参照；数字信号只有 0 和 1 两种状态，模拟输入用于灰色这类中间状态。
- 数字端口中 **0（RX）和 1（TX）** 用于与电脑传输数据，应最后使用。
- 电源端口提供 **GND（接地）**、**5V**、**3.3V**。
- 学习心得：保持恒心、做事细心、不要害怕失败。
