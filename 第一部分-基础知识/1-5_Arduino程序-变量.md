## 正文

大家好，这节课我们的重点要跟大家讲一讲 Arduino 编程中的**变量**这个概念。接下来我会告诉大家如何在 Arduino 程序中创建一个变量，最后我还会告诉大家在创建变量中需要注意哪些事情。

首先我来跟大家讲一下什么是程序变量。现在假设我们要做一个小的科研项目，这个科研项目是什么呢？是要用 Arduino 开发板来测量一下这一整天的温度情况。其中我们最关心的有两个信息：一个是 Arduino 的开发板测量到的当前温度数值，还有一个就是记录这一天里面最高的温度数值。那么对于"当前温度"和"最高温度"这两个信息，就是两个变量——也就是我们在写 Arduino 程序的时候，这两个信息就是两个编程的变量。

变量是存储在 Arduino 的内存里面的。我们可以把内存设想成一个很大很大的柜子，那么这个柜子里面有一个又一个小格子。在这个科研小项目里面，我们有两个变量，分别是当前温度，还有一个变量是最高温度，而 Arduino 会把这两个变量相应地放到两个不同的小格子里面。

现在假设 Arduino 开始工作了。它现在测量了一个温度，数值是多少呢？20 度。它就会把这个 20 度放到内存的这个小盒子里面。同时，20 度是测量的第一个温度数值，所以它肯定是最高温度，于是它会把 20 度也放到最高温度这个小格子里面。

再过了一会，Arduino 再次测量一个温度数值，这时候它测量的数值是多少呢？30 度。30 度是不是当前的最高温度呢？的确是最高温度了，于是它就会把 30 度也放到相应的小格子里面。再过了一会儿，Arduino 又测了一个数值，18 度，这时候 18 度不是最高温度，Arduino 就不会做任何事情，继续让 30 度保持在"最高温度"这个小格子里面。

在这个过程中我们看到，程序的变量数值它是随着 Arduino 的工作产生了变化的，但是变量本身的名称还是没有变化的。也就是说，我们"当前温度"这个变量，它的数值体现是 20，后来变成 30，最后变成 18，它是在不断地根据实际情况发生了变化，但是这个变量本身的名称一直没有变化。也就是说：**变量值是可以改变的，而变量名称是不能改变的。**

接下来我来跟大家介绍一下**变量类型**这个概念。首先我们看一个例子，我们看到屏幕上呢有三组不同的信息：第一个信息是 18，第二个信息是 dog（d-o-g），第三个信息是英文字母大写的 A。这三个不同的信息，我们也能看出来它是属于不同类型的。

而对于 Arduino，当我们在创建一个变量的时候，第一件事情我们就要告诉 Arduino 这个变量它的类型是什么。那我们再回到刚才这个测量温度的项目示例上来。如果我们要让 Arduino 来测量这一整天的温度的话，我们一定要写一段程序告诉 Arduino 如何来测量。那么在这段程序里面我们会创建很多个变量，其中一个变量叫做"当前温度"。那当我们在创建这个变量的时候，我们必须要告诉 Arduino 这个变量是用来存放什么类型信息的。

刚才我们这几个测量的数值都是整数，那好，我们现在就告诉 Arduino，这个变量在程序中将要存储的信息类型是整数型信息。同时我们再看刚才这几个例子，一个是 18，一个是 dog，一个是 A，很明显了，只有 18 是可以传递到"当前温度"这个变量中去的，因为它是一个整数。但如果我们要是把 dog 这样的英文单词赋予给这个变量，这是错误的；同样的，英文的 A 也是不可以赋予给这个变量的，因为它不是一个整数。

下面我们来看一下如何来创建一个变量。我们看到屏幕上显示出来了一个程序语句，这句话由三部分组成：第一部分是变量类型，它是英文单词 integer 这个单词的三个首字母 **int**，它代表的是整数型变量，integer 这个单词就是"整数"；后面这一段是**变量名称**，英文好的同学可能已经看到了，它是由两个单词组成的，第一个是 current，第二个单词是 temperature，这还是我们刚才那个项目实例里面的那个变量名称——"当前温度"；最后一部分就是这个语句最后的分号，这个分号会告诉计算机，我们这一个程序语句到这里就结束了。

那接下来我来向大家实际演示一下如何在 Arduino 程序中创建一个变量。首先我们打开 Arduino IDE，请看这里。

首先，我们要创建一个变量的第一步，是要告诉 Arduino 我们这个变量它的类型是什么。目前我们只学了一种类型的变量，就是整数型变量，后续我会把其他类型的变量跟大家做一个介绍，现在我们先只关注这一种类型的变量——整数型的变量。还记得刚才我们敲的那个整数型变量那个单词是什么？它是 **int**。

请注意，我们再看，我们在敲完这三个英文字母以后，Arduino IDE 自动地就把这个词变成了一个颜色。之前我们讲过，这个 int 是一个关键字，所以 Arduino IDE 会自动地把它变成一个颜色。敲完 int 以后，我们接下来要敲一个空格，好告诉 Arduino IDE 我们这个变量类型已经输完了。

接下来我们要说的是变量名称。请注意，变量名称不能使用中文，只能使用英文——又说到我们的英文有多重要了。还记得刚才我们说这个变量的名称是什么？当前温度的变量名称是 current（c-u-r-r-e-n-t），current，当前，temperature（t-e-m-p-e-r-a-t-u-r-e）。好，到这里这个变量名称写完了。

还有一件事情非常重要，千万不要忘记，我们要切换成一个分号，告诉 Arduino 这个变量就已经创建完毕了。

我们可以根据自己的意愿来给程序变量起名，但同时我们要遵守几个原则。首先第一个，变量必须要用英文写出来，也可以用汉语拼音拼出来，但是不能写中文。现在屏幕上面有几个变量名称，请注意这几个变量名称都是错误的，它们错在哪儿呢？我们一点点来说。

首先我们看第一个变量名称 `current temperature`，注意变量名必须用连贯的一个词，中间不能有空格，所以这个地方有空格是错的。第二个，我们看在这个变量名后面有一个特殊字符井号，问号、井号或者 dollar 这种特殊字符是不能用在变量名称中的。第三个，我们看这个变量名称它的第一个字符是一个数字，这是不允许的。我们再往下，high——如果您有印象的话，对于这种关键字是不能用来做变量名称的。

当我们在给一个变量起名的时候，我们应该遵守一些规则，这些规则并不是一些硬性的要求，但是在建立变量的时候，这对于我们将来会很有帮助。首先说第一个：给变量起名的时候，应该尽量想一想这个变量是用来存储什么类型的信息、存储什么内容，然后根据这个变量本身它存储的内容给它起个名字。

举个例子，我们这个程序里面这个变量，我们知道它是用来存储温度信息的，那么我们就给它起名叫 current temperature。那么当我们下一次，或者我们别的朋友在读到我们这段程序的时候，他看到这个变量名称，第一个反应就知道这个变量是存储当前温度这样一个数值的。

我再给大家举一个反例，告诉大家什么样的变量名称是一个不太好的变量名称。同样的还是存储当前温度这个数值，我们给这个变量名称起名叫 dog。如果我们用 dog 来存储当前温度这个数值的话，对于 Arduino IDE 来说我们编译起来是没有任何问题的，但是有一个问题：我们写完程序以后，也许过一段时间我们要自己再来看一看这段程序，或者我们这段程序写得特别的棒，好多朋友都来传阅，当别人在看到这段程序的时候，如果看到一个变量名称他写的是 current temperature，一目了然，没有任何问题，这是存储当前温度的变量；假如不用 current temperature，我们用的是 dog——哎呀，这哥们要是看到这样的一个变量名称，我估计他立马就懵了，什么东西这是？尤其是当他发现这个 dog 里面存的是一个温度，你想一想他的心情会是什么样的。反正我如果看到有朋友要这么写程序的话，我肯定会崩溃的。

其次，这个变量名称假如它不止一个单词，就好像我们这个"当前温度"，我们看到它是两个单词，这个时候我们可以用第二个单词的首字母大写来作为这两个单词的分界，这是一种方法；还有一种方法，比如说同样的我们还是给它起名叫 current temperature，写完 current 以后，我们可以写第二个单词，这时候我们写一个下划线，然后再写；或者我们在第二个单词首字母大写，这样就更清晰了。以上这几种方法都是可以的，我相信您在将来读到别的程序的时候，肯定会看到类似的这种变量名称的起名方法。

接下来我来跟大家讲一下如何给一个变量来赋值。当我们创建完一个整数型变量以后，假如我们没有给这个变量任何数值的话，那么 Arduino 默认会给这个整数型变量一个默认的数值，也就是 0。那现在我们看到，在这段语句中我们没有给这个 current temperature 这个变量任何数值，那么在目前这个状态下，current temperature 它的数值是等于 0。

我们也可以在声明这个变量的同时给这个变量一个初始值。我们不想让它最初让这个 current temperature 这个变量等于 0，我们想比如说我们想要这个 current temperature 这个变量在初始的状态下它等于 18，那我们怎么做呢？请看屏幕。估计您看我写了这几个字符以后您已经明白了，很简单，首先就是要告诉 Arduino 这个 current temperature 它等于多少，等于 18。

在这里，这个等号它有一个特殊的名称，千万记住，这是一个非常关键的知识点，这个等号它叫**赋值运算符**。也就是说，我们在每次给一个变量赋值的时候，都要用到这个运算符。比如说我们在后续写的写程序的过程中，需要再给这个变量重新赋值，我们先写出我们要赋值的这个变量名称是什么，current temperature，然后等号也就是赋值运算符，现在我们要给这个变量赋予一个新的数值，比如说我们要赋予它 30，好，这边显示 30，最后要加上分号，表示这一句结束。那么 Arduino 在看到这一个程序语句的时候，它就会把 30 赋予给 current temperature 这个变量了。

我再讲一遍：最初我们创建了一个变量，它的变量类型是整数类型，它的变量名称叫 current temperature。我们给这个 current temperature 这个变量一个初始的数值，这个初始数值是可选的，可以给它一个初始数值，也可以不用给。如果我们给初始数值的话，那么这个变量在初始状态下就有一个数值，也就是在这里写了 18。然后程序开始运行，运行到这里的时候，当 Arduino 看到我们要让这个 current temperature 这个变量改变它的数值了，那么这时候这个 current temperature 它的数值就等于 30 了。

## 本节要点

- 变量就是程序中用来存放信息的"小格子"，存放在 Arduino 的内存里。
- 变量值可以改变，变量名称不能改变。
- 创建变量时必须先说明变量类型。本课学习的是整数型 **int**（integer 的缩写）。
- 一条变量声明语句由三部分组成：变量类型 + 变量名称 + 分号，例如 `int currentTemperature;`。
- 起名规则：只能用英文或拼音、不能有空格、不能含 # / ? / $ 等特殊字符、不能以数字开头、不能使用关键字（如 high）；多个单词可用下划线或首字母大写分隔。
- 命名要有意义，能反映变量存储的内容（如 currentTemperature），避免用 dog 这类毫不相关的名字。
- 不给初始值时，整数型变量默认为 **0**；可在声明时用赋值运算符 `=` 直接给初始值（如 `int currentTemperature = 18;`）。
- `=` 叫**赋值运算符**，是给变量赋值的专用符号，语句末尾同样要加分号。
