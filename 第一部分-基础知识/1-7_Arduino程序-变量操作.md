我们学到这里以后，我不知道你有没有好奇，我们为什么要把建立变量这个过程写在程序最开始，而且是所有的函数的外面、括号的外面？那么如果我们要把这个变量写到一个函数的里面，会什么样的结果呢？我告诉你为什么：所有的变量都有它的一个工作范围，也就是说，当我们把一个变量在建立它的时候，如果我们把这个变量建立在某一个函数——我们现在看到这是 setup 这个函数的里面——的时候，那么这个变量只允许在这个函数内部使用。

## 本节要点

- `delayTime = delayTime + 1000;` 与直接写 `delayTime = 4000;` 完全不同：前者每次执行都会在**当前值基础上**再加 1000，因此 3000 → 4000 → 5000 → 6000 不断累加。
- 程序执行顺序：建立变量（赋 3000）→ setup()（不变）→ loop() 中逐条执行，执行到最后一条后回到第一条反复执行。
- 整数型（int）的取值范围是 **-32768 ~ 32767**，超出后会发生"溢出"，回卷到另一端（像吃豆从右边出去、左边进来）。
- 比 int 更大的是**长整型**，可表示更大范围的数值。
- 选数据类型的依据：变量实际可能达到的最大/最小值。Arduino 内存有限，一律用最大类型是浪费，甚至会导致内存不足。
- **变量的作用域**：变量定义在函数内部（括号内）→ 只能在**该函数内部**使用，叫**局部变量**；定义在所有函数外面 → 任何函数都能用，叫**全局变量**。
- 在函数外定义的变量不能跨函数使用时会报错：`xxx was not declared in this scope`。
- 不同函数内可以定义同名变量，编译能通过，但它们是**互不相关的两个变量**，因为作用域不同。
- 正常编程中应避免在不同函数里用同名变量，容易把自己搞糊涂。
- 思考题：要表示小数（如 3.14），应使用哪种数据类型？
