在这儿我把这段程序给挑出来了，我们首先来关注这个圆括号里面的内容，大家还记得它叫什么？它叫逻辑表达式。那么这个逻辑表达式里面这个双等号还记得它是什么吗？它叫关系运算符。所谓关系运算符，它肯定是要进行一个运算，对吧？那么既然要进行运算，那肯定要有一个运算的结果。

在上节课我没有提这一点，那在这里可能会想着重地告诉大家，这个关系运算符它所计算的结果有两种。第一种，第一种运算的结果是真，换句话说，也就是说这个关系运算符算出来的结果是真实的。啊，怎么是真实的呢？对于我们这个相等两个等号的这个关系运算符来说，它两侧两个表达式的确是相等的，那么在这种情况下它预算的结果是真，那么在这种情况下它会执行哪儿呢？它就执行这段语句；否则它的运算结果自然是假的了，那么它将运算另外一段程序。那么把这段程序翻译一下，就是我们看到的屏幕上这一段：通过关系表达式判断真还是假，从而控制这个程序它的运行的哪一部分。

大家请注意，对于这个关系表达式，当 Arduino 对它进行关系运算并且产生了结果以后，它是如何来存储和处理的呢？它是通过两个数字，一个是 1，一个是 0。也就是对于 Arduino 来说，当这个关系运算结果是真的的时候，也就是 true 的时候，那么 Arduino 实际上是把它当做了一个数字 1 来处理；那反过来如果假的话，它是当做 0 来处理的。

对于这种真真假假、1 和 0 的这种运算，Arduino 是专门有一种数据类型来存储这样的数据的，它的名字叫布尔型的数据，因为是 boolean。大家一定注意，这种数据类型它的重要性绝不亚于我们之前学过的任何一种数据类型。请注意，这个布尔型的数据它可以存储 1 和存储 0，只有这两种。你给它一个 3 行不行？你给它 3 可以，但是你要给它 3 的时候它会把它当做什么呢？它会把它弄到 1。换句话说，对于布尔型的数据，除了 0 以外，你给它任何数值它都会当做 1 来处理的。也就是说，我们把一个变量，我们把它定义成布尔类型的变量以后，它如果这个变量所存储的数值是 0 的时候，OK，没问题，就是 0；但如果这个变量所存储的这个数值不是 0 了，变成 -30000、正 1000、正 500，它全部都当做 1 来处理。

为了加深大家对布尔型数据的学习和认识，我们在这儿把这个按键开关控制 13 引脚上内置 LED 的这段实例程序我们把它重新改写一下，这一次我们将使用这个布尔型数据。请大家跟着我，随着我敲这个程序的过程跟我一起来思考。好，我们来开始吧。

设置完成以后，接下来我们要对这两个引脚进行程序编写了。首先我们要针对 pushButton 这个变量这个引脚，也就是小按键的引脚，我们要让 Arduino 不断地去检查这个引脚它的状态，并且把这个电平状态通过 digitalRead 这个语句读取出来，并且存储到这个 pushButton 这个变量里面去。然后我们要检查这个 pushButton 它的数值，并且我们要根据这个数值进行判断。pushButton 这个变量它的数值是 1，也就是真的的话，digitalWrite 这条语句我们给 13 号引脚写一个 HIGH 让它点亮，也就是高电平；否则，否则怎么样呢？我们要让这个 13 引脚上的 LED 我们把它熄灭，这就是低电平。程序写完了，我们试着编译一下，看看有没有毛病。好，一切顺利，这段程序写到这里就写完了。

## 本节要点

- 关系运算符的运算结果只有两种：真（true）或假（false）；Arduino 存储结果时用数字 1 表示真，用数字 0 表示假。
- 布尔型数据（boolean，也可简写为 bool）专门用来存储 1 和 0 这两种数值，只认这两种；除 0 以外的任何数值（如 -30000、1000、500）都会按 1 处理。
- 课程把 DigitalInputPullup 程序改写为使用布尔型变量的版本：建立布尔变量 pushButton，用 pinMode 把 2 号引脚设为 INPUT_PULLUP、13 号引脚设为 OUTPUT。
- 改写后的程序用 digitalRead 读取按键引脚状态存入布尔变量，再以此变量作为 if 的判断条件：为真（1，未按键）时点亮，否则（0，按下）时熄灭。
- 两种写法都可行：DirectInputPullup 原程序用逻辑关系运算的结果来控制流程，改写程序直接用布尔变量作为判断结果。
- 实测效果与上一节课正好相反：本课程序上传后 13 引脚 LED 默认点亮，按下按键熄灭、抬起又亮起；原因正是 INPUT_PULLUP 下按下为低电平（0）、松开为高电平（1）。
- 知识小结：按键开关把引脚置为高电平或低电平，Arduino 用 1 和 0 表示，布尔型变量存储这两个值，再用 if 语句判断，最终实现用小按键控制 LED。
