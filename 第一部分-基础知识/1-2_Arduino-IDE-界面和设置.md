# 1-2 Arduino IDE 界面和设置

> 系列：零基础入门学用 Arduino（第一部分）｜ UP主：太极创客
> 时长：约 10 分钟

## 正文

大家好，这节课我们一起来熟悉 Arduino IDE，也就是 Arduino 的开发环境。主要内容有：如何选择开发板的型号还有端口，如何保存一个 Arduino 程序，以及一起来了解一下软件的界面。

首先，请把你的 Arduino 开发板还有数据线拿出来。我们看到数据线有两端，一端是标准的 USB 接口，请把这一端插在你的电脑上；另外一端就接在你的 Arduino 开发板上就可以了，就这么简单。接下来请启动你的 Arduino 开发软件，也就是 Arduino IDE。

什么是 Arduino IDE 呢？其实说白了很简单，就好像我们要写一个文档，有时候我们可能会打开 Word，或者使用 Windows 自带的文本编辑软件；或者我们要画一幅画，可能会用 Photoshop，或者用 Windows 自带的画笔。Arduino IDE 说白了就是我们要开发 Arduino 程序的时候所要使用的软件。它长得有点像一个文本编辑器，但事实上它这里面有很多特殊的功能，专门是用来开发 Arduino 使用的。

首先我要给大家讲一下如何来正确选择 Arduino 开发板型号，以及如何正确选择 Arduino 使用的端口。请留意下面的内容，非常非常重要，一定要仔细听。

我们把鼠标挪到"工具"菜单点击它，这时候会弹出一个子菜单。我们在这边往下看，看到"开发板"的选择，当我们把鼠标挪上去的时候，会弹出一个子菜单，在这里面我们可以看到有很多很多选项，每一个选项都针对一个 Arduino 的开发板。我们看到 Arduino 家族真的有很多种开发板。这里我的软件上面已经默认选择的是 Arduino Uno，就这个选项已经选好了。这个就是 Arduino 最基本、最初始的一个开发板。我们整个这个教程也将针对这个 Uno 开发板来进行教学。为什么选择这个开发板呢？说白了它是给初学者的，也就是给零基础的人使用的，它非常简单，但同时它的功能又非常非常的强大。

接下来我们要告诉 Arduino IDE，我们的开发板是接在哪一个端口上的。同样的选择"工具"，点击"工具"，然后从下面这个菜单里面找到"端口"这个菜单。如果您这个软件现在这个地方是灰色的、不让选的话，那有两种可能：第一种，就是您的开发板是不是没有插好，检查一下开发板的数据线是不是已经非常牢固地连接到您的电脑上去了；第二个可能，就是您在安装 Arduino 软件的时候驱动程序没有很好地安装，这时候可能需要您重新安装一下这个 Arduino 开发程序，或者是重新安装一下 Arduino 的驱动程序。如果试过这两个还有问题的话，那估计你就要联系一下你这块 Arduino 开发板的卖家了。

我的这个开发板，你可以看到现在当我把鼠标挪到这个地方的时候，它显示出来就是 COM10，后面写着一个 Arduino Uno 的名称，点击它，这样就可以告诉 Arduino IDE 我的这个 Uno 的端口在哪里了。有的时候可能电脑上插了很多个设备，那么这个时候当您选择"工具 → 端口"时，可能看到很多个选项，但是一定要注意找到写着 Arduino Uno 的那个选项。

一旦在 Arduino IDE 中设置好开发板的型号以及端口以后，下一次如果您把 Arduino 开发板拔掉以后再重新插回去的时候，您的电脑是能够记住 Arduino 开发板的相关信息的，也就是设置一次就可以了，不用反复地做这工作。

我在这给大家演示一下。现在我可以看到我的开发板是连接在电脑上了，我把 Arduino 开发板拔掉，可以听到这个电脑被 Arduino Uno 拔掉以后发出的声音。这时候我们看一下，您可以看到这个端口这地方它是灰色的，不能选任何东西。好，我们现在再把这个开发板插回去，这个声音说明开发板已经插回去了。我们再看一下，同样还是选择 Arduino Uno，那么端口呢还是同样的 COM10。这些信息都被电脑保存住了，不用再反复设置了。

当您的 Arduino 开发板插到电脑上以后，您电脑所识别 Arduino 这个端口跟我这里会有区别。因为电脑有很多个端口，它会自动根据系统的状态来分配一个端口给 Arduino。那么可能您的电脑当前分配给 Arduino 的端口不是我这个端口——我这个地方写的是 COM10——您那个电脑上面分配给 Arduino 的端口可能是别的端口，号码和我这里是不同的，所以这一点你一定要留意，不用完全和我这里端口相同。

接下来我向大家介绍一下如何来保存一个 Arduino 的程序。Arduino 的程序有一个自己的英文名称叫 **sketch**，这个词在英文里边是"素描、草稿"这样的词汇，而在 Arduino 里面，它就是专门针对 Arduino 程序的名称，叫 sketch。

在这里我想多说两句英文知识。这对于学习计算机来说可能听起来有点遥远，但事实上，学好英文对于学好计算机、学好编程是很有帮助的。好多理工科的同学往往对英文会有一些排斥或者抵触，事实上知识是相通的，尤其是英文，因为我们现在写程序大部分都是使用英文；同时我们读资料的时候，包括将来我们要学习最前沿的新科技知识的时候，经常会接触到英文的资料。所以在这里我想多说两句关于英文学习的重要性，它对于学习编程、学习计算机是非常重要的。

闲话少说，我们说回到如何来保存一个 Arduino 程序。当我们写好一个 Arduino 的程序以后，我们要把这个程序保存起来，这是非常关键的，这就好像我们写 Word 文档或者创建其他电脑文件一样，经常保存这是一个好习惯。如何来保存呢？我们点击"文件"，点击"保存"，很简单，在弹出菜单里面告诉电脑我们要存在什么地方就可以了。默认的情况下，Arduino 程序保存的路径是"我的文档"下面的 Arduino 目录里面。

多说两句，就是关于这个文件的名称，不能使用空格还有一些特殊字符，尽量使用 26 个英文字母，还有数字、减号或者下划线就可以了。我们给我们的 Arduino 程序编一个名字，我们管它叫做 `my_sketch`，然后点击保存。

当我们保存完成以后，我们看到这里会显示我们这个程序的名称。我们可以敲一些内容在程序里面了，随便敲一点 "this is my first sketch"，当然这句话不是程序了，随便敲一点作为一个实例吧。当我们在程序里面敲文字以后，我们可以注意到这里它多了一个小符号，这个小符号代表着我们这个程序跟上一次保存的版本比较起来有新的编辑内容。快速保存的话，可以点击这个向下的箭头，点它，刚才那个小符号就没了。那么现在我们再敲点内容，看它又出来了。再保存，再敲，再保存。

在编程过程中要记得经常保存我们所写的程序，这是一个好的编程习惯，这样可以保证我们实时地把工作进度保存下来。如果一旦发生什么特殊情况，我们可以及时地把当前的工作状态得到一个恢复。

接下来我们来介绍一下 Arduino IDE 的界面。Arduino IDE 的界面主要分成这么几个区域：首先是快捷按钮，接下来是编辑程序的区域，再接下来是这里的这个状态栏，再往下是信息面板。我们接下来将一步一步地跟大家讲述每一个区域的作用是什么。

首先我们来看最上面的这一排功能按钮。先看最左边这个按钮，当我们把鼠标挪到上面去以后，我们可以看到它的名字叫做"验证"。顾名思义，这个按钮就是检查一下我们所写的程序有没有什么错误、有什么问题。在我们写程序的过程中，应该经常地让电脑验证一下我们的程序，这是一个比较好的编程习惯。其实这个按钮还有另外一个功能，它可以把我们所写的程序翻译成计算机能够读懂的格式。我们所写的程序都是用英文字母、语句所写出来的计算机程序，但事实上电脑要读懂这段程序，需要通过编译这个过程，把我们所写的程序转换成计算机能读懂的一个格式，那么这个过程就叫做编译。

接下来我们再来看旁边这个按钮"上传"。上传的功能是什么呢？我在这给大家做一个简单的介绍。当我们写这个程序的时候，我们知道这个程序是保存在我们计算机里面的，说得更具体一点是计算机硬盘里面。那么这个时候，如果要是让 Arduino 去运行我们的程序，我们就必须要把计算机硬盘里的程序传给 Arduino，那这个过程就叫做上传。

剩下这三个按钮就比较好理解了。首先我们看这个按钮是"新建"，点击它，我们看到新建了一个程序；再点击又有一个新的；再点击又有一个新的。这个呢是"打开"，点击一下，这就是我以前在计算机里面存的这么多个程序，随便点击一个，这是我以前写的一个程序。最后这个按钮是"保存"，刚才我们已经介绍过了，就是专门用来保存我们所写的程序用的。

在我们程序编写区域的下方，这个蓝色的长条，你经常看到这里会出现一些文字，这个地方是 Arduino IDE 用来显示它当前工作状态的。我们来做一个实验：比如我们写了一段程序，做一个保存，点一下保存按钮，我们可以看到这里显示"保存完成"，就是说 Arduino IDE 告诉我们这个程序现在已经保存好了。或者比如说我们现在对这个程序做一个验证，点一下验证，这时候我们可以看到这里显示"计算机正在编译项目"，也就是它正在把我们这段程序做一个编译。编译完成了，这里也告诉我们现在的状态是已经编译完成了。

当程序编译完成以后，我们可以看到最底下这边出现了很多文字，这个区域是专门用来让 Arduino IDE 告诉我们这段程序的一些基本信息的。或者说，比如我们这段程序出了一些错误，它也会通过这里来告诉我们。我们来试一下，随便写一段，随便瞎写几个字母，我们让 Arduino IDE 验证一下，点验证，正在编译项目，这时候看到了 "exit status 1"、"was not declared in this scope"，这是什么东西呢？就是说这是个错误。哪儿错了呢？第一，这一行，标红色的这段文字就是错的。

到这里，Arduino IDE 界面的主要部分我们就介绍结束了。后面我们会随着教程的不断进展，把其他这里没有涉及到的内容做一个更详细的介绍。谢谢大家，再见。

## 本节要点

- Arduino IDE 是开发 Arduino 程序所用的软件，本质类似带特殊功能的文本编辑器。
- 开发板型号在"工具 → 开发板"中选择，本教程统一使用 **Arduino Uno**。
- 端口在"工具 → 端口"中选择；若端口为灰色不可选，先检查数据线是否插牢，再检查驱动是否装好，最后才考虑联系卖家。
- 型号和端口只需设置一次，电脑会记住；但每台电脑分配的端口号（如 COM10）不同，无需与教程一致。
- Arduino 程序在英文中称为 **sketch**。
- 常用文件名只用英文字母、数字、减号和下划线，不要用空格和特殊字符。
- IDE 界面分为快捷按钮区、程序编辑区、状态栏、信息面板；编辑区出现小符号表示有未保存的修改，建议随时保存。
- 顶部按钮：验证（同时完成编译）、上传（把程序从电脑传给开发板）、新建、打开、保存。
