# 1-1 Arduino IDE 下载和安装

> 系列：零基础入门学用 Arduino（第一部分）｜ UP主：太极创客
> 时长：7 分 27 秒

## 正文

大家好，这节课我将向大家介绍如何下载并且安装 Arduino 编程软件。

首先，在电脑里打开你所喜欢使用的浏览器，在地址栏里输入 Arduino 官方网站的网址 `www.arduino.cc`。如果你发现打开页面的速度有点慢，没有关系，因为这个网站的服务器在国外。如果访问有困难，也不要紧，接着往下看，我们一会儿还会告诉大家第二种下载安装 Arduino 编程软件的方法。

当你打开了这个页面以后，我们看到最上面这一排有一个 Software（软件）的链接，点击它，往下拉，找到 "Download the Arduino IDE" 这样的字样，并且找到你所使用电脑的操作系统对应的版本。我用的是 Windows 操作系统，那么我在这里下载 Windows 版本。下载完后解压缩，然后就可以用了。点击这里，稍等一下。

好，在这个页面里是 Arduino 公司的一个募捐页面。Arduino 公司为我们做了很多很多非常出色的事情，我推荐大家如果感兴趣的话，可以给他们捐献一些自己的力量，捐点钱也可以。如果想捐钱，点击这里——我已经捐过了，那我点这里。这时候浏览器会弹出一个提示问你，点击这里，软件就开始下载了。网站是在国外，所以它的下载速度可能会有点慢，没有关系。

如果你发现从 Arduino 官方网站下载软件速度慢得没法忍受，我们还有第二种方法：可以来到我们太极创客的官方网站。具体如何做呢？就是打开浏览器，并且在网址里输入我们的网址 `www.taichimaker.com`。打开网址以后，你可以看到最上面一行里面有"软件下载"这个链接，点击它，然后找到——我们会定时地把 Arduino 的软件放在百度云盘以供大家下载。所以只要点击这个链接，就可以来到百度云盘直接下载了。相信这样做大家也不用担心速度问题了。

软件下载完成以后，找到软件存储位置，并且双击这个图标开始安装程序。不过一会儿我会告诉大家如何把这个软件变成中文的。

首先我们先点击同意条款，然后这里一定注意要全部都选中，尤其是这一行 "install USB driver"，这个是非常关键的，这是我们的 Arduino 开发板硬件的驱动程序，所以在这里一定注意要勾选这个地方。其他呢，就是建立一些桌面的快捷方式：这一行是在开始菜单建立快捷方式，这一行是在桌面建立快捷方式，这一行是把电脑里面所有的 .ino 程序是否关联到 Arduino IDE 里面去。这些可以根据自己的选择，重点就是一定要注意这一行要勾选，千万要记住这里是勾选的。

软件大概需要 416.7 兆的空间，目前需要这么大了。确认你的电脑有足够的硬盘空间以后，点击下一步，然后在这里输入你要安装的路径，点击安装，接下来就等着了。安装的过程可能是要等一段时间，如果比较慢的话，一定要耐心等待。

请留意，在安装过程中电脑可能会问你是否安装这个 Arduino USB 驱动程序，在这一步千万记住——如果不安装，开发板是不能正常工作的。点击安装。

软件安装结束以后，你会看到桌面上有一个 Arduino 的图标，双击它就可以打开 Arduino 开发软件了。首先我们要看一看这个软件的一些基本设置：点击"文件"，然后点击"首选项"。

细心的朋友可能已经发现，刚才我们在安装软件的时候是英文的，但是现在全都变成中文了。为什么呢？因为我们在这里对编辑器的语言有一个"系统预设"，这个系统预设是这个程序安装时默认的，就是我们的 Windows 操作系统本身的语言，是中文的。那么安装完以后，这个编辑器也就是我们这个 Arduino 开发软件，它的界面也就自动被设置成中文的了。

第二个就是看这里，这个地方是项目文件夹位置。什么是项目文件夹位置呢？就是将来我们在开发 Arduino 时会编写很多 Arduino 的程序，那么这些 Arduino 程序默认存在什么地方呢？也就是存在我们这个电脑的这个位置。也就是说，所有将来你开发的 Arduino 的程序都会存放在这里所指定的位置。如果你想改，直接在这里改就可以了。

接下来我们要说一下关于字体，也就是编辑器字体大小。这个字体就是说我们在将来开发 Arduino 程序的时候，这个文字字体大小是多少。基本上根据你自己的需求吧，我这边设置的是 22，相对已经是足够大的了。

再接下来就是关于这一行，我们看到"显示行号"，这个很重要。什么是行号呢？就是我们在开发程序的时候，这个程序一行又一行，每行前面有一个数字。显示行号的时候，它就会显示这个数字；如果我们把这个地方勾掉，那么这个行号就消失了。为了便于我们开发，我建议还是把这个"显示行号"留住。

当你做好了所有这些设置以后，就可以点"好"了。

## 本节要点

- 官方下载地址是 `www.arduino.cc`，进入后点击 Software → Download the Arduino IDE，选择对应操作系统的版本。
- 官网服务器在国外，下载慢属正常现象；可从太极创客官网 `www.taichimaker.com` 的"软件下载"栏目转到百度云盘下载。
- 安装时必须勾选 **install USB driver**（Arduino 开发板硬件驱动），否则开发板无法正常工作。
- Arduino 开发板驱动安装的提示窗口中一定要选择"安装"，这是开发板能被电脑识别的关键。
- 安装后在"文件 → 首选项"中可查看和修改：编辑器语言（系统预设为中文）、项目文件夹位置、编辑器字体大小、是否显示行号。
- 建议保留"显示行号"，便于阅读和调试程序。
