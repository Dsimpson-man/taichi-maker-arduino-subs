## 本节要点

- 预备知识：本项目是「零基础入门学用物联网」教程的第三个部分 MQTT 应用篇中的第一个制作项目，会用到基础知识篇与 MQTT 协议篇的内容，建议先补齐这两篇再看本节。

- 资源下载：库文件、项目源代码与屏幕测试代码、手机 App、背景包，都可以在「1-1-0 天气时钟资源下载」页面一次性下载。
- 主控程序需要做四处个性化修改：①添加心知天气信息（私钥 + 城市）②设置哔哩哔哩网站信息（UP 主 user id + 视频 BV 号）③修改时区 ④设置 MQTT 服务。
- 代码修改完成后，依次上传主控程序、上传背景图片到闪存文件系统，再用 WiFiManager 完成配网，天气时钟即可正常工作。
- 常见问题对照：白屏通常是没有成功连接 WiFi；当前气温显示 999 通常是心知天气私钥没有设置正确；背景图片不显示通常是图片没有上传到闪存；哔哩哔哩信息不显示通常是没有填对用户 id 和 BV 号。
