在之前的课程里，我们学习了如何使用 Arduino 配合电机驱动板来控制直流电机还有步进电机。那么这节课我们将学习一种新的方法来用 Arduino 控制电机。这个方法呢说它新其实也并不是很新，为什么呢？因为这个方法本身它的原理和我们之前学的这个原理很相似，但是我为什么管这个方法叫新方法呢？正是因为使用的这个电机驱动板和之前所学的这个电机驱动板是有很大的不同的。

好，那现在请您回忆一下，我们在之前课程里给大家讲过，假如我们现在要用 Arduino 来驱动一个 NEMA 这么一个步进电机，我们首先是要用一个 A4988 这个电机驱动板或者其他的这种电机驱动板来配合我们的 Arduino 实现这个步进电机的这种驱动的工作；或者说我们现在要驱动的是一个 28BYJ-48 步进电机，那这时候我们还是要给这个电路配一个 ULN2003 步进电机驱动板。那么无论是 ULN2003 驱动板也好，还是说 A4988 驱动板也好，这些它们都并不是专门为 Arduino 所设计的，换句话说，我们用其他的微控制器也可以配合这些驱动板来使用。但是我们这节课给大家介绍的这个电机驱动板呢，请看这里这个图片，这里这个电机驱动板它就是专门给 Arduino 设计的。

为什么这么说呢？先看哈，我们看看这个电机驱动板的背面，你看这里，这张图片就是一个电机驱动板的背面了，在这个电路板的背面我们可以看到电路板的两侧有两排插针，这两排插针的作用正是用来插到我们这个 Arduino 开发板这两排引脚的这个插孔中去的，那么插好以后的效果呢，请看就是我刚刚给大家演示的这个照片，这个图片里的效果了。好，那说了这么半天，我还没有给大家介绍这个电路板它的真正大名呢，它叫做 Arduino AFMotor 电机扩展板。那么所谓电机扩展板就是专门用来驱动电机用的电机扩展板，什么是 Arduino 扩展板？就是为我们的 Arduino 开发板来扩展功能的电路板，那么自然而然，所谓电机扩展板自然就是让 Arduino 扩展的功能让它可以去驱动电机的这种扩展板，就叫做电机扩展板。那请看这个名字里面还有个 AFMotor，这个 AFMotor 就是我们这款电机扩展板它的名字。那是不是 Arduino 还有别的电机扩展板呢？有的，我们在后续课程中还会给大家介绍更多的电机扩展板，这节课我们的主角是 AFMotor 电机扩展板。

那么您现在只要记住一点，只要是扩展板，它的背面一定是设计了两排插针，这些插针是可以插到 Arduino 开发板上的，直接插这个电路板就可以用了。这种扩展板的好处是它们省去了很多接线的麻烦，我们之前如果用电机驱动板的话，需要用很多线把 Arduino 和我们的驱动板连接在一起，如果一不小心这个线没接好的话，那电路可能还不能正常工作，那么有了这个电机扩展板以后，这些麻烦就省掉了，只要把这个扩展板插到 Arduino 的上面就可以用了。不过这种扩展板它有自己的缺点，什么缺点呢？这种扩展板是比较占用 Arduino 资源的，也就是说我们这个 Arduino 一旦插上了扩展板以后，它基本上就只能干一件事，现在我们给 Arduino 插了一个电机扩展板，它基本上只能用来驱动电机。如果我们现在这个 Arduino 既来驱动电机，又来驱动比如说一串数字 LED 光带，那么现在这个 Arduino 就已经很难来满足我这个要求了。当然了，具体 Arduino 需要完成什么工作是由我们要完成这个项目所决定的，比如说我们现在眼前的这个项目就是要让 Arduino 来控制一系列的电机，这时候选择使用扩展板是一个不错的一个方法。

好，那接下来我给大家讲一讲我们将如何来使用这款 AFMotor 电机扩展板。这个电机扩展板它比较适合控制通用的模型直流电机，就像 130 电机这种，还有 28BYJ-48 步进电机以及舵机这几种电机，但是 AFMotor 电机扩展板它不是很适合用来控制 NEMA 这一系列的步进电机的，那么具体如何来控制 NEMA 步进电机的这个扩展板呢，我们将在后边的课程给大家讲。好，那我们就来开始。首先我们来看看 AFMotor 电机扩展板它的主要功能。AFMotor 电机扩展板最多驱动的模型直流电机的数量是四个，驱动 28BYJ-48 步进电机的最多是驱动两个，还可以最多驱动两个舵机。在扩展板上配有两块 L293D 芯片，主要负责电机的驱动工作，这个芯片对于很多爱好航模的朋友们来说应该还是挺熟悉的，比较老牌的电机驱动芯片。另外我们这个扩展板它不光能够配合 Arduino UNO 开发板来使用，同时还可以配合 Arduino Mega 的开发板来使用，不过这节课我们主要是针对 Arduino UNO 开发板来给大家进行讲解的，原因是无论 UNO 也好还是 Mega 也好，它们在配合 AFMotor 电机扩展板的使用时候的原理都是一样的。

好了，那么了解了 AFMotor 电机扩展板的主要功能以后，接下来我们再来看看 Arduino AFMotor 电机扩展板的主要结构了。那您现在屏幕上看到的这张图就列出了 AFMotor 电机扩展板的主要电机端口和元件。可能乍一看还挺复杂的，没关系，我一点点给你讲，很容易你就明白了。首先请看，在我们这个扩展板两侧有两排用红色字体标注出来的这个电机端口，它们是用来连接直流电机或者是步进电机的，请注意，我在这说的是直流电机或者步进电机，是因为这两排端口既可以连接直流电机也可以连接步进电机，但是它们是并不能用来连接舵机的，为什么呢？因为舵机有自己专门的接口。请看，在左上角这个灰色字体标志出来的这里，是连接舵机端口，一共是可以连接两个舵机，请看这里两排插针就是专门给两个舵机设计的，上面请看这写的 SERVO1，下面是 SERVO2，分别是上面这是连接一个舵机，下面的是一个舵机。

好，我们继续往下看，请看这里，在我们这个电机控制板的下方有一个外接直流电源接口，这个外接直流电源接口的作用非常关键，请大家注意，我们的电机要想工作首先是要有电，那么这个电从哪来呢？可能有朋友会说，既然这个电机扩展板是插在 Arduino 上的，那这个电能不能从 Arduino 上来呢？这个回答呢也对也不对。首先我说为什么这个回答是对的，请看在我们这个电机扩展板左上方这里有两个驱动舵机的端口，那么这两个舵机端口它的电源来源正是我们的 Arduino 开发板，换句话说我们的 Arduino 开发板它这个输出功率还能够勉勉强强地满足这个舵机的要求；但是如果要是让这个 Arduino 驱动直流电机或者步进电机的话，那么这 Arduino 电源的输出功率太低了，很难能够满足直流电机和步进电机的要求，那这时候我们就需要依赖外接直流电源接口来为直流电机和步进电机来供电了。

除了能够为电机提供电源以外，这个外接直流电源接口还有一个非常重要的功能，那就是它也可以为我们的 Arduino 开发板来供电。那么这可能有朋友会糊涂，既然我们这个 Arduino 已经通过 USB 数据线连到电脑上了，那么这个电脑上的 USB 已经可以为 Arduino 开发板供电了，干嘛现在还有一个外接电源接口来为 Arduino 供电呢？原因是我们在这个开发的时候，我们电脑是用数据线连到 Arduino 开发板了，这时候 Arduino 上的这个电呢就是来自于我们电脑的 USB 端口，但是我们不可能永远地来开发这个项目，可能我们把这个项目开发完以后，我们要使用这个开发板以及这个扩展板把它装到一个小机器人上面了，那么这个小机器人可能会动，跑得还挺快的，这时候如果小机器人跑起来，是不是我们还要用一个电脑拿一根数据线接在这个 Arduino 开发板上，小汽车跑到哪儿我们后边跟着哪儿呢？这个就不太现实了。因此我们就需要把这个数据线给断开，但一旦数据线断开的话，那么这个 Arduino 开发板这个电源从哪来呢？我们就可以用这个外接直流电源接口来为我们的 Arduino 开发板来供电了，换句话说这个电源接口它上面连接电源的一方面是可以为电机供电的，另一方面也可以为我们的 Arduino 开发板来供电。

好，那讲到这儿这就引出了我们要给大家讲的下一个电子元件了。请看这里，是有一个电源跳线，这个电源跳线的功能就是来设置我们这个外接直流电源接口它这个功能的。当我们的 Arduino 需要通过外接直流电源接口上连接的电源来供电的时候，那么这时候我们就把这个电源跳线安到这个插针上去；当我把这个插针上面这个跳线给它移除的时候，这个时候我们这个外接直流电源是不会为我们 Arduino 供电的，那么这个时候 Arduino 就必须要通过它上面所连接的这个 USB 数据线连到电脑上，这个时候 Arduino 才能有电。这一点很关键，请大家务必要小心，不要搞错了。

另外还有一个非常非常关键的地方，那就是我们这个外接直流电源的极性千万不要接反了。什么叫做不要接反呢？请看，我们这个外接接口上面这里标志的是正 M，那么这个正 M 所对应的这个端子是接电源正极的，千万注意正极对正极；旁边这个写 GND 这个单词的，它就是接直流电源的负极的，不要搞反，如果搞反的话有可能会对我们这个电机扩展板造成伤害，所以千万小心。另外我们在给扩展板配一个电源的时候也要小心，这个电源不是随便想用多大就用多大的，电源首先有个电压的要求，还有个电流的要求。具体的电压的要求，它的允许接的电压的范围是正 4.5 伏特到 25 伏特之间，这是一个很宽泛的电压范围，具体应该选多大电压呢？这个是由被驱动的电机的工作电压来决定的，比如说我们现在要驱动这个电机它的工作电压是 5 伏特，那好，那你接一个 5 伏特电压就可以了；或者说您现在驱动电机它的工作电压是 12 伏特，那接一个 12 伏特电压；那么如果我们这个电机它的工作电压超过 4.5 伏特到 25 伏特这个范围怎么办？那很遗憾，我们这个电机扩展板是没办法驱动这种类型电机的，我们只能换一个电机驱动板来工作了。好，那以上就是这个外接电源的电压的要求，要看我们电机它这个电压要求。

除了电压要求以外，还有一个电流的要求，电流的要求和电压要求非常的相似，也要看我们这个驱动电机它对电流的这个要求是多大。这款 AFMotor 电机扩展板它能承受的最大输出电流基本上就是 1000mA 左右，你让它输出超过 1000mA 的电流的话，那这个时候这个电机控制板就有点吃不消了。那么吃不消的现象是什么呢？请看我们这电机扩展板上有两块 L293D 芯片，那么这两块 L293D 芯片如果输出电流超过 1000mA 的时候会变得非常的烫，老这么烫的时候它可能就烧了，所以呢我们这个电机扩展板它基本上就是用来控制一些像我刚才说的直流模型电机，或者是 28BYJ-48 步进电机，如果我们让它驱动 NEMA 步进电机的话呢，这时候它是吃不消的，一般 NEMA 系列的步进电机它所需要的电流是比较大的，所以这就是为什么我不用它来控制 NEMA 步进电机。好，那么简单来说，当我们为这个扩展板来选择电源的时候，对于电流这个指标，它要看电机的电流要求，那么电机的电流要求如果过大，请注意，如果电机它对电流要求超过 1000mA 了，那么很遗憾，我们 AFMotor 电机扩展板无法为其工作。好，关于如何来选择外接电源这个问题，我要给大家讲的就是这些内容了。

接下来我给大家讲的是，要想让我们的 AFMotor 电机扩展板能够正常工作的话，我们还要为我们的 Arduino IDE 安装第三方库，这个第三方库的名字就在屏幕上所看到的，它也叫 AFMotor 电机库。有了这个 AFMotor 电机库以后，我们就可以用扩展板来驱动直流电机以及步进电机了。但是对于直流电机来说，AFMotor 电机库足够了，如果要是你还想要用这个扩展板来驱动步进电机的话，那么光有这个 AFMotor 电机库就有点不够了，因此我建议您除了安装这个 AFMotor 电机库以外，如果想要驱动步进电机的话，我建议您再装一个 AccelStepper 库。让您装两个第三方库的原因是，AFMotor 库用它来控制直流电机还行，但是要用它来控制步进电机呢，它的功能太单一了，我们在后续教程中给大家介绍这些制作中，有些功能光靠 AFMotor 库是没办法实现的，因此我们还建议您同样也安装 AccelStepper 库。

那么接下来我给大家讲讲如何把我们的电机和电机扩展板连在一起。我刚才给大家说了，在这个电机扩展板的两侧有两排连接电机的接口，这两排接口是可以分成四个直流电机端口的。首先第一个，你看这个红色矩形所标志的标志 M1 的，这是第一个这个电机的端口，接下来请看 M2，这是第二个端口，M3 在这里，M4 在这里。那么在这两排接口的中间，请看中间的这两个，这两个端子是接地的，接地的端子。如果我们只是驱动直流电机的话，那么中间这个接地端子是用不到的，但如果你驱动有一些步进电机，比如说像 28BYJ-48 步进电机，这时候就要用到接地端子了。可能有朋友在听我讲这些什么端子、接口啊、有什么电机啊接地可能会有点迷惑，没关系，我再给您详细地讲一讲。你看哈，我们这里 M1 这个 M1 它有两个，两个接线的这么两个地方，这每一个接线的地方就是一个端子。对于直流电机来说，请大家回忆一下，直流电机通常是有两根引线的，这两根引线请看，这两根引线就是直流电机的两根引线，这两根引线将会分别地连接到这两个端子上，这两个端子一起就构成了一个直流电机的一个端口，一个端口两个端子，两个端子接两根线。怎么的连接呢？请看，在每个端子上面都有一个螺丝钉，那么这个螺丝钉我们是可以使用螺丝刀来拧紧或者是松开的，当我们顺时针拧这个螺丝钉的时候，这时候这个端子上面的这个接线的位置就会把我们这根电机的引线把它给固定住，那么反过来当我们逆时针地来旋转这个螺丝钉的时候，这时候这个端子就会把这根线给松开。

## 本节要点

- 新的控制方法：用专门为 Arduino 设计的 AFMotor 电机扩展板（背面两排插针直接插到 UNO / Mega 上），省去大量接线；缺点是占用 Arduino 资源，插上后基本只能干驱动电机这一件事。
- AFMotor 扩展板适合控制通用模型直流电机（如 130 电机）、28BYJ-48 步进电机和舵机，不适合控制 NEMA 系列步进电机；板载两块 L293D 驱动芯片。
- 主要功能：最多驱动 4 个直流电机、2 个 28BYJ-48 步进电机、2 个舵机；两侧红色标注端口接直流/步进电机，左上角 SERVO1/SERVO2 接舵机。
- 电源要点：外接直流电源接口电压范围为 4.5V～25V（由被驱动电机工作电压决定），承受电流约 1000mA，超限会使 L293D 发烫甚至烧毁；端子正 M 接正极、GND 接负极，绝不能接反。
- 电源跳线：需要外接电源给 Arduino 供电时插上跳线；开发阶段（USB 连电脑供电）应移除跳线，否则外接电源不向 Arduino 供电。
- 库的准备：需为 Arduino IDE 安装 AFMotor 电机库；若要驱动步进电机，还建议再装 AccelStepper 库，因为 AFMotor 库对步进电机功能太单一，且 AccelStepper 库无法直接控制本扩展板。
- 接线结构：两侧接口分为 M1、M2、M3、M4 四个直流电机端口，中间两个端子是公共接地端子（只驱动直流电机时用不到，驱动 28BYJ-48 等步进电机时要用）；每个端口两个端子，用螺丝刀顺时针拧紧固定电机引线、逆时针松开。
- 直流电机示例程序：`#include <AFMotor.h>`；用 `AF_DCMotor` 建立 `motor1`～`motor4` 四个对象，括号内参数对应 M1～M4 端口；`setup()` 中用 `setSpeed(200)`（范围 0～255）设速度并用 `run(RELEASE)` 让电机停止。
- 运行逻辑：`loop()` 中先用 `run(FORWARD)` 正转，再用 `for` 循环配合 `setSpeed()` 把速度由 0 逐渐加大到 255，然后由 255 逐渐减小到 0；接着用 `run(BACKWARD)` 反向做同样的加减速，最后 `run(RELEASE)` 配合 `delay(1000)` 停止 1 秒，如此往复；如转向相反，可对调电机两根引线。
