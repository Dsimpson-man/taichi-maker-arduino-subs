## 关于本字幕集

这是太极创客 Arduino 教程**第四部分**的完整字幕文稿，主线是**把电机这一类执行器彻底讲透**。

原视频共 **14 个分P，已全部整理交付**，总时长约 **5 小时 39 分钟**。

这是四个部分里**最"硬件"的一部分**：先讲电机的分类与基本原理，再分别深入直流电机与步进电机两大路线，从最基础的 `analogWrite()` 驱动讲到 `AccelStepper` 库，最后落到两款常用扩展板（AFMotor、CNC）的实战使用。

**整理标准：**

- ✅ 去除口语语气词（"呢/啊/呃/那么"等）与口误重复
- ✅ 补充标点、按知识点与操作步骤分段
- ✅ 校正电机与驱动领域技术术语（`H 桥`、`PWM`、`步距角`、`AccelStepper`、`AFMotor`、`CNC Shield` 等）
- ✅ 保留讲解者的教学语气与全部实质内容（正文信息保留率 ≥ 80%，本册实测 85%–97%）
- ✅ 每集附「本节要点」便于复习

## 学习路线

```
阶段一 · 电机原理        4-1-1 ~ 4-1-2   电机分类、结构、为什么会转
      ↓
阶段二 · 直流电机驱动    4-1-3           H 桥、PWM 调速、正反转
      ↓
阶段三 · 步进电机原理    4-1-4 ~ 4-1-5   步距角、励磁方式、细分
      ↓
阶段四 · 步进电机实战    4-1-6 ~ 4-1-8   42 步进电机（大功率）、28BYJ-48（入门款）
      ↓
阶段五 · AccelStepper 库 4-1-9 ~ 4-1-10  加减速、多轴协调、专业级控制
      ↓
阶段六 · 电机扩展板      4-1-11 ~ 4-1-14 AFMotor（直流/步进）、CNC Shield（三轴）
```

**学习建议**：

- 手里有 **28BYJ-48 + ULN2003 驱动板**这套最便宜的入门组合，就可以跟着阶段三、四动手（对应 4-1-8）。
- **42 步进电机 + 驱动器**成本较高、且需要外接电源，建议先把原理（4-1-4/4-1-5）看懂再决定是否购买。
- 如果目标是做**写字机 / 雕刻机 / 3D 打印机**，重点看阶段五（`AccelStepper`）和阶段六的 CNC 扩展板（4-1-13/4-1-14）。
- **务必注意**：步进电机不能直接接 Arduino 引脚，必须经驱动器；且电机供电与 Arduino 供电要分开处理，具体接法见对应集数。
