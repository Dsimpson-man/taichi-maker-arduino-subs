## 关于字幕来源的说明

本字幕集取自 B站**官方的 AI 生成字幕**（`ai-zh`），并非人工字幕。

需要说明的是，B站的 AI 字幕接口存在一个已知问题：**对同一分P 重复请求时，可能返回其他视频的字幕内容**。因此本项目的抓取流程对每一集都做了内容核对（时长比例 + 开头主题），并对发现异常的集数进行了重新抓取，确保交付内容的正确性。

AI 字幕本身也存在同音字误识别（如把 Arduino 识别成"耳边""阿迪诺"），整理时已尽力校正。**如发现技术描述与视频原文有出入，请以原视频为准。**
