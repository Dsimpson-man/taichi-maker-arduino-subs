## 怎么用

**找代码**：直接搜函数名，比如搜 `analogWrite` 或 `WiFi.begin`，会定位到讲它的那几集。

**按路线学**：从第一部分开始。第二部分是第一个完整动手项目；第三、第四部分可以按兴趣挑；ESP8266 是联网方向，需要一点第一部分的基础。

**当讲义看**：每集末尾的「本节要点」可以快速回顾，不用重看视频。

**建议配合原视频**：文稿保留的是讲解内容，接线演示、实物外观、IDE 界面操作这类**只能看画面**的信息无法用文字替代。

## 整理标准

- 去除口语语气词（"呢/啊/呃/那么"等）与口误重复
- 补充标点、按知识点与操作步骤分段
- 校正领域技术术语（`analogWrite()`、`PWM`、`Servo`、`ESP8266WebServer`、`ArduinoJson` 等）
- **保留讲解者的教学语气与全部实质内容**（正文信息保留率 ≥ 80%，实测 85%–105%）
- 每集附「本节要点」便于复习

## 关于字幕来源与准确性

本字幕集取自 B站**官方的 AI 生成字幕**（`ai-zh`），**不是人工字幕，也不是官方文稿**。

整理过程中处理了两类问题：

1. **AI 同音字误识别** —— 如把 `Arduino` 识别成"耳边""阿迪诺"，`JSON` 识别成"杰森"。已尽力校正，每部分 README 附有该部分的**术语对照速查表**。
2. **接口返回脏数据** —— B站 AI 字幕接口存在一个已知问题：**对同一分P 重复请求时可能返回其他视频的字幕**。本项目对每一集都做了内容核对（时长比例 + 开头主题），并对发现异常的集数重新抓取。

**尽管如此，文稿仍可能存在识别或整理误差。如发现技术描述与视频原文有出入，请以原视频为准。**
