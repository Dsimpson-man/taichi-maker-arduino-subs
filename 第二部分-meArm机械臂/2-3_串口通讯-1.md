关于串口通讯，我们在之前的课程里面都是让 Arduino 通过串口发送整个程序运行的一些变量的状态，然后我们再通过电脑上的 Arduino IDE 里面的串口监视器，去了解这个程序它所运行的情况。那时候我们一直使用的是这三条语句，分别是 `Serial` 库里面的 `begin` 这个函数，还有 `println` 这个函数以及 `print` 这个函数。但既然是通讯，我们就不能只是 Arduino 光发送数据到我们电脑上来，Arduino 本身还要能够接收这个数据。具体怎么让 Arduino 来接收我们发送给它的数据呢？这个就是我们这节课主要讲解的内容了。

首先让我们先对这个串口通讯有一个整体的认识，我们来到太极创客的网站里面来。请看，在我们这个编程语句参考函数下面，有一个关于串行通讯的介绍。串行通讯就是串口通讯的另外一种称呼。好，我们先看：串行端口用于 Arduino 和个人电脑或其他设备进行通讯，所有的 Arduino 控制器都有至少一个串行端口。请注意，所有的 Arduino 控制器都有至少一个串行端口，有些 Arduino 控制器会有不止一个串行端口，这串行端口也叫做 UART 或者 USART。个人电脑是可以通过 USB 端口与 Arduino 的引脚 0（RX）和引脚 1（TX）进行通讯，所以当 Arduino 的引脚 0 和引脚 1 用于串行通讯功能的时候，Arduino 的引脚 0 和引脚 1 是不能做其他使用的。我们也可以通过 Arduino IDE 中的串口监视器来与 Arduino 控制器进行串口通信，我们只需要点击 Arduino IDE 软件中的串口监视器按钮，就可以打开这个串口监视器了。

请注意，这里所说的是我们可以用串口监视器进行串口通讯。换句话说，我们不光是可以用 Arduino 向我们的电脑发送数据，并且使用串口监视器来浏览这些数据的状态，我们还可以通过串口监视器向 Arduino 来发送数据。现在请您看屏幕，在屏幕上的这个 Arduino UNO 开发板的引脚 0 和引脚 1 上面，分别写着 RX 和 TX。我们之前接触过它很多次了，不过这次我要给它做一个郑重的介绍。什么介绍呢？请看，RX 它的含义就是接收，也就是 receive；TX 它的作用是发送，也就是 transmit。也就是说，如果我们要让 Arduino 接收数据的时候，它是通过这个引脚 0，也就是 RX 来接收我们发给它的数据的；那么反过来，如果用 Arduino 来向我们其他的设备，比如说像我们电脑来发送数据的时候，它是通过引脚 1，也就是 TX 来发送数据的。

同时，我不知道大家有没有注意到，当我们在使用 Arduino 串口监视器进行数据传输的时候，我们这个 Arduino 开发板上面会有两个 LED 灯，旁边一个写着 TX，一个写着 RX。当 RX 和 TX 工作的时候，这个相应的 LED 也会发生闪烁。如果你们以前没有注意的话，那请您以后我们再上传程序或者在 Arduino 进行串口通讯的时候，你可以看一看。同时我们的电脑相对应的这个 USB 端口里边，也是具有 TX 和 RX 这两条数据线的。

请大家注意，以前我们的电脑是专门有一个叫做串口的这么一个端口来进行串口通讯的，后来新的电脑把以前的串口给它融入到了这个 USB 端口里了。这个 USB 端口不光能够进行串口通讯，它还有很多其他的功能，不过这个就超过我们这个学习范围了，我们现在只要记住了：USB 端口我们是用它来和我们 Arduino 进行串口通讯的。

现在您在屏幕上看的这个示意图，就是我们的 Arduino 控制器和计算机进行串口通讯的时候，它的一个连接方式。请看好，我们计算机上面这个 TX 这个端口，它是通过数据线连到了 Arduino 的 RX 这个端口上的。这样的话，当我们有数据要发送给 Arduino 的时候，就可以通过计算机的这个 TX 发送到 Arduino 的 RX 中，TX 发送、RX 接收。那相对应的话，我们当然有 Arduino 的数据要发送给计算机的时候，也是通过 Arduino 的 TX 发送出到计算机的 RX 来接收。

不过有一点我们经常会忽略，就是说我们所要进行串口通讯的这些设备，它的 GND 必须要连接在一起的。因为我们这个进行串口通讯的设备，它是一个具有高电平和低电平的电压信号，所以进行通讯的这些设备，必须要接地点都连在一起，这样才能有相应的高电平和低电平产生。可能这么说有点抽象，没关系，我们后面继续学，你很容易就能明白。好，现在只要记住一点：只要是进行串口通讯，就一定要把接地点连在一起。肯定有朋友说，我从来没有把我的电脑和我的 Arduino 板接地接在一起过。实际上，当您用您的数据线把 Arduino 和电脑连在一起的时候，您的这根数据线里面就已经把 Arduino 的这个接地点和您的电脑的接地点连在一起了。同时您的这根数据线不光能够把这两个设备的 GND 连到一起，它还会把 RX、TX 进行相应的连接，这样的话我们的 Arduino 和我们的计算机就能进行数据通信了。

同时，如果您要使用 Arduino 和其他的模块进行串口通讯的时候，也要遵守这样的一个连接方式。比如在我们这个 meArm 的这个小制作中，我们将来会使用 HC-06 这个蓝牙通讯模块来和 Arduino 进行通讯的，那这个通讯过程就是一个串口通讯过程。我们看我们这个 HC-06 这个模块，它也有一个 TX 和一个 RX，那么它和 Arduino 的连接方式，和刚才我们电脑和 Arduino 的连接方式是相同的，同时一定注意 GND 是连到一起的。

## 本节要点

- 前几课使用串口是单向的：Arduino 用 `Serial.begin()`、`Serial.print()`、`Serial.println()` 把变量状态发到电脑，再用串口监视器查看；本节课要解决的是「Arduino 如何接收数据」。
- 所有 Arduino 控制器都至少有一个串行端口（UART / USART），有些型号不止一个；UNO 上串口占用引脚 0（RX）和引脚 1（TX），一旦用于串口通讯就不能再作其他用途。
- RX = receive，负责接收；TX = transmit，负责发送。两台设备交叉连接：本机 TX 接对方 RX，本机 RX 接对方 TX。
- 串口通讯双方的 GND 必须连在一起，因为高/低电平是相对同一参考地而言的；用 USB 数据线连接 Arduino 和电脑时，线里已经同时接好了 GND 与 RX、TX。
- 串口数据是一串高低电平：高电平 5V 代表 1，低电平 0V 代表 0；数据一位一位排队发送，所以叫「串行通讯」，与之对应的是同时发送的「并行通讯」（Arduino 不支持）。
- 一个 bit 是最小单位，一个字节（byte）有 8 位（8 个 bit）。Arduino 每次读取串口数据都是按一个字节读取，这个概念必须牢记。
- Arduino 的串口采用 TTL 标准（高电平 5V、低电平 0V），其他串口标准的高低电平电压值不同。
- 波特率决定每一位数据的持续时间。`Serial.begin(9600)` 表示每秒传输 9600 位，每位持续 1/9600 秒；程序中设定的波特率必须与串口监视器里设定的速率一致。
- 波特率对应的位并不都是数据位，字节前后还有用于标识和控制的位；HC-06 蓝牙模块与 Arduino 之间也是这种串口通讯连接方式。
