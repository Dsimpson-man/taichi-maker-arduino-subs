# 2-1 MeArm项目概述

## 正文

大家好，欢迎您收看由太极创客为您制作的零基础入门学用 Arduino 教程。这节课是我们整个教程的第二大部分的第一节课。在第一部分的课程中，我们给您讲述了关于 Arduino 的一些基础知识；那么在这一部分里面，我们将要把我们学到的这些基础知识实际地应用起来，我们一起来做一个项目。这个小项目，它的名称叫做 MeArm，它是一款开源的机械臂。请您留意一下，我们这一部分的教程将是我们第一部分教程的延续，所以我们这部分教程需要您掌握了第一部分教程的知识以后才能学习。现在您在屏幕上看到的这些知识，像是我们这一部分教程里面需要用到的知识。假如您还没有掌握这些知识的话，我建议您还是先看一看我们零基础入门学用 Arduino 教程的基础知识篇，然后再来看我们这部分的教程。

既然我们要学习制作的是一款机械臂，那我们先了解一下这个机器人它的概念。机器人是一个非常非常广泛的概念，它包括一切能够模拟人类行为或者思想、并且还能够模拟其他生物的机械，包括像机械爪、机械猫等等等等。对于机器人的定义有很多种分类方法，到目前还有很多争议，而且事实上有些电脑程序都可以被称作是一个机器人。那么我们这个 MeArm 机械臂，它肯定不是电脑程序，它所符合的这个特点就很像是我们在屏幕上看到的第三条：它模拟的是一个工业中使用的机器人，这种机器人是能够自动执行任务的人造机器装置，它可以取代或者协助我们人类工作，一般是机电装置，由计算机程序或者是电子电路来控制。

在这一堆生涩的概念里，我想让您注意几点。首先第一个，请留意我们这个 MeArm 机械臂是由计算机程序和电子电路来控制的，这里面这个电子电路指的就是我们这个 Arduino 的控制器了，那么这个计算机程序指的就是我们为 Arduino 控制器所编写的程序；同时，我们这个 MeArm 是一个机电装置。它是不是可以协助取代我们的工作呢？可能有点难，不过学习它可以让我们掌握有关机械臂和机器人的一些基础知识和概念，这样将来我们真的到了机器人时代的时候，我们可以更轻松地驾驭它们。

到这儿可能有朋友说：机器人时代，你开玩笑的吧，感觉还挺遥远的呢。其实不然，我们现在的生活里面已经充满了机器人了。比如我们家庭生活里边，扫地机器人它就是一个非常典型的例子；或者我们平时日常使用的产品，很多都是机器人做出来的，比如像汽车，很多汽车工厂都采用了机器人来生产、来制作；还有像医学、太空探索等很多很多领域，都离不开机器人。这个要说起来就没完没了了，我们还是把我们的注意力拉回到我们的 Arduino 上来，让我们一起来制作专门属于我们自己的这个小机器人。

首先我给大家介绍一下学习制作、还要使用 MeArm 都需要哪些材料。第一个，自然而然就是一个 MeArm 本身了。MeArm 它是一个开源的硬件产品，您可以通过互联网来获得制作的图纸，请注意，因为它是开源的，所以这方面的资料都是免费、都可以获取到的。我们也整理收集了一些关于 MeArm 的相关的制作、还有组装的一些资料，您可以到我们太极创客网站上面来获得这方面的资料内容，希望对您有所帮助，这个网站网址就在屏幕上显示出来了。假如您有充分的制作设备的话，您可以自己来把这个图纸转化成 MeArm 的零部件，然后自己来搭建；假如您设备有限，您也可以通过互联网来获得一些套件，然后再把这个套件组装起来，这个方法可能更适合我们刚刚入门的 Arduino 的爱好者们。不管您选择哪种方法，我觉得都没有问题，因为我们现在要学习的是 Arduino，MeArm 是配合我们 Arduino 学习使用的。

假如您是选择通过互联网来获得 MeArm 套件然后进行组装这种方法的话，那请您千万留意一点：现在屏幕上面看到的这个机械臂，它叫做 Mini Arm，它不是 MeArm，它跟 MeArm 很类似，但是它有很多地方跟 MeArm 有一些区别。为了制作这套教程，我们太极创客这个团队曾经尝试了很多种开源硬件的产品，最终我们选择的是 MeArm 而并不是 Mini Arm。我们在这儿不会去评论任何一种产品的好与不好，不过请留意，我们这套教程使用的不是 Mini Arm，所以您千万要小心这一点。为了便于大家能够识别 MeArm 和 Mini Arm，我们在这儿给大家指出一个非常明显的差别：请看，MeArm 它在机械臂正前方这个地方，是一个塑料的板，那么这个板的两端是用两个螺丝钉把它固定起来的；但是在 Mini Arm 上面的这块是没有这个板的，而且也没有这个螺丝钉。这个地方对整个 MeArm 的结构起到了一个很好的加固作用。所以我们选择的是 MeArm 而不是 Mini Arm，这一点请大家千万要留意。

然后我们还需要一块 Arduino UNO 的开发板，这个开发板具体选择官网版还是选择克隆版，我们在第一部分的教程里面给大家反复地讲过几次了，在这我就不再赘述了。接下来我们还需要一个面包板，以及一个面包板电源模块，这个电源模块的作用是为这个 MeArm 来单独供电的。我们这个 MeArm 本身是有四个小电机来驱动这个 MeArm 的动作的，如果单独靠这个 Arduino 来为这个 MeArm 这四个小电机来供电可不可以呢？老实说，如果您只是在测试、在学习的时候，您可以凑合着用这个 Arduino 来为这四个电机来供电；不过如果您要真的让这个 MeArm 稳定地工作的话，您还是必须要为这个 MeArm 单独地配一个电源。这样的话 MeArm 才能够更加有力量，也不会老是像抽筋一样地在那抖动。假如您担心这个电源模块不会使用，没关系，我们在后续的教程中会仔细地给大家讲述这个电源模块怎么用，而且我们在未来的这些制作项目里面也会经常用到这个面包板电源模块，它还是很有用处的。

接下来，有面包板自然也就有面包板跳线了，还有我们需要用 20 根左右的杜邦线，注意，是公对公的杜邦线。还有我们需要一根 USB 线，这根 USB 线的作用是为了配合我们这个面包板电源模块使用的，它的一端将来会连到这个电源模块上，它另外一端会连到我们这个供电设备上。刚才我说了，为了让 MeArm 能够稳定地工作，我们需要为它提供一个独立的电源，这个电源我们给您提供了几种方案：第一种方案，您可以使用您一般手机的充电器；第二种方案，您也可以使用您电脑上的 USB 端口；第三种方案，就是可以使用充电宝。这三种方案每一种都可以，看见哪种方便就选哪种。它们都有个共同特点是什么呢？就是所有这三种方案都能输出正五伏的直流电压，我们这个正五伏直流电压会通过这个 USB 线最后传递到我们这个电源模块，然后这个电源模块是给我们这个面包板来供电使用的。假如您有别的方法来给面包板供电，那您完全可以采用您自己习惯用的方法，没有必要按照我们刚才给您提的这几种方案，我们只是给您一个建议，具体怎么做呢您自己来定。

最后是一个可选件。假如您希望用您的手机或者其他的移动设备通过蓝牙的方式来控制这个 MeArm 机械臂，那么您就需要一个 HC-06 无线蓝牙串口透传模块，当然了，如果您喜欢用其他的无线控制模块的话也可以。自然了，如果您不需要用蓝牙来控制 MeArm 的话，那这个您可以把它从您的清单里面删除掉。如果您选择了使用这个 HC-06 这个无线蓝牙模块的话，那么您还需要两个电阻，这两个电阻阻值分别是 10K 欧姆和 20K 欧姆，它们的作用是保护这个模块的。

在我们学习和制作这个 MeArm 之前，我们先对这个 MeArm 机械臂有一个整体的概念和认识。请看，这个 MeArm 机械臂，它的这个动作是靠四个电机来控制的，那么这四个电机是连接在我们这个 Arduino 控制器上的，我们通过对这个 Arduino 控制器的编程，可以对这个四个电机发出相应的指令，那么同时这四个电机在接收到这个指令以后，也会带着这个 MeArm 做出相应的动作。

首先我们来看底座上这个电机，它会对这个 MeArm 机械臂产生怎样的作用呢？请看，我们现在这个 MeArm 它正在沿着底座左右地转动，这个左右转动是源自于何处的呢？就是底座上这个电机带动这个 MeArm 在左右转动。接下来我们再来看这个机械臂它的后臂上面所连接的这个电机，它的作用是怎么样的呢？请看屏幕，现在这个 MeArm 机械臂它正在前后地运动，那这个前后运动来自于何处呢？是由于连接后臂的这个电机正在转动，这个转动也就带动了这个后臂前后运动。接下来我们来看这个电机，它的主要作用是来驱动这个前臂的动作的，跟其他的电机不同的是，这个电机它是通过一个传动装置来驱动这个机械臂的前臂的。请看屏幕，现在我们这个机械臂它正在上下动作，这个上下动作是驱动前臂这个电机转动，从而带动这个前臂在上下动作。最后我们来看这个机械臂控制一个钳子开合的这个电机，它是怎么来发挥作用的呢？请看，现在这个钳子正在重复张开、闭合这样的一个动作，它是由于我们这个钳子上装的这个电机，它通过一系列齿轮传动带动这个钳子在动作。

关于这个机械臂它的基本介绍，我要讲的就是这些内容了。后续的我们会把这个 MeArm 一步一步地拆分成小任务，我们通过完成一个又一个小任务，最终我们将会一起来搭建出这个机械臂。同时我们也会把这个教程的所有的相关内容免费地开放给大家。当然我们的水平也非常有限，假如您看了我们的教程内容以及看了我们这个开发软件，有任何的改进的建议的话，我们非常欢迎您来跟我们联系，毕竟这个 MeArm 机械臂它是一个开源的项目，我们也非常希望能跟大家一起来交流，一起让这个开源项目越来越好，越来越让更多人喜欢上它，通过它我们一起来爱上科技创作，感受创客文化。好了，这节课的内容到这就结束了，我们下一节课再见。

## 本节要点

- 本部分是第一部分 Arduino 基础知识的延续与应用，MeArm 是一款开源的机械臂项目，需要先掌握基础知识篇的内容。
- 机器人的定义非常宽泛；MeArm 属于模拟工业机器人的机电装置，由 Arduino 控制器（计算机程序 + 电子电路）来控制。
- 材料清单：MeArm 本体、Arduino UNO 开发板、面包板、面包板电源模块、跳线、约 20 根公对公杜邦线、USB 线；可选 HC-06 蓝牙模块及 10K / 20K 欧姆电阻。
- 请注意区分 MeArm 与 Mini Arm：MeArm 正前方有一块用两颗螺丝固定的塑料加固板，本教程使用的是 MeArm。
- 必须为 MeArm 单独供电（手机充电器 / 电脑 USB 口 / 充电宝，均输出 5V 直流），否则机械臂会无力并抖动。
- MeArm 的四个电机分别控制：底座左右旋转、后臂前后运动、前臂上下运动（经传动装置驱动）、钳子张开与闭合。
