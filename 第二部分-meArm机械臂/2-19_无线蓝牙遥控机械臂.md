大家好，在这节课我将给大家介绍一下如何使用 HC-06 这个蓝牙模块配合我们的机械臂，通过手机用蓝牙来控制我们的机械臂。首先我给大家介绍一下使用 HC-06 蓝牙模块来控制机械臂的这个电路连接，相信大家看到这个电路图应该不会感到很陌生，因为这个就是我们之前使用 Arduino 控制器来控制我们机械臂的四个舵机的一个电路连接，完全一样，唯一不同的是我们在这个电路基础之上增加了一个蓝牙模块。

那我们来着重看一下这个 HC-06 蓝牙模块的具体情况。请看这个蓝牙模块的 VCC 和 GND 这两个引脚，分别通过了引线接在了我们的电源轨的正极和负极上。好，我们再来看蓝牙模块的 TX 这个引脚，它是经过了一根绿色的这根导线一直接到什么地方呢？我们来沿着它走哈，请注意这个绿色的导线，TX 是接到我们这个 Arduino 开发板的 RX 硬件的串口这个引脚上。那 Arduino 的 TX 这个引脚呢，还是通过蓝色一根导线，我们看一下一根蓝色导线接到什么地方呢？Arduino 的 TX 这个引脚是通过蓝色导线一直接到了，请看，经过了一个分压电路接到了 HC-06 的 RX 这个引脚上。好，同时 RX 引脚上面也是接了两个电阻，这两个电阻的作用就是起到分压的作用，我们之前介绍过。请看 HC-06 的 RX 引脚出来两条路，一条路通过一个电阻然后接到了电源轨的负极上，也就是整个电路的接地这个点；那么回过头来我们再看 RX 另外一条路，也是通过了一个电阻连到了我们的 Arduino TX 引脚上。

那到这里你可能也注意到了，我们在这个实例中使用的是 Arduino 的硬件传输接口，当然您也可以试着使用软件传输接口，如果使用软件串口接口稳定性没有问题的话那您可以继续使用，否则的话建议您可以把它调整到 Arduino 的硬件串口接口上。还有一点请注意，如果我们在 Arduino 开发板上的硬件串口接口上接了外围电路的话，那么我们在上传程序的时候先要把硬件传输接口上的外围电路先移除，才能够上传程序给 Arduino 开发板。

我们直接看，我们启动应用以后就可以点击 HC-06 这个设备名称，点击这个设备名称以后将会弹出这样一个菜单，这个菜单里面一共有四种工作模式，我们将选择 controller mode，也就是手柄的工作模式。好，这个手柄的工作模式它的界面就是大家现在看到的这个样子。假如你是首次使用这款应用的话，那么在使用应用之前先要对手柄的各个按键进行一个初始化的设置，这个初始化设置是怎么做的呢？您可以点击屏幕右上角这个小齿轮的这个图标，那么点击这个图标以后，将看到这个界面，就是你现在屏幕上看到这个样子了。您看有两个屏幕，是因为这一屏还挺长的，我们把它分成两部分了，那么上半部分呢，到这里 start，从这里开始就是下半部分的了。好，我们看到在这个屏幕里面呢，因为我们是首次使用这个应用程序，所以所有的这些按键都是没有设置过的，显示为 not set。那么没有设置过的话怎么办呢？我们就要给它进行一个初始化的设置了。怎么进行初始化设置呢？我们只需要把我们对应控制机械臂的这些字符指令把它输入进来就可以了。您现在就可以按照我们屏幕上显示这些字符对您的手机应用来进行一个初始化的设置，这些字符的内容呢不用我多说了，在我们之前的课程内容也给大家介绍过很多次了——W、S、A、D、8、5、4、6。

## 本节要点

- 本节把蓝牙控制与机械臂结合起来：电路与之前用 Arduino 控制四个舵机的连接完全相同，只是在原有电路基础上增加了一个 HC-06 蓝牙模块。
- 蓝牙模块接线：VCC 接电源轨正极、GND 接电源轨负极；HC-06 的 TX 接 Arduino 的 RX（硬件串口），Arduino 的 TX 经分压电路接 HC-06 的 RX。
- 分压电路由两个电阻构成：HC-06 的 RX 一路经电阻接电源轨负极（接地），另一路经电阻接 Arduino 的 TX。
- 本例用的是硬件串口；也可尝试软件串口，若稳定性没问题可以继续用，否则建议改回硬件串口。硬件串口上接有外围电路时，上传程序前必须先移除这些外围电路。
- 手机端仍以 Arduino Bluetooth Controller 为例，选择 controller mode（手柄模式）；首次使用要先点右上角小齿轮图标对按键做初始化设置（初始显示 not set）。
- 手柄按键对应的字符指令沿用之前的约定（W、S、A、D、8、5、4、6 等），其中 select 用 M 切换机械臂工作模式，start 用 I 让机械臂恢复到刚上电时的初始化状态。
- 第一段演示用手柄模式遥控机械臂夹起小旗子，按 start 可恢复初始状态。
- 第二段演示用 terminal mode（终端模式）逐条发送指令：C30 张开钳子、R90 后臂到 90 度、F90 前臂到 90 度、B45 让底盘转到 45 度，Arduino 会把指令回馈信息回送到手机屏幕。
- meArm 机械臂篇至此全部结束；下一阶段教程将以智能家居为主题，用常用电子模块配合 Arduino 制作生活中实际可用的创客作品，同样免费开放。
